# 개인 지식 위키

누적 지식 위키는 `d:\wiki` 에 있음. 목차(`index.md`)는 세션 시작 시 컨텍스트에 자동 주입됨(SessionStart 훅). 작업이 목차 항목과 관련되면 해당 페이지(`d:\wiki\<topic>.md`)를 Read 로 열어 활용. 페이지끼리는 마크다운 링크로 연결되니 필요하면 타고 들어가 확인.

- 갱신: 작업 중 오래 재사용될 지식(빌드·실행 명령, 디버깅 원인·해결, 라이브러리·API 동작, 설계 결정, 반복 패턴 등)을 알게 되면, `d:\wiki` 에서 겹치는 기존 페이지가 있으면 그 페이지를 갱신·통합하고(중복 페이지 생성 금지), 없으면 새 토픽 페이지(`<topic>.md`)를 만들고, `index.md` 에 `[제목](<topic>.md) — 한 줄 요약(그 페이지를 언제 여는지 드러나게)` 을 추가·갱신. 본문은 페이지에, 목차엔 요약만. 페이지엔 핵심 주장의 근거·출처, 불확실 항목(추정·미확인), 시간 민감 지식의 갱신 날짜를 표시.
- 유지: 사용자가 요청하면 점검 — 노후 정보, 페이지 간 모순, 고아 페이지(인바운드 링크 없음), 끊긴·누락 링크, 보강 필요 지점.
- 목차는 얇게 유지. 항목이 많아지면 카테고리별 sub-index 로 분리하고 최상위 목차엔 sub-index 만 둠.
