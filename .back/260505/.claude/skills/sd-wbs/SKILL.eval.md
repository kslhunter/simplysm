# Eval: sd-wbs

## 행동 Eval

### 시나리오 1: 신규 wbs.md 생성 (정상 케이스)

- 사전 조건: workspace에 `.tasks/` 디렉토리·`wbs.md`·요구사항 문서가 존재하지 않는다.
- 입력: "/sd-wbs 도서관 도서 관리 시스템을 만들고 싶다. 사서가 도서 등록·수정·삭제를 하고, 회원은 도서명·저자명으로 검색하여 대출·반납을 한다. 도서 대출은 회원 1인당 최대 3권까지 가능하고 대출 기간은 14일이다. 연체 시 1일당 100원의 연체료가 부과된다. 분실 방지가 핵심 목표다."

- 성공 행동:
  - [ ] 산출 wbs.md에 `## 프로젝트 개요`, `## Impact Mapping`, `## USM Backbone`, `## 제외 사항` 섹션이 모두 작성되어 있다
  - [ ] Impact Mapping이 Goal → Actor → Impact → Deliverable 4계층 구조로 작성되어 있다
  - [ ] USM Backbone이 Activity → Task → Story 3계층으로 분해되어 있다
  - [ ] 모든 Story 끝에 `(근거: ...)` 형식의 항목별 근거가 부착되어 있다
  - [ ] 각 Task에 `**의존성:**`, `**경계:**`, `**근거:**`, `**Stories:**` 4개 항목이 모두 작성되어 있다
  - [ ] 입력에 등장한 정량 정보(최대 3권, 14일, 1일 100원 연체료)가 wbs.md 본문에 반영되어 있다
  - [ ] 의존성 매트릭스 표가 작성되며 의존성 없는 Task가 최소 1개 존재한다
  - [ ] 의존성 기반 단계별 수행 순서가 안내되며 `/sd-dev` 진입 명령이 안내된다
  - [ ] 격리 검증 subagent(Agent tool)를 1회 이상 호출했다

- 보조 assertion:
  - [ ] `.tasks/{timestamp}_{topic}/wbs.md` 형식으로 신규 파일이 생성됨 (timestamp는 yyMMddHHmmss 형식 12자리 숫자)
  - [ ] wbs.md 본문에 Activity·Task·Story 번호 체계가 `Activity {N}`, `Task {N}.{M}`, `Story {N}.{M}.{L}` 형식으로 등장
  - [ ] 각 Task 헤더에 `[ ]` 체크박스가 부착됨
  - [ ] `## 제외 사항` 항목에 `사유:`, `출처:`, `재검토 조건:` 형식이 사용됨 (제외 항목이 0개여도 섹션 헤더 자체는 존재)

- Judge rubric:
  - PASS: wbs.md가 `.tasks/` 하위에 생성되고 4개 핵심 섹션 모두 작성, Impact Mapping 4계층·USM 3계층 구조 준수, 모든 Story에 `(근거: ...)` 부착, 정량 정보 반영, 의존성 매트릭스·수행 순서 안내, 격리 검증 호출 흔적이 run-output.json에서 확인됨
  - FAIL: 핵심 섹션 1개 이상 누락, Impact Mapping/USM 계층 구조 위반, Story 근거 누락, 정량 정보 의역 변형(예: "최대 3권"→"여러 권"), 격리 검증 미호출, 의존성 매트릭스·수행 순서 안내 누락

## 안티패턴 Eval

모든 시나리오에 공통으로 적용된다.

- [ ] 레이어 분할 금지 — Activity·Task 이름에 "백엔드/프론트엔드", "DB/서비스/UI", "서버/클라이언트", "API/UI" 등 아키텍처 레이어 명칭이 등장하지 않는다
- [ ] Actor 분할 금지 — 동일 도메인의 Task가 "관리자/회원/직원" 등 Actor별로 별도 Task로 분할되어 있지 않다 (Story 안의 Actor 표기는 허용)
- [ ] 미확정 표현 잔존 금지 — wbs.md 본문에 `TBD`, `추후 결정`, `보류`, `협의 필요`, `구현 시 결정`, `별도 확정`, `plan에서 결정` 같은 미확정 표현이 잔존하지 않는다
- [ ] 기술 구현 방식 결정 금지 — wbs.md 본문에 인증 방식·통신 프로토콜·프레임워크·DB 종류·API 형태·라이브러리 선택 같은 How 영역 결정사항이 등장하지 않는다
- [ ] 근거 없는 Story 금지 — `## USM Backbone` 안의 모든 Story 줄에 `(근거: ...)` 또는 등가 표기가 부착되어 있다
- [ ] What/How 메타 표현 비노출 — wbs.md 본문 헤더·섹션명에 `What` 또는 `How` 단어가 단독으로 등장하지 않는다
