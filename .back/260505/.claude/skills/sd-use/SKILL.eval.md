# Eval: sd-use

## 행동 Eval

### 시나리오 1: Help 모드 - 전체 스킬 카탈로그 표시

- 입력: "/sd-use --help"
- 체크리스트:
  - [ ] 출력에 sd-claude-docs, sd-issue, sd-outlook이 포함되어 있다
  - [ ] 출력에 sd-rule-clarify, sd-rule-options, sd-rule-readme가 포함되어 있다
  - [ ] 출력에 sd-readme, sd-init가 포함되어 있지 않다
  - [ ] 코드 블록(``` 안) 형태로 출력되었다
  - [ ] sd-commit의 설명이 "단일 커밋"을 포함한다

### 시나리오 2: 신규 스킬 라우팅 - GitHub 이슈

- 입력: "/sd-use 이슈 등록해줘"
- 체크리스트:
  - [ ] sd-issue가 최종 선택된 스킬이다
  - [ ] 선택된 스킬명이 실행 전에 사용자에게 안내되었다

### 시나리오 3: Rule 스킬 라우팅

- 입력: "/sd-use 선택지를 제시할때 규칙 적용해줘"
- 체크리스트:
  - [ ] sd-rule-options가 최종 선택된 스킬이다
  - [ ] 선택된 스킬명이 실행 전에 사용자에게 안내되었다

### 시나리오 4: 기존 스킬 라우팅 (회귀)

- 입력: "/sd-use 커밋해줘"
- 체크리스트:
  - [ ] sd-commit이 최종 선택된 스킬이다
  - [ ] 선택된 스킬명이 실행 전에 사용자에게 안내되었다

## 안티패턴 Eval

- [ ] 존재하지 않는 스킬(sd-readme, sd-init)로 라우팅한다
- [ ] 매칭 불명확 시 사용자에게 확인 없이 임의로 스킬을 선택한다
