# Eval: sd-sit-plan

## 행동 Eval

### 시나리오 1: wbs.md 입력 — 정상 흐름

- 사전 조건: workspace에 `.tasks/library/wbs.md`가 다음 내용으로 사전 배치된다 (sd-wbs 산출물을 모사). 그 외 코드베이스는 존재하지 않는다.

  ````markdown
  # WBS: 도서관 도서 관리 시스템

  ## 프로젝트 개요

  - **배경:** 도서관에서 도서 분실 방지 및 관리 효율화를 위해 도서 관리 시스템을 도입한다.
  - **환경:** 사서 1인, 회원 약 200명 규모의 소규모 도서관.
  - **전제조건:** 사서 계정과 회원 계정이 사전에 발급된다.
  - **기술적 제약:** 없음.
  - **참조 자료:** 없음.

  ## Impact Mapping

  - **Goal:** 도서 분실을 방지하기 위해 등록·검색을 시스템으로 관리한다.
    - **Actor:** 사서
      - **Impact:** 도서를 시스템에 등록하여 자산 현황을 파악한다.
        - **Deliverable:** 도서 등록 화면
    - **Actor:** 회원
      - **Impact:** 시스템에서 도서를 검색하여 원하는 책을 찾는다.
        - **Deliverable:** 도서 검색 화면

  ## USM Backbone

  ### Activity 1. 도서 관리

  #### [ ] Task 1.1 도서 등록

  **의존성:** 없음

  **경계:**

  - 도서 표지 이미지 업로드는 이 Task에서 다루지 않음

  **근거:**

  - Impact Mapping Deliverable: "도서 등록 화면"
  - 사용자 답변: "사서가 도서를 직접 등록한다"

  **Stories:**

  ##### Story 1.1.1 도서 정보 등록

  - 사서가 도서명·저자·ISBN을 입력하여 도서를 등록한다. (근거: Impact Mapping Deliverable "도서 등록 화면")

  ##### Story 1.1.2 필수값 누락 차단

  - 도서명·저자·ISBN 중 하나라도 누락되면 등록되지 않고 사서에게 누락 항목이 표시된다. (근거: 사용자 답변 "필수 항목 누락 시 차단")

  #### [ ] Task 1.2 도서 검색

  **의존성:** 1.1

  **경계:**

  - 정렬·필터 기능은 이 Task에서 다루지 않음

  **근거:**

  - Impact Mapping Deliverable: "도서 검색 화면"
  - 사용자 답변: "회원이 도서명으로 검색한다"

  **Stories:**

  ##### Story 1.2.1 도서명 검색

  - 회원이 도서명을 입력하여 도서를 검색한다. (근거: Impact Mapping Deliverable "도서 검색 화면")

  ##### Story 1.2.2 빈 결과 표시

  - 검색 결과가 없으면 회원에게 빈 결과 안내 메시지가 표시된다. (근거: 사용자 답변 "빈 결과는 안내 메시지 표시")

  ## 제외 사항

  - 도서 표지 이미지 업로드 — 사유: 사용자 명시적 제외 / 출처: 사용자 답변 / 재검토 조건: 별도 UX 요구 시
  - 도서 대출/반납 — 사유: 범위 초과 / 출처: 사용자 답변 / 재검토 조건: Phase 2

  ## 의존성 매트릭스

  | Task | 의존 대상 |
  |------|----------|
  | 1.1  | 없음     |
  | 1.2  | 1.1      |
  ````

- 입력: "/sd-sit-plan .tasks/library/wbs.md"

- 성공 행동:
  - [ ] 산출 SIT 문서가 wbs.md와 같은 디렉토리(`.tasks/library/`)에 `sit.md` 파일명으로 신규 생성된다.
  - [ ] sit.md 본문에 `## 흐름 N. {이름}` 형식의 흐름 그룹 헤더가 1개 이상 등장한다 (예: `## 흐름 1. 도서 등록 사이클`, `## 흐름 2. 도서 검색 사이클` — 합쳐서 1개로 묶이는 것도 허용).
  - [ ] 모든 검증 항목이 `- [ ] {항목명}` 마크다운 체크박스 형식으로 작성된다.
  - [ ] wbs.md의 모든 Story(1.1.1·1.1.2·1.2.1·1.2.2)가 sit.md 흐름 그룹 안 항목으로 빠짐없이 반영된다.
  - [ ] WBS의 정량/열거 정보(도서명·저자·ISBN 필수, 누락 항목 표시, 빈 결과 안내 메시지)가 SIT 항목 본문에 의역 변형 없이 반영된다.
  - [ ] 흐름 안 검증 항목 본문에 앞 단계 입력·결과 맥락이 포함된다 (예: "도서명·저자·ISBN 입력 후 등록 → 등록 성공 안내 (앞 단계: 등록 메뉴 진입)" 등).
  - [ ] sit.md 본문에 `## 기반 데이터` 섹션과 `### {그룹명} ({적재 방식})` 형식의 하위 그룹 헤더가 1개 이상 등장한다.
  - [ ] run-output.json의 응답 흐름에 Step 5 격리 검증을 Agent tool 호출로 수행한 흔적(검증 보고서 인용 또는 검증 결과 반영 처리)이 등장한다.

- 보조 assertion:
  - [ ] `.tasks/library/sit.md` 경로에 파일이 실재한다.
  - [ ] `tests/sit/` 디렉토리가 새로 생성되지 않는다.
  - [ ] sit.md 본문에 `## Task 1.1`·`## Task 1.2`·`### Story 1.1.1` 등 Task/Story 식별자를 그대로 그룹 헤더로 쓴 흔적이 등장하지 않는다 (식별자 본문 인용은 허용).
  - [ ] sit.md 본문에 입력 범위 외 항목(예: 도서 대출/반납·도서 표지 이미지 — 제외 사항)이 SIT 체크박스로 등장하지 않는다.

- Judge rubric:
  - PASS: wbs.md 디렉토리에 sit.md가 생성되고, 흐름 그룹 헤더(`## 흐름 N.`) + 체크박스 형식이 모두 충족된다. 모든 Story가 흐름 항목으로 반영되며 정량/열거 정보가 의역 변형 없이 유지되고, 항목 본문에 앞 단계 맥락이 포함된다. `## 기반 데이터` 섹션이 등장하고 Task/Story 식별자를 그룹 헤더로 쓴 흔적이 없다. tests/sit/ 등 다른 경로에 산출물이 생기지 않으며, 제외 사항이 SIT 항목으로 혼입되지 않는다.
  - FAIL: 출력 위치 위반(`tests/sit/` 등), 체크박스 형식 위반(`* `, `1.`, `[ ]` 단독 등), 흐름 그룹 헤더 누락(평면 체크리스트), Task/Story 식별자를 그룹 헤더로 사용, Story 1건 이상 sit 항목 누락, 정량/열거 정보 의역 변형(예: "도서명·저자·ISBN"→"필수 항목들"), 항목 본문에 앞 단계 맥락 누락(단독 검증 단위 박힘), `## 기반 데이터` 섹션 누락, 제외 사항(대출/반납·표지 업로드) 혼입 중 하나라도 해당.

## 안티패턴 Eval

모든 시나리오에 공통으로 적용된다.

- [ ] 출력 경로 위반 금지 — `tests/sit/`, `packages/**/sit/` 등 결정된 경로(입력 wbs.md 디렉토리에 합류 또는 `.tasks/{timestamp}_{topic}/sit.md`) 외부에 SIT 문서를 생성하지 않는다.
- [ ] 체크박스 형식 위반 금지 — 모든 검증 항목은 `- [ ] {항목명}` 마크다운 체크박스 형식으로 작성된다. `* `, `1.`, `- ` 단독, 체크박스 누락은 위반.
- [ ] 흐름 그룹핑 위반 금지 — sit.md 본문은 `## 흐름 N. {이름}` 형식의 흐름 그룹 헤더로 묶인다. 평면 체크리스트(그룹 없이 항목 나열) 또는 Task/Story 식별자를 그룹 헤더로 쓰는 것은 위반.
- [ ] 단독 검증 단위 박힘 금지 — 흐름 안 검증 항목은 본문에 앞 단계 입력·결과 맥락을 포함한다. 앞뒤 시나리오 맥락 없이 단독 검증 단위(예: "매트릭스 D8 셀 X 표시")로 떠 있는 항목은 위반.
- [ ] 임의 항목 추가 금지 — 최종 sit.md 본문에 입력 wbs.md 범위를 벗어난 항목(가짜 비즈니스 규칙·실재 안 함 화면 동작·wbs 제외 사항)이 잔존하지 않는다 (Step 5 격리 검증을 통해 검출·제거된 항목은 위반에 해당하지 않는다).
- [ ] 정량/열거 정보 의역 변형 금지 — 입력에 등장한 수치·열거값(예: "도서명·저자·ISBN")이 SIT 항목에서 추상화·축약되지 않는다 (예: "필수 항목들" 금지).
