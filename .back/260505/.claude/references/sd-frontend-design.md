# sd-frontend-design: 프론트엔드 디자인 일반 규칙

프론트엔드 UI 코드(HTML 템플릿, SCSS, 컴포넌트 구성) 작성·수정 시 적용한다.
라이브러리별 `README.md` 규칙이 본 문서보다 우선한다.

## 기존 패턴 우선

기존 페이지의 다음 패턴을 파악해 따른다.

- 레이아웃 구성 (Topbar, Sidebar, View 조합)
- 색상·테마 사용 방식
- 간격·여백 패턴
- 폼 컴포넌트 배치·스타일
- 반응형 처리

## 스타일링 수단 우선순위

상위 수단으로 해결 가능하면 하위 수단을 사용하지 않는다.

1. `component`: 패키지가 제공하는 컴포넌트 자체로 해결
2. `attribute`: 컴포넌트 input, 디렉티브 속성으로 해결
3. `class`: 유틸리티 클래스로 해결
4. `style`: 인라인 스타일, CSS 변수 직접 지정

## 일관성 체크리스트

- 같은 목적의 UI 요소에 스타일링 수단을 혼용하지 않는다
- 색상·간격·폰트 크기 등 매직넘버 대신 패키지가 제공하는 변수/클래스를 사용한다
