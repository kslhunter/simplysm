# 로컬 프로젝트 위키 (`.wiki/`)

repo 국한 + 온디맨드 지식의 전담 저장소 — 원격 위키 관문 1 에서 탈락한 지식의 공식 수신처임.

**경계 (어디에 쓰는가)**:

- 원격 공용 위키: repo 독립·영속 지식 (별도 주입되는 "무엇을 담는가" 블록의 4관문).
- 로컬 `.wiki/`: 그 repo 에서만 유효한 지식 — 내부 구조·경로·정책·합의·함정. 온디맨드로 열어 볼 지식.
- CLAUDE.md: 매 세션 상시 필요한 최소 지침만. 온디맨드로 충분한 repo 지식은 CLAUDE.md 를 불리지 말고 `.wiki/` 로 보낼 것.
- 관문 1 외 나머지 기준(판정 질문·검증됨·영속·얇게 유지)은 로컬 위키에도 동일 적용됨 — 틀린·노후 정보는 로컬에서도 없느니만 못함.

**구조 (평문 md 폴더 트리)**:

- 위치: 프로젝트 루트 `.wiki/**/*.md`. CLI 없음 — Read·Write·Glob·git 으로 직접 다룸.
- 페이지 = md 파일. frontmatter 에 `summary:`(필수 — 라우팅 요약)·`title:`(선택 — 없으면 파일명이 제목). 파일명은 짧은 슬러그로 하고, 긴 표시 제목은 `title:` 로 둘 것.
- 폴더 = hub. 폴더 요약은 폴더 안 `README.md` 의 frontmatter 임. `.wiki/` 직속 `README.md` 는 트리 자체의 hub 페이지임(루트맵 항목 아님).

**탐색**:

- 세션 시작 시 훅이 `.wiki/` 최상위 라우팅 목록(로컬 ROOT MAP)만 주입함 — 전체 목차 아님. `.wiki/` 가 없거나 비어 있으면 주입하지 않음.
- 주입 목록에서 관련 항목 식별 → 폴더면 열어(Glob + frontmatter) 더 펼치고, 파일이면 Read 로 본문을 활용할 것. 원격과 동일한 온디맨드 원리임.
- 루트맵 항목에 `(요약 없음)` 이 보이면 그 페이지를 열어 본 김에 frontmatter `summary:` 를 보충할 것.

**작성**:

- 원격과 동일하게 자동 기록 — 대상 판정(repo 국한 + 판정 질문 통과)에 맞으면 묻지 않고 기록할 것. `.wiki/` 가 없으면 만들어 기록할 것.
- 기록 전 기존 페이지를 확인할 것(Glob·Grep) — 겹치면 갱신·통합하고, 없으면 새 파일로 작성할 것.
- 요약 = 라우팅 전용(그 페이지를 언제 여는지 한 줄) — 본문 사실 복제 금지. 원격의 요약 규칙과 동일함.
- 트리 모양: 최상위 항목 수가 곧 세션 주입량 — 최상위를 작게, 커지면 폴더(hub)로 묶을 것.
