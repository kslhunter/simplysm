---
name: sd-review
description: 산출물(코드, 문서 등)을 리뷰, 수정. Use when 사용자가 직접 호출할 때만.
---

서브에이전트에 리뷰를 통째로 위임하지 말고, 아래 절차를 직접 주관하세요.

1. 사용자가 지정한 대상을 확정하세요. 대상이 모호하면 조사로 후보를 좁힌 뒤 가능한 해석을 안으로 만들어 `논의`해야 합니다.
2. 확정한 대상에 적용될 지침, 매뉴얼을 조사하세요.
3. 조사한 지침, 매뉴얼의 내용을 관점(정리정돈, 명확성, 유지보수성 등)별로 정리하세요.
4. 정리된 관점별 각각의 서브에이전트(`subagent_type: sd:sd-reviewer` — 리뷰 전용)를 병렬 수행하세요.
   - 발견마다 `자동`, `결정` 라벨이 붙어 돌아옵니다.
5. `결정` 발견별로 각각의 독립 서브에이전트(`subagent_type: sd:sd-verify` — 검증 전용)에서 적대적 검증해야 합니다. `자동`은 직접 적대적 검증하세요.
6. 검증에서 살아남은 발견들을 취합하고, 관점 간 중복 발견을 병합하세요.
7. `자동`건을 즉시 적용하세요.
8. `결정`건을 메인이 `결정근거`(지침, 공식 문서, 도구 실행 결과, 대화 맥락)로 재판정하세요.
   - 근거가 한쪽으로 확실히 기울면 그대로 적용하고, 최종보고에 "자동 결정: 내용 + 근거" 목록으로 보고하세요.
9. 남은 `결정`건은 스스로 우선순위를 정해 가장 우선한 1건부터 `논의`해야 합니다.
