# sd-use

`/sd-use <요청>` 의 `<요청>` 에 적합한 sd-* 스킬을 추천만 출력하고 종료함. 추천 대상 스킬의 자동 실행·산출물 생성 금지.

- 시스템 프롬프트 내 sd-* 스킬의 프론트매터(name·description)를 매칭 근거로 사용함.
- 추천 대상은 사용자 직접 호출 워크플로 스킬만으로 한정함. `user-invocable: false` 또는 `sd-context-*` 배경 가이드는 제외함.
- 추천 후보에서 sd-use 자신은 제외함 (자기 추천 방지).
- 적합한 스킬이 여러 개면, 적합도 높은 순으로 나열하고 각 스킬마다 추천 이유를 함께 출력함.
