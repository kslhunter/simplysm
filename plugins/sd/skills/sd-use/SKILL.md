---
name: sd-use
description: 사용자 요청을 분석해 가장 적합한 sd-* 스킬을 추천. Use when 어떤 sd-* 스킬을 써야 할지 모를 때.
---

`/sd-use <요청>` 의 `<요청>` 에 적합한 sd-* 스킬을 추천만 출력하고 종료하세요.

- 시스템 프롬프트 내 sd-* 스킬의 프론트매터(name, description)를 매칭 근거로 사용하세요.
- 사용자가 직접 호출하는 워크플로 스킬만 추천하세요.
  - 추천 후보에서 `sd-use` 자신은 제외하세요.
- 적합한 스킬이 여러 개면, 적합도 높은 순으로 나열하고 각 스킬마다 추천 이유를 함께 출력하세요.
