# sd-research

리서치 범위를 설정하고 병렬 조사·검증을 거쳐 최종 결과를 사용자에게 보고한다.

## 절차

1. 리서치 조사 범위를 설정한다.
2. 조사 범위에 따라 병렬 독립 서브에이전트로 조사를 수행한다.
3. 조사결과를 통합하여 중복을 제거하거나 의미를 병합한다.
4. 결과를 건별로 독립 서브에이전트로 검증을 수행한다.
5. 최종 답변을 작성하여, 사용자에게 보고한다.
