이 코드베이스를 분석해 CLAUDE.md 파일을 생성하세요.

무엇을 담을 것인가:
1. 빌드, 린트, 테스트 실행 방법처럼 자주 사용될 명령어. 단일 테스트 실행 방법 등 이 코드베이스에서 개발하는 데 필요한 명령어를 포함하세요.
2. 향후 인스턴스가 더 빠르게 생산성을 낼 수 있도록 하는 상위 수준의 코드 아키텍처와 구조. 여러 파일을 읽어야 이해되는 "큰 그림" 아키텍처에 집중하세요.

사용 노트:
- 이미 CLAUDE.md가 있으면 그에 대한 개선안을 제안하세요.
  - 필요한 정보를 추가하기보다 필요없는 정보를 삭제하거나 잘못된 정보나 표현을 수정하는것이 더 중요합니다.
- 쉽게 발견할 수 있는 모든 컴포넌트나 파일 구조를 나열하지 마세요.
- 일반적인 개발 관행은 넣지 마세요.
- 당신이 읽은 다른 파일에 명시적으로 담겨 있지 않은 정보를 지어내지 마세요.
