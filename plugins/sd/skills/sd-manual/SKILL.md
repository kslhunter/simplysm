# sd-manual

독자는 주로 코드 작업 중인 에이전트이며, "이걸 하려면 어떻게 하나"를 빠르게 얻는 것이 목표입니다.

두 축:

- 작업 목적 단위로 조직해야 합니다. 섹션 1개가 작업 목적 1개("~하려면 ~한다")입니다.
  - 함수, 옵션을 나열하는 레퍼런스 구조나 내부 동작을 설명하는 구조로 만들지 마세요.
- 방법이 실제 동작과 일치해야 합니다. 수행법을 대상 코드에서 직접 확정하세요.
  - 그 방법이 독자가 관찰하는 최종 결과(화면, 실제 동작)로 이어지는지 끝까지 추적해야 합니다.
  - 함수 반환값만 보고 결과를 단정하지 마세요.

## 산출물

- 활성 references 경로의 `manuals/<주제>.md`.
- 같은 경로 `README.md` 의 매뉴얼 인덱스 표에 트리거 + 링크 1행.

## 절차

1. 주제와 대상 코드 범위를 확정하고, 독자가 이 매뉴얼로 하려는 작업들을 식별하세요. 갱신이면 기존 파일을 먼저 읽어야 합니다.
2. 그 작업들을 목차로 변환하세요.
3. 각 작업의 수행법을 코드 근거 위에 확정하고 최종 결과까지 추적해야 합니다.
4. 기존 `manuals/*.md` 의 톤, 구조를 답습해 작성하세요 (목적 설명 → 작성법 + 코드 예시 → 지킬 것).
5. 신규는 README 인덱스에 1행 추가하세요. 갱신은 기존 파일, 인덱스 행을 보존한 채 변경분만 반영하고, 합의 없이 무관한 부분을 고치지 마세요.
