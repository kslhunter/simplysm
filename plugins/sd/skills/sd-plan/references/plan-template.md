## 11. Traceability 규칙

- 모든 `SCOPE` 는 최소 1개 `TASK` 와 연결해야 합니다.
- 모든 `IMPACT` 는 그 영향을 처리하는 `TASK` 를 최소 1개 가져야 합니다.
- 모든 `TASK` 는 최소 1개 근거(`FIND`/`DEC`/`SCOPE`)와 연결해야 합니다.
- 모든 `TASK` 는 최소 1개 `AC` 와 1개 검증 방법(`TEST` 또는 `GATE`)을 가져야 합니다.
- 모든 `TASK` 는 완료 시 소비자가 쓸 수 있는 동작 1개를 남겨야 합니다 (여러 slice 공유 기반의 선행 TASK 만 예외).
- 연결되지 않은 작업은 삭제하거나 근거를 추가하세요.
