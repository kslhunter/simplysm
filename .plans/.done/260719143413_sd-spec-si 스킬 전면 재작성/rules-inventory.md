# 현행 규칙 전수 목록 (재작성 대조 기준)

TASK-001 산출물. `plugins/sd/skills/sd-spec-si/` 3파일의 모든 규칙을 원자 단위로 추출함. TASK-002-004 재작성 후 GATE-002 에서 이 목록과 1:1 대조함.

## 범례

- **성격**: `절차`(언제 무엇을) / `명세`(무엇을 쓰나) / `판단-전반`(연산 전반 가르기) / `판단-국소`(특정 카테고리 안에서 가르기) / `메타`(문서 자신에 대한 규정).
- **목적지**: `SKILL`(절차 + 판단-전반) / `format`(명세 + 판단-국소) / `example`(형식 실현) / `폐기`.
- **비고 마커**: `[§]` = § 번호 지칭에 의존해 표현이 바뀔 대상 (DEC-002). `[중복]` = 같은 내용이 2곳 이상. `[폐기후보]` = ASM-001 점검 결과. `[고유]` = 한 곳에만 있어 소실 위험 (RISK-001).
- 목적지 판정 기준: 성격이 명세, 판단-국소면 format, 절차, 판단-전반이면 SKILL. 이 기준을 예외 없이 적용했으므로 현행 SKILL.md 에 있던 산출물 명세(파일 배치, 섹션 구조, 신뢰도 표기, 골격, 결정 맥락/작업 메모 작성법)는 전부 format 목적지로 배정함.
