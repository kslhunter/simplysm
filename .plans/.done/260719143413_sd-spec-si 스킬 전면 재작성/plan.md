## 1. 목표, 문제, 완료 정의

- 목표: sd-spec-si 스킬 3파일을 전면 재작성해, 규칙의 적용 범위가 읽는 즉시 판별되는 구조로 만든다.
- 해결할 문제: 규칙 성격 3종(절차 / 산출물 명세 / 판단 규칙)이 두 파일에 성격과 무관하게 섞여 배치돼, 읽는 LLM 이 각 규칙이 어디까지 적용되는지 추측해야 한다. 실제로 선행 세션에서 리뷰어와 메인 에이전트가 동일한 오해를 했다(파일 배치 규칙을 실행 모드 규칙으로 오독 — §3 FIND-001).
- 완료 정의:
  - 3파일 재작성 완료 + 파일명 `example-spec.md` → `example.md` 변경.
  - `SKILL.md` 500줄 이하.
  - 현행 규칙이 재작성본에 누락 없이 이관됨(격리 서브에이전트 전수 대조로 확인 — GATE-002).
  - 재작성본만 읽은 독립 서브에이전트가 요건 단계 산출물을 형식대로 생성함(GATE-003).
- 성공 시 관찰 가능한 변화: 임의의 규칙 1건을 집었을 때 그것이 절차인지 산출물 명세인지 판단 규칙인지가 소속 파일로 즉시 결정된다. `§4.x`, `§4-6`, `§8, §9 불변식` 같은 번호 지칭이 문서에서 사라진다.
