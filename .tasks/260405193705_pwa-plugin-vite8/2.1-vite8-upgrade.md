## 구현계획

### 배경

`packages/sd-cli`에서 Vite를 라이브러리로 사용하여 Angular/Solid 클라이언트 앱을 빌드한다. `createClientViteConfig()` (`vite-config.ts`)가 Vite `InlineConfig`를 생성하고, `client.worker.ts`에서 `createServer()` / `viteBuild()`로 실행한다. Angular AOT 컴파일은 `sdAngularPlugin` (`vite-angular-plugin.ts`)이 Vite 플러그인으로 처리한다.

Vite 8의 핵심 변경은 Rolldown이 esbuild + Rollup을 대체한 것이다. 이에 따라:
- `esbuild` config → `oxc` config [근거: Vite 8 migration]
- `build.rollupOptions` → `build.rolldownOptions` [근거: Vite 8 migration]
- `optimizeDeps.esbuildOptions` → `optimizeDeps.rolldownOptions` (esbuild 플러그인 → Rolldown 플러그인) [근거: Vite 8 migration]
- `handleHotUpdate` → `hotUpdate` (deprecated, 향후 메이저에서 제거 예정) [근거: Vite 8 migration]

### 목표

- Vite ^8.0.0 호환 (`InlineConfig` 생성, dev server, production build) [근거: wbs "Vite 8 업그레이드"]
- esbuild/Rollup API → oxc/Rolldown API 마이그레이션 [근거: Rule "oxc/rolldownOptions 마이그레이션"]
- Angular linker disk cache를 Rolldown 플러그인으로 변환 [근거: Rule "Angular linker Rolldown 플러그인"]
- legacyModule import.meta 안전망 유지 [근거: D1]
- handleHotUpdate deprecated 경고 제거 [근거: Rule "hotUpdate 마이그레이션"]

### 비목표

- Node.js 버전 업그레이드 [근거: wbs 경계]
- Vite 8 신규 기능 활용 [근거: wbs 경계]

(c) `optimizeDeps.esbuildOptions` 제거:

(d) `esbuild.supported` → renderChunk 플러그인:
```typescript

// After — 기존 sd-legacy-strip-dynamic-import 아래에 추가
{
  name: "sd-legacy-strip-import-meta",
  enforce: "post",
  renderChunk(code) {
    if (!code.includes("import.meta")) return null;
    return {
      code: code.replace(/\bimport\.meta/g, "(void 0)"),
      map: null,
    };
  },
}
```

**3. `packages/sd-cli/src/angular/vite-angular-plugin.ts`** [근거: Rule "Angular linker Rolldown", "hotUpdate"]

(a) `config()` 훅 — optimizeDeps 플러그인 변환 (line 148-188):

esbuild plugin → Rolldown plugin (Rollup-style `load` hook):
```typescript
// Before
optimizeDeps: {
  esbuildOptions: {
    plugins: [{
      name: "angular-vite-optimize-deps",
      setup(build) { build.onLoad({ filter: /\.[cm]?js$/ }, async (args) => { ... }) },
    }],
  },
},

// After
optimizeDeps: {
  rolldownOptions: {
    plugins: [{
      name: "angular-vite-optimize-deps",
      async load(id) {
        if (!/\.[cm]?js$/.test(id)) return null;
        const content = await fsp.readFile(id, "utf-8");
        const hash = createHash("sha256").update(content).digest("hex");
        const cachePath = path.join(linkerCacheDir, `${hash}.js`);
        try {
          return await fsp.readFile(cachePath, "utf-8");
        } catch { /* cache miss */ }
        const result = await prebundleTransformer.transformFile(id);
        const resultStr = typeof result === "string" ? result : new TextDecoder().decode(result);
        try {
          await fsp.mkdir(linkerCacheDir, { recursive: true });
          await fsp.writeFile(cachePath, resultStr);
        } catch { /* non-fatal */ }
        return resultStr;
      },
    }],
  },
},
```

(b) `handleHotUpdate` → `hotUpdate` (line 288-407):

- 훅 이름 변경: `handleHotUpdate` → `hotUpdate`
- 파라미터: destructured `{ file, modules, server }` → `hotUpdate` 옵션 객체
- `server.moduleGraph` → `this.environment.moduleGraph`

### 대안 검토

| 대안 | 선택하지 않은 이유 |
|------|-------------------|
| `esbuild` / `rollupOptions` deprecated 유지 (auto-convert) | 자동 변환은 deprecation 경고 발생. 다음 메이저에서 제거 예정이므로 지금 마이그레이션이 적절 |
| optimizeDeps.rolldownOptions에 target 설정 | Rolldown은 esbuildOptions.target과 동일한 형식 미지원. oxc.target + build.target으로 충분 |
| import.meta 치환 대신 Chrome 64+ 요구 | Chrome 61+ 호환 요구사항 변경은 범위 초과 |
| handleHotUpdate 유지 (deprecated) | deprecated 경고가 dev 서버 실행마다 발생. 사용자 경험 저하 |
