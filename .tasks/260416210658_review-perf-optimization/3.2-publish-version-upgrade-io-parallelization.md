## 구현계획

### 배경

`version-upgrade.ts`는 publish 커맨드에서 호출되는 유틸리티로, 두 개의 함수(`upgradeVersion`, `computePublishLevels`)를 export한다. 두 함수 모두 독립 파일에 대한 순차 I/O 루프를 포함하며, `Promise.all` 병렬화가 가능하다. [근거: PERF-006]

### 목표
- `upgradeVersion`의 패키지/템플릿 순차 I/O를 병렬화하여 패키지 수에 비례한 지연 제거 [근거: Rule "패키지별 독립"]
- `computePublishLevels`의 depsMap 구축 순차 I/O를 병렬화 [근거: Rule "depsMap 독립 구축"]

### 비목표
- 위상 정렬 로직 변경 [근거: wbs 경계]
- 프로젝트 루트 package.json 처리 방식 변경 [근거: wbs 경계]

### 설계

**`upgradeVersion` 패키지 루프 (`version-upgrade.ts:50-56`):**

현재:
```typescript
for (const pkgPath of allPkgPaths) {
  const pkgJsonPath = path.resolve(pkgPath, "package.json");
  const pkgJson = await fsx.readJson<PackageJson>(pkgJsonPath);
  pkgJson.version = newVersion;
  await fsx.write(pkgJsonPath, json.stringify(pkgJson, { space: 2 }) + "\n");
  changedFiles.push(pkgJsonPath);
}
```

변경 후:
```typescript
const pkgChangedFiles = await Promise.all(
  allPkgPaths.map(async (pkgPath) => {
    const pkgJsonPath = path.resolve(pkgPath, "package.json");
    const pkgJson = await fsx.readJson<PackageJson>(pkgJsonPath);
    pkgJson.version = newVersion;
    await fsx.write(pkgJsonPath, json.stringify(pkgJson, { space: 2 }) + "\n");
    return pkgJsonPath;
  }),
);
changedFiles.push(...pkgChangedFiles);
```

**`upgradeVersion` 템플릿 루프 (`version-upgrade.ts:62-70`):**

현재:
```typescript
for (const templatePath of templateFiles) {
  const content = await fsx.read(templatePath);
  const newContent = content.replace(versionRegex, `$1"~${newVersion}"`);
  if (content !== newContent) {
    await fsx.write(templatePath, newContent);
    changedFiles.push(templatePath);
  }
}
```

변경 후:
```typescript
const templateChangedFiles = await Promise.all(
  templateFiles.map(async (templatePath) => {
    const content = await fsx.read(templatePath);
    const newContent = content.replace(versionRegex, `$1"~${newVersion}"`);
    if (content !== newContent) {
      await fsx.write(templatePath, newContent);
      return templatePath;
    }
    return undefined;
  }),
);
changedFiles.push(...templateChangedFiles.filter((f) => f != null));
```

**`computePublishLevels` depsMap 구축 (`version-upgrade.ts:86-101`):**

현재:
```typescript
const depsMap = new Map<string, Set<string>>();
for (const pkg of publishPkgs) {
  const pkgJson = await fsx.readJson<PackageJson>(path.resolve(pkg.path, "package.json"));
  const allDeps = { ...pkgJson.dependencies, ...pkgJson.peerDependencies, ...pkgJson.optionalDependencies };
  const workspaceDeps = new Set<string>();
  for (const depName of Object.keys(allDeps)) {
    const shortName = depName.replace(/^@simplysm\//, "");
    if (shortName !== depName && pkgNames.has(shortName)) {
      workspaceDeps.add(shortName);
    }
  }
  depsMap.set(pkg.name, workspaceDeps);
}
```

변경 후:
```typescript
const depsEntries = await Promise.all(
  publishPkgs.map(async (pkg) => {
    const pkgJson = await fsx.readJson<PackageJson>(path.resolve(pkg.path, "package.json"));
    const allDeps = { ...pkgJson.dependencies, ...pkgJson.peerDependencies, ...pkgJson.optionalDependencies };
    const workspaceDeps = new Set<string>();
    for (const depName of Object.keys(allDeps)) {
      const shortName = depName.replace(/^@simplysm\//, "");
      if (shortName !== depName && pkgNames.has(shortName)) {
        workspaceDeps.add(shortName);
      }
    }
    return [pkg.name, workspaceDeps] as const;
  }),

const depsMap = new Map(depsEntries);
```

### 대안 검토
| 접근 방식 | 장점 | 단점 | 비채택 사유 |
|-----------|------|------|-------------|
| `for...of` 유지 (현행) | 변경 없음 | 순차 I/O 지연 유지 | 최적화 목적과 불부합 |
| `Promise.allSettled` | 부분 실패 허용 | 불필요한 복잡성, 현재도 첫 에러에서 중단 | 에러 동작 변경 불필요 |

### Vertical Slicing

#### [x] Slice 1: `upgradeVersion` I/O 병렬화
- **구현 내용:** 패키지별 package.json 루프와 템플릿 파일 루프를 `Promise.all` 병렬화. `changedFiles` 반환 시 루트가 첫 항목이 되도록 순서 유지.
- **Scenarios:** 복수 패키지 병렬 업데이트, 패키지 없음, 복수 템플릿 병렬 업데이트, 템플릿 없음, changedFiles 첫 항목이 루트

#### [x] Slice 2: `computePublishLevels` I/O 병렬화
- **의존:** 없음 (Slice 1과 독립)
- **구현 내용:** depsMap 구축 루프를 `Promise.all` 병렬화. 위상 정렬 로직 변경 없음.
- **Scenarios:** 의존 관계가 있는 패키지들의 레벨 계산
