# Feature 2.1 createBrowserWorker 래퍼 제거 — LLM 검증

## 검증 항목

- [x] Worker 생성 시 표준 패턴 사용: `client-protocol-wrapper.ts:47-50`에서 `new Worker(new URL("../workers/client-protocol.worker.js", import.meta.url), { type: "module" })` 패턴 확인. `createBrowserWorker` 래퍼 미사용.
- [x] Worker URL이 .js 확장자 사용: `client-protocol-wrapper.ts:48`에서 `client-protocol.worker.js` 확인. `.ts`에서 `.js`로 정상 변경됨.
- [x] Worker 에러 핸들러 유지: `client-protocol-wrapper.ts:73-86`에서 `worker.onerror` 핸들러 존재 확인. 대기 중인 요청 reject + fallback 로직 유지.
- [x] browser-compat.ts 래퍼 코드 제거: `createBrowserWorker` 함수 제거됨, `WorkerLike` 인터페이스 제거됨. `isWorkerSupported` 함수(22-24행), `BlobInput` 타입(8행), `FileCollection` 인터페이스(14-19행) 유지 확인.
- [x] import 정리: `client-protocol-wrapper.ts:8`에서 `WorkerLike` type import 및 `createBrowserWorker` import 제거됨. `isWorkerSupported`만 import.
- [x] worker 변수 타입: `client-protocol-wrapper.ts:17`에서 `let worker: Worker | undefined` 확인. DOM Worker 타입 직접 사용.
- [x] getWorker() 반환 타입: `client-protocol-wrapper.ts:39`에서 `function getWorker(): Worker | undefined` 확인.
- [x] null 체크 제거: `createBrowserWorker` 후 `if (worker == null) return undefined;` 라인 제거됨. `new Worker()`는 항상 인스턴스 반환.
