## 구현계획

### 배경

`@simplysm/angular` 패키지의 `features/data-view/` 디렉토리에 3개의 추상 클래스가 존재한다. 각 추상 클래스는 companion 컴포넌트와 **동일 파일에 co-located** 되어 있다:

| 추상 클래스 | 현재 파일 | companion 컴포넌트 |
|---|---|---|
| `AbsSdDataSheet` (L69-336) | `sd-data-sheet.ts` | `SdDataSheet` (L340+) |
| `AbsSdDataDetail` (L49-208) | `sd-data-detail.ts` | `SdDataDetail` (L212+) |
| `AbsSdDataSelectButton` (L39-122) | `sd-data-select-button.ts` | `SdDataSelectButton` (L126+) |

### 목표

- 3개 추상 클래스를 `Abs` prefix → `Base` 접미사로 변경 [근거: CLAUDE.md Naming Conventions]
- 추상 클래스를 `*.base.ts` 파일로 분리 [근거: CLAUDE.md 파일명 규칙]
- 모든 내부 참조(import, injectParent, extends, 주석, 테스트) 업데이트 [근거: WBS 범위]

### 비목표

- 추상 클래스 내부의 메서드/프로퍼티 시그니처 변경 [근거: WBS 경계]
- CLAUDE.md 문서 업데이트 [근거: Feature 1.6 범위]
- usage 문서 업데이트 [근거: Feature 1.6 범위]

### 설계

각 추상 클래스에 대해 동일한 패턴으로 처리:

1. **새 `*.base.ts` 파일 생성**: 추상 클래스 코드 + 필요한 import 추출, 클래스명 변경
2. **기존 파일 수정**: 추상 클래스 코드 제거, 새 파일에서 import + re-export (내부 참조 호환)
3. **`index.ts` 수정**: export 경로를 새 파일로 변경
4. **내부 참조 업데이트**: `injectParent<>()` 타입 파라미터, extends 구문, import 경로
5. **테스트 업데이트**: fixture import, describe 텍스트
