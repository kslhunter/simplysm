## 구현계획

### 배경

Feature 1.1~1.5에서 코드의 모든 심볼명이 변경되었으나, 3개 문서 그룹의 심볼명은 아직 옛 이름을 사용하고 있다. 문서와 코드의 불일치를 해소해야 한다.

### 목표
- 모든 문서의 심볼명이 `index.ts` export와 일치하도록 치환 [근거: Rule "심볼명은 index.ts와 일치"]
- selector/alias 참조도 실제 코드와 일치하도록 업데이트 [근거: Rule "selector/alias도 현재 코드와 일치"]
- 교차 참조 타입도 누락 없이 업데이트 [근거: Rule "코드 블록 내 타입 참조도 새 이름으로"]

### 비목표
- 문서 구조/섹션 재편 [근거: wbs 경계 "문서의 구조/섹션 재편은 하지 않음"]
- 이미 업데이트된 Naming Conventions, Key Patterns/Composable 섹션 재수정

### 설계

각 문서 파일에 대해 위 "심볼명 매핑" 테이블의 옛 이름 → 새 이름을 적용한다.
- 코드 블록 내 class/interface/type 선언문, 타입 참조, selector, alias, 사용법 예시 모두 포함
- 제목(## `SdButtonControl`)도 포함
- 설명 텍스트 내 인라인 참조(`` `SdButtonControl` ``)도 포함

### 대안 검토

자동화 스크립트(sed/awk) 대안: 문서 내 컨텍스트에 따라 치환이 달라지는 경우(예: `ISdModal` → `SdModalContentDef` vs `SdModal` 컴포넌트)가 있어 수동 편집이 더 안전하다.
