# Feature 1.5 Composable 함수 use* → inject* 변환

## 참조 자료
- WBS: [wbs.md](./wbs.md)
- 합의된 네이밍 규칙: `packages/angular/CLAUDE.md` — Naming Conventions > Composable 함수
- 코드 분석: 21개 `use*` 함수 중 12개가 `inject()` 사용, 9개는 미사용

### 설계 결정
| # | 결정사항 | 선택 | 근거 |
|---|---|---|---|
| D1 | inject() 미사용 9개 use* 함수 처리 | `use*` prefix 유지 | 3-prefix 체계(inject/setup/use)로 역할 명확 구분. inject=DI의존, setup=부수효과설치, use=순수유틸리티. `setup*`으로 변경 시 기존 setup 함수(부수효과 패턴)와 성격 불일치 |
| D2 | CLAUDE.md 컨벤션 테이블 업데이트 | `use*` 카테고리 추가 | 기존 테이블에 inject/setup만 있어 use* 누락. 3-prefix 체계 명시 필요 |

## 요구명세

```gherkin

  Rule: index.ts export 업데이트
    # 근거: WBS 범위
    Scenario: Public API export 이름 변경
      Given 6개 함수(5개 core/utils + 1개 core/providers)가 index.ts에서 export됨
      When 함수명이 inject*로 변경됨
      Then index.ts의 export 문이 새 함수명과 새 파일 경로로 업데이트됨

  Rule: CLAUDE.md 컨벤션 테이블 업데이트
    # 근거: 설계 결정 D2

      When use* 카테고리를 추가하고 기존 예시를 실제 코드에 맞게 수정
```

## 구현계획

### 배경
angular 패키지의 `src/core/utils/`, `src/core/providers/`, `src/features/data-view/`, `src/ui/data/sheet/`에 걸쳐 21개 `use*` composable 함수가 존재한다. 이 중 12개가 Angular `inject()`를 사용하며, 합의된 네이밍 규칙에 따라 `inject*` prefix로 rename한다. [근거: CLAUDE.md Naming Conventions]

### 목표
- DI 사용 `use*` 함수 12개를 `inject*`로 함수명/파일명 rename [근거: Rule "DI 사용 함수는 inject* prefix"]
- 패키지 내부 모든 import 경로 및 호출부 업데이트 [근거: Rule "index.ts export 업데이트"]
- CLAUDE.md 컨벤션 테이블에 3-prefix 체계 반영 [근거: Rule "CLAUDE.md 컨벤션 테이블 업데이트"]

### 비목표
- DI 미사용 9개 `use*` 함수 변경 [근거: 설계 결정 D1]
- 기존 `setup*` 함수 변경 [근거: WBS 경계]
- `withBusy`, `injectParent`, `setSafeStyle`, `mark` 등 기타 유틸 함수 변경 [근거: WBS 경계]
- usage.md 등 참조 문서 업데이트 [근거: Feature 1.6 범위]

### 대안 검토

**전체 21개를 inject*로 rename** — CLAUDE.md 예시와 일치하나, inject() 미사용 함수에 inject prefix는 의미적 오해 유발. 기각. [근거: 설계 결정 D1]

**비DI 함수를 setup*로 rename** — 컨벤션 테이블 문면과 일치하나, 기존 setup* 함수(부수효과 설치 패턴)와 성격이 다른 순수 유틸리티가 같은 prefix를 공유. 기각. [근거: 설계 결정 D1]
