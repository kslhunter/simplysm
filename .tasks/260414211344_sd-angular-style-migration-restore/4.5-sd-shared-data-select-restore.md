## 구현계획

### 배경

v14 마이그레이션에서 `sd-select`의 `trackByFn` input이 누락되었다. v14는 `_flatItems()` computed로 래퍼 객체를 생성하고 `track item`으로 추적하는데, 래퍼가 매번 새로 생성되므로 items 변경 시 모든 DOM이 재생성된다. `sd-sheet`(`sd-sheet.ts:561`)에는 이미 `trackByFn`이 존재하므로 동일 패턴을 적용한다.

### 목표

- `sd-select`에 `trackByFn` input 추가로 DOM 재사용 지원 복원 [근거: Rule "sd-select는 trackByFn input을 제공해야 한다"]
- `sd-shared-data-select`에서 `__valueKey` 기반 추적을 전달하여 v12 동작 복원 [근거: Rule "sd-shared-data-select는 trackByFn으로 __valueKey 기반 추적을 전달한다"]

### 비목표

- `sd-select`의 `_flatItems` 래퍼 구조 변경 [근거: wbs 경계 "v14 개선이므로 유지"]
- value/open 바인딩 방식 변경 [근거: wbs 경계 "signal 전환은 v14 개선이므로 유지"]

### 설계

**sd-select 변경** (`packages/angular/src/controls/select/sd-select.ts`):
- input 추가: `trackByFn = input<(item: T, index: number) => unknown>((item) => item);`
  - v12 시그니처: `sd-select.control.ts:299`
  - v14 sd-sheet 패턴: `sd-sheet.ts:561`
- 템플릿 변경 (line 86): `track item` → `track trackByFn()(item.data, item.index)`
  - v14 래퍼 구조 `{ data, index, depth }` 적용

**sd-shared-data-select 변경** (`packages/angular/src/data/shared-data/sd-shared-data-select.ts`):
- 프로퍼티 추가: `trackByFn = (item: TItem): TItem["__valueKey"] => item.__valueKey;`
  - 근거: v12 `sd-shared-data-select.control.ts:169`
- 템플릿 바인딩 추가 (line 55 `<sd-select>` 태그): `[trackByFn]="trackByFn"`
  - 근거: v12 `sd-shared-data-select.control.ts:54`

### 대안 검토

`sd-select`의 `_flatItems` computed에서 래퍼 객체를 캐싱하여 참조 안정성을 확보하는 방안을 고려했으나, v12와 v14 `sd-sheet` 모두 `trackByFn` input 방식을 사용하므로 일관성을 위해 동일 패턴을 적용한다.
