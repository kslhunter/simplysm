### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---|---|---|
| D1 | data-sd-type 바인딩 소스 | `type()` (v12 방식) | `controlType()`은 number→"text", year→"text"로 변환되어 SCSS 셀렉터(`[data-sd-type="number"]`, `[data-sd-type="year"]`) 미매칭. v12에서도 "datetime-local" 셀렉터는 미매칭이었으므로 동일 |
| D2 | controlValueText 표시 패턴 | `controlValueText() ? controlValueText() : " "` (v12 방식) | v14의 `?? controlValue()` 폴백과 실질 차이는 미미하나, v12 패턴 일관성 유지 |
| D3 | controlValueText computed 폴백 | computed에 `?? this.controlValue()` 폴백 추가 | v14의 toDisplayText()가 text/date 등에서 undefined를 반환하므로, 템플릿 변경만으로는 readonly 필드에서 값 대신 공백이 표시됨. v12 동작 완전 복원을 위해 computed도 변경 |

## 구현계획

### 배경

`sd-textfield.ts`는 v12→v14 마이그레이션에서 `textfieldTypeHandlers` 패턴으로 리팩토링되었다. 이 과정에서 템플릿의 표시 로직과 호스트 속성 바인딩 소스가 변경되어 CSS 셀렉터 매칭과 표시 패턴이 v12와 달라졌다.

### 목표

- `controlValueText` 표시 표현식을 v12 패턴으로 복원 [근거: Rule "controlValueText 표시 시 v12 패턴 사용"]
- `data-sd-type` 호스트 속성이 `type()` (사용자 지정 타입)을 바인딩하도록 복원 [근거: Rule "data-sd-type은 사용자 지정 type() 값을 바인딩"]

### 비목표

- `_contents` class 바인딩 방식 변경 (v14 개선) [근거: wbs 경계]
- SCSS 경로 변경, 주석 정리 [근거: wbs 경계]
- `textfieldTypeHandlers` 리팩토링 구조 [근거: wbs 경계]

### 설계

대상 파일: `packages/angular/src/controls/input/sd-textfield.ts`

**변경 1 — 템플릿 (line 33):**
```
// Before (v14)
<pre>{{ controlValueText() ?? controlValue() }} </pre>

// After (v12 패턴 복원)
<pre>{{ controlValueText() ? controlValueText() : " " }}</pre>
```

**변경 2 — 호스트 바인딩 (line 277):**
```
// Before (v14)
"[attr.data-sd-type]": "controlType()"

// After (v12 패턴 복원)
"[attr.data-sd-type]": "type()"
```

### 대안 검토

**`controlType()` 유지 + SCSS 셀렉터 수정안:**
controlType()은 number→"text", year→"text"로 변환하므로 SCSS에서 number/year 구분이 불가. 이 접근은 불가.
