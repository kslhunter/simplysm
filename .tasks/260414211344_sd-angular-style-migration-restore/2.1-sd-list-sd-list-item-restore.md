## 구현계획

### 배경

sd-list와 sd-list-item은 v14 마이그레이션 과정에서 CSS 스타일과 템플릿 구조가 v12와 달라진 부분이 있다. 로직 변경 없이 CSS/템플릿만 v12에 맞춰 복원한다. [근거: WBS "Angular API 전환에 따른 올바른 개선을 제외한 변경/누락 복원"]

### 목표

- sd-list 호스트를 flex column으로 복원 [근거: Rule "sd-list display 모드"]
- sd-list-item `._content` 내부 레이아웃을 v12 기준으로 복원 (gap, align-items, flex) [근거: Rule "_content 내부 레이아웃"]
- sd-collapse-icon을 `._content` 마지막으로 이동 [근거: Rule "sd-collapse-icon 배치 순서"]
- hover 스타일을 accordion 전용 + 모바일 투명 + readonly 제외로 복원 [근거: Rule "hover 스타일 범위"]
- `data-sd-open` 호스트 속성 복원 [근거: Rule "data-sd-open 호스트 속성"]
- flat 레이아웃 스타일 복원 [근거: Rule "flat 레이아웃 스타일"]

### 비목표

- `setupRipple()` 함수 전환 복원 — v14 개선이므로 유지 [근거: WBS 경계]
- `keydown.enter` 접근성 이벤트 제거 — v14 개선이므로 유지 [근거: WBS 경계]
- `_tool` 클래스 제거 — v14 개선이므로 유지 [근거: WBS 경계]
- 호스트 `display: block` 제거 — v14 개선이므로 유지 [근거: WBS 경계]

### 설계

**sd-list.ts 변경:**
- SCSS `display: block` → `display: flex; flex-direction: column` [근거: Rule "sd-list display 모드"]

**sd-list-item.ts 템플릿 변경:**
- sd-collapse-icon `@if` 블록을 `_label` 앞에서 `_tool` 뒤 (닫는 `</div>` 직전)로 이동 [근거: Rule "sd-collapse-icon 배치 순서"]

**sd-list-item.ts 호스트 변경:**
- `"[attr.data-sd-open]": "open()"` 추가 [근거: Rule "data-sd-open 호스트 속성"]

**sd-list-item.ts SCSS 변경:**
- `._content`: `gap: var(--gap-sm)` → `var(--gap-xs)`, `align-items: center` 제거 [근거: Rule "_content 내부 레이아웃"]
- `._label`: `flex: 1` → `flex: 1 1 auto; overflow: auto` [근거: Rule "_content 내부 레이아웃" + D1]
- hover: 전역 `&:hover > ._content` 제거 → accordion 블록 내 `&:not([data-sd-readonly="true"]) > ._content:hover` 패턴으로 이동 [근거: Rule "hover 스타일 범위"]
- readonly: hover override 제거 (accordion `:not(readonly)` 가드로 대체) [근거: Rule "hover 스타일 범위"]
- flat: `font-size: 0.85em` → `var(--font-size-sm)`, `display: block`, `background: transparent` 추가 [근거: Rule "flat 레이아웃 스타일"]
- flat hover override 제거 (hover가 accordion 전용이므로 불필요) [근거: Rule "hover 스타일 범위"]
- `.sd-theme-mobile > sd-list-item > ._content:hover { background: transparent }` 추가 [근거: Rule "hover 스타일 범위"]

### 대안 검토

v14의 `display: flex; align-items: center; gap: var(--gap-sm)` 인라인 SCSS 패턴 vs v12의 `flex-row gap-xs` 유틸리티 클래스 패턴:
- v14의 인라인 SCSS 패턴을 유지하되 값만 v12에 맞춤. 유틸리티 클래스 사용은 v14 코드 스타일과 불일치하므로 채택하지 않음.
