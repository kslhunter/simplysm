## 구현계획

### 배경
v14 sd-modal은 v12에서 마이그레이션되면서 일부 템플릿 구조와 자동 크기 조정 로직이 누락/변경되었다. v14의 signal 기반 API, injectDragResize 추출, focusTrap 등 개선사항은 유지하면서 시각적·기능적 동작만 v12에 맞춘다. [근거: wbs Feature 3.3]

### 목표
- `._title` 태그를 `<h5>`로 복원 [근거: Rule "제목 태그는 h5"]
- 닫기 버튼을 `<sd-anchor>` 컴포넌트로 복원 [근거: Rule "닫기 버튼은 sd-anchor 컴포넌트"]
- backdrop 이벤트를 `(click)`으로 복원 [근거: Rule "backdrop 이벤트는 click"]
- dialog tabindex를 `0`으로 복원 [근거: Rule "dialog tabindex는 0"]
- `(sdResize)` 기반 자동 maxHeight/maxWidth 조정 복원 [근거: Rule "자동 maxHeight/maxWidth 조정"]
- `(window:resize)` 핸들러 복원 [근거: D1 "복원"]

### 비목표
- `movable` 기본값 변경 (v14 false 유지) [근거: D2 "수행 안 함"]
- `useCloseByBackdrop` 기본값 변경 (v14 true 유지) [근거: D3 "수행 안 함"]
- `display: flex; flex-direction: column` 직접 적용 되돌리기 [근거: wbs 경계 "v14 개선이므로 유지"]
- 포커스 트랩 제거 [근거: wbs 경계 "v14 개선이므로 유지"]
- `|| undefined` 패턴 제거 [근거: wbs 경계 "v14 개선이므로 유지"]

### 설계

#### 템플릿 변경 (`sd-modal.ts`)

1. **title 태그**: `<span class="_title">` → `<h5 class="_title">` [근거: Rule "제목 태그는 h5"]
2. **닫기 버튼**: `<button class="_close-btn">` → `<sd-anchor [theme]="'gray'" class="_close-btn">` [근거: Rule "닫기 버튼은 sd-anchor 컴포넌트"]
3. **backdrop**: `(mousedown)="onBackdropClick()"` → `(click)="onBackdropClick()"` [근거: Rule "backdrop 이벤트는 click"]
4. **dialog tabindex**: `tabindex="-1"` → `tabindex="0"` [근거: Rule "dialog tabindex는 0"]

#### imports 변경

- `SdAnchor` 추가 (닫기 버튼용) [근거: Rule "닫기 버튼은 sd-anchor 컴포넌트"]
- `SdEvents` 추가 (sdResize 이벤트용) [근거: Rule "자동 maxHeight/maxWidth 조정"]

#### host 바인딩 추가

```typescript
host: {
  // 기존 바인딩 유지
  "(sdResize)": "onHostResize($event)",       // [근거: Rule "자동 maxHeight/maxWidth"]
  "(window:resize)": "onWindowResize()",       // [근거: D1]
}
```

#### 메서드 추가

```typescript
// sdResize 핸들러 [근거: v12 sd-modal.control.ts:394-410]
onHostResize(event: SdResizeEvent): void {
  if (event.heightChanged) this._calcHeight();
  if (event.widthChanged) this._calcWidth();
}

onDialogResize(event: SdResizeEvent): void {
  if (event.heightChanged) this._calcHeight();
  if (event.widthChanged) this._calcWidth();
}

// 높이 제한 [근거: v12 sd-modal.control.ts:412-422]
private _calcHeight(): void {
  const dialogEl = this._getDialogEl();
  if (dialogEl === null) return;
  const style = getComputedStyle(this._elRef.nativeElement);
  const paddingTop = style.paddingTop === "" ? 0 : (parseInt(style.paddingTop, 10) || 0);
  if (dialogEl.offsetHeight > this._elRef.nativeElement.offsetHeight - paddingTop) {
    dialogEl.style.maxHeight = "100%";
    dialogEl.style.height = "100%";
  }
}

// 너비 제한 [근거: v12 sd-modal.control.ts:425-430]
private _calcWidth(): void {
  const dialogEl = this._getDialogEl();
  if (dialogEl === null) return;
  if (dialogEl.offsetWidth > this._elRef.nativeElement.offsetWidth) {
    dialogEl.style.maxWidth = "100%";
    dialogEl.style.width = "100%";
  }
}

// 윈도우 리사이즈 [근거: v12 sd-modal.control.ts:432-441, D1]
onWindowResize(): void {
  const dialogEl = this._getDialogEl();
  if (dialogEl === null) return;
  const hostEl = this._elRef.nativeElement;
  if (dialogEl.offsetLeft > hostEl.offsetWidth - 100) {
    dialogEl.style.left = hostEl.offsetWidth - 100 + "px";
  }
  if (dialogEl.offsetTop > hostEl.offsetHeight - 100) {
    dialogEl.style.top = hostEl.offsetHeight - 100 + "px";
  }
}
```

#### SCSS 변경

`._close-btn` 스타일을 `<button>` 전용에서 `sd-anchor` 호환으로 변경:
- `border: none; background: transparent; cursor: pointer; font-size: inherit; color: inherit;` 제거 (sd-anchor가 자체 처리)
- `display: flex; align-items: center; justify-content: center;` 제거 (sd-anchor는 inline-block)
- padding만 유지
- hover 스타일 제거 (sd-anchor의 theme="gray" 기본 hover 사용)

#### dialog에 sdResize 바인딩 추가

`._dialog` div에 `(sdResize)="onDialogResize($event)"` 추가

### 대안 검토

**ResizeObserver 직접 사용 vs sdResize 플러그인**: sdResize 플러그인이 이미 v14에 존재하고 SdEvents 디렉티브를 통해 템플릿 바인딩이 가능하므로, 별도 ResizeObserver 설정보다 기존 플러그인 사용이 일관적이다. → sdResize 채택

**window:resize를 effect로 처리 vs host 바인딩**: v12처럼 host 바인딩이 간결하고, v14에서도 동일 패턴이 지원된다. → host 바인딩 채택
