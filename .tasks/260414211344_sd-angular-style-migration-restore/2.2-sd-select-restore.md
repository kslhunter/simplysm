## 구현계획

### 배경
`packages/angular/src/controls/select/` 하위 3개 파일의 v12→v14 마이그레이션 과정에서 변경/누락된 스타일·템플릿·API를 복원한다. v14의 signal/computed/MutationObserver 기반 아키텍처는 유지하면서 시각적·기능적 동작만 v12에 맞춘다.

### 목표
- sd-select: placeholder 클래스를 `sd-text-color-gray-default`로 복원 [근거: Rule "placeholder 클래스"]
- sd-select: multi vertical 구분자를 `<div class='p-sm-0'>` + `<span>` 래핑으로 복원 [근거: Rule "multi vertical 구분자"]
- sd-select: `dropdownOpen`을 model로 변경하여 외부 양방향 바인딩 지원 [근거: Rule "open model"]
- sd-select-button: display block, 자체 padding/align 제거 [근거: Rule "display block", "padding 제거"]
- sd-select-item: tabindex/click/keydown 호스트 이동, data-sd-select-mode, 배경색 복원 [근거: Rule "호스트 이동", "select-mode", "배경색"]

### 비목표
- sd-select의 signal/computed innerHTML 관리 방식 변경 [근거: wbs 경계 "유지"]
- sd-select-item의 MutationObserver 방식 변경 [근거: wbs 경계 "유지"]
- sd-select-item의 disabled cursor/pointer-events 변경 [근거: wbs 경계 "유지"]

### 설계

**sd-select.ts:**
- 템플릿 line 57: `tx-trans-lighter` → `sd-text-color-gray-default`
- 컨스트럭터 line 403: separator `<br>` → `<div class='p-sm-0'></div>`
- 컨스트럭터 line 405-409: 각 htmlPart를 `<span style="display: inline">` 래핑
- line 272: `dropdownOpen = signal(false)` → `dropdownOpen = model(false)` (import에 model 이미 있음)

**sd-select-button.ts:**
- CSS line 20: `display: inline-flex` → `display: block`
- CSS line 21-22: `align-items: center; justify-content: center;` 제거
- host line 37: `[attr.tabindex]` 제거 (v12에 없음)

**sd-select-item.ts:**
- 템플릿: `<div class="_content" tabindex="0" (click)="onClick()" (keydown)="onKeydown($event)">` → `<div class="_content" style="display: inline-block;">`
- 호스트: `tabindex='0'`, `(click)="onClick()"`, `(keydown)="onKeydown($event)"`, `data-sd-select-mode` 추가
- CSS: `> ._content` 네스팅 제거 → 호스트에 직접 적용 (padding, cursor, transition, background, hover/focus/selected 스타일)
- CSS: `var(--trans-lighter)` → `rgba(0, 0, 0, 0.07)` (hover/focus/selected)
- CSS: disabled의 `> ._content` → 호스트 직접 적용 (cursor/pointer-events는 v14 개선 유지)
- `onClick()`: 매개변수 없음 → `$event` (v12처럼 preventDefault/stopPropagation)은 v14 방식으로 유지 가능하나, v12는 호스트에서 `(click)="onClick($event)"`로 event를 전달. 복원 필요.
