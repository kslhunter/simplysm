## 구현계획

### 배경
`sd-state-preset.ts`는 v14 마이그레이션 시 템플릿 구조가 flex+gap 기반으로 개선되었으나, 시각적 스타일(배경색, 테두리, padding 값, 아이콘 크기/색상 등)이 v12와 달라졌다. [근거: wbs Feature 2.3]

### 목표
- 단일 파일 `packages/angular/src/data/state-preset/sd-state-preset.ts`의 템플릿과 스타일을 수정하여 v12와 동일한 시각적 결과 달성 [근거: wbs Goal]

### 비목표
- `<sd-gap>` → CSS gap 전환 되돌리기 [근거: wbs 경계]
- flex 레이아웃 래퍼 구조 제거 [근거: wbs 경계]
- delete 버튼의 `[theme]="'danger'"` 제거 [근거: wbs 경계]

### 설계

**템플릿 변경:**
1. Star ng-icon에 `class="tx-theme-warning-default"` 추가
2. Floppy/X ng-icon에 `[size]="'1em'"` 추가
3. 프리셋 이름 앵커(`._preset-name`)에 `tx-trans-default` 클래스 추가

**스타일 변경:**
1. 호스트: `display: block` → `display: inline-block; vertical-align: top`
2. `._add-btn`: `padding: var(--gap-sm) var(--gap-default)`, `line-height: var(--line-height)`, `border: 1px solid transparent` 추가
3. `._preset-item`:
   - `border: 1px solid var(--trans-lighter)` → `border: 1px solid transparent`
   - `background: var(--theme-gray-lightest)` 추가
   - `border-radius: var(--border-radius-default)` → `var(--border-radius-lg)`
   - `padding: var(--gap-xs) var(--gap-sm)` → `var(--gap-sm) var(--gap-default)`
   - `&:hover { background: var(--theme-gray-lighter); }` 추가
   - `> sd-anchor { padding: 0 var(--gap-sm); }` 추가
   - `line-height: var(--line-height)` 추가
4. 사이즈별 padding:
   - sm: 둘 다 `var(--gap-xs) var(--gap-default)`
   - lg: 둘 다 `var(--gap-default) var(--gap-lg)`

### 대안 검토
- 래퍼 div 제거하고 v12의 inline-block + sd-gap 방식으로 완전 복원하는 방안 → wbs 경계에서 flex 전환은 유지로 명시되어 있어 불가
