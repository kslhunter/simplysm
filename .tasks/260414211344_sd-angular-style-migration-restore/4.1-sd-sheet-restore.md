## 구현계획

### 배경

sd-sheet는 v14 마이그레이션 과정에서 composable 함수 기반으로 리팩토링되었다. `useSheetColumnFixing`은 data column만 처리하며, feature cell(선택/확장 열)은 별도 fixing 로직이 없어 수평 스크롤 시 두 feature cell이 겹칠 수 있는 버그가 있다. [근거: useSheetColumnFixing.ts — string key 기반, feature cell 미지원]

### 목표

- v12의 DOM 속성(`data-c`, `data-r`), 이벤트 바인딩(`valueChange`, `pointerdown`), 스타일 속성(`theme="white"`, `disabled`, `title`), 동작(`trackByFn` 기본값, 정렬 아이콘 비교)을 v14 아키텍처 내에서 복원한다 [근거: WBS Feature 4.1 범위 12건]
- feature cell의 `position: sticky` left offset을 올바르게 계산한다 [근거: v12 columnFixingManager.fixedLeftMap()]

### 비목표

- `useSheetColumnFixing` composable 수정 — data column 전용으로 유지 [근거: WBS 경계 "signal 기반 resize-indicator는 개선이므로 유지"]
- tbody tr `(click)="onRowClick(item)"`, `onCellKeydown` 메서드 추출, colspan/rowspan 1→null 최적화 등 v14 개선 사항 — 유지 [근거: WBS 경계]

### 설계

#### 1. Feature cell fixing (신규)

컴포넌트 내에 feature cell 전용 fixing 로직을 추가한다.

```typescript
// sd-sheet.ts에 추가
private _featureCellWidths = signal(new Map<number, number>());

featureFixedLeftMap = computed(() => {
  const map = new Map<number, number>();
  const widths = this._featureCellWidths();
  const hasExpand = this.expanding.hasExpandable();
  
  if (hasExpand) {
    map.set(-2, 0);
    map.set(-1, widths.get(-2) ?? 0);
  } else {
    map.set(-1, 0);
  }
  return map;
});

onFeatureCellResize(event: Event, key: number): void {
  const width = (event.target as HTMLElement).offsetWidth;
  this._featureCellWidths.update((m) => {
    const newMap = new Map(m);
    newMap.set(key, width);
    return newMap;
  });
}
```

[근거: v12의 `onHeaderLastRowCellResize` + `columnFixingManager.fixedLeftMap()`을 v14 signal 패턴으로 재구현]

#### 2. 템플릿 속성 변경 (sd-sheet.ts template)

변경 대상 영역별 목록:

| 영역 | 변경 내용 |
|------|----------|
| 헤더 feature-cell th | `[attr.data-c]`, `[style.left.px]`, `(sdResize)` 추가 |
| 헤더 비-마지막행 th | `[attr.data-c]` 추가 |
| 헤더 마지막행 th | `[attr.data-c]` 추가 |
| 헤더 summary th | `[attr.data-c]` 추가 |
| 헤더 전체선택 checkbox | `hasSelectable()` 가드, `[theme]`, `(click)→(valueChange)` |
| 바디 feature-cell td | `[attr.data-r]`, `[attr.data-c]`, `[style.left.px]` 추가 |
| 바디 멀티선택 checkbox | `[theme]`, `(click)→(valueChange)`, `[disabled]`, `[attr.title]` |
| 바디 싱글선택 anchor | `canChangeFn()` 가드, `(click)→(pointerdown)`, `[attr.title]` |
| 정렬 아이콘 | `sortDef.desc` → `=== false`/`=== true` 명시적 비교 |

#### 3. trackByFn 기본값

```typescript
// 변경 전
trackByFn = input<(item: T, index: number) => unknown>();

// 변경 후
trackByFn = input<(item: T, index: number) => unknown>((item) => item);
```

#### 4. tbody track 표현식

trackByFn 기본값이 항상 존재하므로, tbody의 track 표현식에서 fallback이 불필요해짐:

```typescript
// 변경 전
track trackByFn() ? trackByFn()!(item, $index) : $index

// 변경 후  
track trackByFn()(item, $index)
```

### 대안 검토

| 대안 | 미선택 사유 |
|------|-----------|
| `useSheetColumnFixing`을 확장하여 feature cell 지원 | feature cell은 동적 인덱스(-2/-1)를 사용하고 data column은 string key를 사용하므로, 하나의 Map에 혼합하면 타입 안전성 저하. 관심사 분리 유지가 낫다 |
| feature cell left를 CSS로만 처리 | CSS `position: sticky; left: 0`만으로는 두 개의 feature cell이 겹치는 문제 해결 불가 |
