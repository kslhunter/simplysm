## 구현계획

### 배경

`packages/angular/src` 내부에서 `inject(Sd*Provider)` 호출 시 변수명이 3가지 패턴으로 혼재:
`_sdToast`, `_toast`, `_toastProvider`. sd prefix를 유지하고 Provider suffix를 제거하는 방향으로 통일한다.
[근거: D1 결정]

### 목표

- 모든 Sd* Provider inject 변수가 `_sd{Name}` (클래스 필드) / `sd{Name}` (로컬) 형태를 따름 [근거: wbs 네이밍 규칙 테이블]
- 모든 abstract class의 inject() 필드가 protected [근거: D2 결정]

### 비목표

- 소비앱 코드 변경 [근거: wbs 경계 "소비앱 코드는 이 Feature에서 다루지 않음"]
- Angular 내장 서비스의 변수**명** 변경 [근거: wbs 경계]. 접근 제한자는 변경 대상
- 소비앱 네이밍 규칙 문서 [근거: Feature 1.2 범위]

### 설계

기계적 변수명 리네이밍 + 접근 제한자 변경. 기능 변경 없음.
각 파일에서 변수 선언부와 모든 참조(`this._xxx`, 로컬 `xxx`)를 함께 변경한다.

### 대안 검토

없음 — 기계적 리네이밍이므로 설계 대안 불필요.
