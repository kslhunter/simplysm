## 구현계획

### 배경

core-common 테스트 4개에서 `using`/`await using` 구문으로 리소스를 자동 정리하고 있다. Feature 1.1에서 `Symbol.dispose`/`Symbol.asyncDispose` 메서드를 제거했으므로, 이 구문은 더 이상 사용할 수 없다. [근거: wbs 의존성 Feature 1.1]

각 테스트는 리소스 정리 후의 동작(대기 태스크 미실행, GC 정리 등)을 검증하며, 이 검증 로직 자체는 `using` 구문과 무관하게 유효하다. [근거: 코드 확인]

### 목표

- `using`/`await using` 구문을 try-finally 패턴으로 대체하여 Node.js 20 호환 [근거: Rule "try-finally 패턴 대체"]
- 테스트 이름을 실제 검증 동작에 맞게 변경 [근거: D2]

### 비목표

- 테스트 검증 로직 변경 [근거: wbs 경계]
- 새 테스트 추가 [근거: Feature 범위 외]
- 프로덕션 코드 변경 [근거: Feature 1.1에서 완료]

### 설계

각 테스트에서 `{ using/await using var = ...; ... }` 블록을 `const var = ...; try { ... } finally { var.dispose()/close(); }` 패턴으로 기계적 변환한다. [근거: D1]

변환 패턴:
- `using` (동기): `finally { variable.dispose(); }`
- `await using` (비동기): `finally { await variable.close(); }`

테스트 이름은 제거된 `using` 기능 대신 실제 검증하는 동작을 기술하도록 변경한다. 블록 끝 주석(`// dispose called automatically...`)도 제거한다. [근거: D2]

### 대안 검토

해당 없음. `using`/`await using` 구문의 유일한 대안이 try-finally이며, 이는 JavaScript의 표준 리소스 정리 패턴이다.
