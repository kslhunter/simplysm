# Feature 1.4 legacyModule esbuild.supported 오버라이드

## 참조 자료

- [wbs.md](./wbs.md)
- [debug.md](../260402153922_debug-vite-import-meta/debug.md)

### 근본 원인

Vite가 `defaultEsbuildSupported`에서 `"import-meta": true, "dynamic-import": true`를 강제 주입한다 (`node_modules/vite/dist/node/chunks/config.js:6057-6060`). 이로 인해 `build.target: "chrome61"`이어도 esbuild가 `import.meta`와 `import()`를 변환하지 않고 그대로 출력한다.

Feature 1.1에서 "esbuild가 `target: chrome61`로 `import.meta`를 자동 치환한다"는 전제로 `sd-legacy-import-meta` 플러그인을 제거했으나, Vite의 강제 설정이 이 전제를 무력화한다.

### 참조 파일

- `packages/sd-cli/src/utils/vite-config.ts` — legacyModule 블록 (line 232-242)
- `node_modules/vite/dist/node/chunks/config.js:6057-6060` — `defaultEsbuildSupported` 정의

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | import.meta 변환 방법 | esbuild.supported에 import-meta: false | Vite 내부 원리에 정확히 대응하며 최소 코드 변경 |
| D2 | dynamic-import 처리 | Vite 기본값(true) 유지 | dynamic-import: false는 esbuild가 require()로 변환하여 브라우저 실패. Rollup inlineDynamicImports가 import()를 인라인하므로 esbuild가 건드리면 안 됨 |

## 구현계획

### 배경

`createClientViteConfig()`에서 `legacyModule: true`일 때 `config.build.rollupOptions.output.inlineDynamicImports: true`만 설정하고 있다. Vite가 내부적으로 `esbuild.supported`에 `"import-meta": true, "dynamic-import": true`를 강제하여 esbuild의 Chrome 61 타겟 변환이 무력화된다.

### 목표

`legacyModule: true`일 때 `config.esbuild.supported`에 `"import-meta": false, "dynamic-import": false`를 설정하여 Vite의 강제 설정을 오버라이드한다.

### 비목표

- Vite 내부 코드 수정
- `sd-legacy-import-meta` 플러그인 복원

### 설계

`vite-config.ts`의 `legacyModule: true` 블록에서 `config.esbuild.supported`를 설정한다:

```typescript
if (options.legacyModule === true) {
  config.esbuild = {
    ...config.esbuild,
    supported: {
      "import-meta": false,
      "dynamic-import": false,
    },
  };
  config.build = {
    ...config.build,
    rollupOptions: {
      output: {
        inlineDynamicImports: true,
      },
    },
  };
}
```

Vite의 merge 순서: `{ ...defaultEsbuildSupported, ...esbuildOptions.supported }` — 사용자 설정(`esbuildOptions.supported`)이 `defaultEsbuildSupported`를 오버라이드한다.
