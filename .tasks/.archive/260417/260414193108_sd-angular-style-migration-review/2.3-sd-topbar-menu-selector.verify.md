# sd-topbar-menu dead CSS 삭제 -- LLM 검증

## 검증 항목

- [x] dead CSS 확인: `SdDropdown`이 popup을 `document.body.appendChild(popupEl)`로 이동시킴(sd-dropdown.ts:70). 따라서 `sd-topbar-menu sd-dropdown-popup ...` 하위 선택자는 팝업 열림 시 DOM 계층이 끊어져 매칭 불가. v12도 동일(sd-dropdown.control.ts:55)
- [x] styles 속성 제거 확인: sd-topbar-menu.ts에서 `styles` 속성이 완전히 제거됨. 유일한 규칙이 dead CSS였으므로 다른 스타일 손실 없음
- [x] 다른 코드에서 해당 스타일 참조 없음: ViewEncapsulation.None이므로 글로벌 스타일이지만, 해당 선택자는 sd-topbar-menu 전용이며 다른 컴포넌트에서 의존하지 않음
