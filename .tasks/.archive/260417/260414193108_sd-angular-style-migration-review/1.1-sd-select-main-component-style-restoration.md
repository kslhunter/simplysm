## 구현계획

### 배경

v14 `sd-select.ts`에서 스타일 구조가 변경되어 시각적 퇴행이 발생. 핵심 원인은 border/background 등 시각적 컨테이너 속성이 `> sd-dropdown`에서 `> sd-dropdown > ._sd-select-control`로 이동된 것으로, sd-select-button이 컨테이너 밖에 표시되는 문제를 야기. [근거: v12:153-158 vs v14:113-115]

### 목표

- 시각적 컨테이너 구조(border/bg on sd-dropdown)를 v12 기준으로 복원 [근거: Rule "시각적 컨테이너는 sd-dropdown"]
- 모든 상태(disabled, focus)와 변형(inline, size, inset)의 스타일 복원 [근거: Rule "Disabled 시각적 구분" 외 4개]
- v14의 의도적 개선사항(form-control-base, text-overflow, align-items) 유지 [근거: WBS 경계]

### 비목표

- Template 구조 변경 [근거: WBS 경계]
- TypeScript 로직 변경 [근거: WBS 경계 "스타일만 복원"]
- 다른 컴포넌트(sd-select-button, sd-select-item 등)의 스타일 변경 [근거: WBS Feature 1.2, 1.3에서 별도 처리]

### 설계

**수정 대상**: `packages/angular/src/controls/select/sd-select.ts` — styles 섹션 (98-174행)

**핵심 구조 변경** [근거: Rule "시각적 컨테이너는 sd-dropdown"]:

1. `._sd-select-control`에서 `border`, `border-radius`, `background` 제거
2. `> sd-dropdown`에 `display: flex; overflow: hidden; border; border-radius; background` 이동
3. `._sd-select-control`에 `flex-grow: 1; gap: var(--gap-default)` 추가 (flex 컨테이너 내 남은 공간 차지)
4. `._sd-select-control-icon`에서 `margin-left: var(--gap-sm)` 제거 (gap으로 대체)

**속성 추가/수정**:

- **루트**: `width: 100%; min-width: 10em` 추가 [근거: Rule "기본 크기 설정"]
- **Focus**: `&:focus, &:focus-within { border-color: var(--theme-primary-default) }` on `> sd-dropdown` [근거: Rule "포커스 시 primary 색상 피드백"]
- **Icon**: `&:hover/&:focus/&:active > ._sd-select-control-icon { opacity: 1 }` on `._sd-select-control` [근거: Rule "아이콘 인터랙션 피드백"]
- **Button**: `padding; border-left; border-radius` on `> sd-select-button` [근거: Rule "sd-select-button 컨테이너 내 배치"]
- **Disabled**: 배경을 `sd-dropdown`으로 이동(`--theme-gray-lightest`), 텍스트색 `--text-trans-light` 추가 [근거: Rule "Disabled 시각적 구분"]
- **Inline**: `vertical-align: top` 추가 [근거: Rule "Inline 수직 정렬"]
- **Size sm/lg**: gap + button padding 구조화 [근거: Rule "Size variant 스케일링"]
- **Inset**: min-width, border/radius 제거, button radius, focus outline-offset, disabled 별도 처리 [근거: Rule "Inset 모드 통합 스타일"]

**유지 사항** [근거: WBS 경계]:

- `@include mixins.form-control-base()` — padding, font, transparent border 제공
- `text-overflow: ellipsis` on `._sd-select-control-content` — v14 개선
- `align-items: center` on `._sd-select-control` — v14 개선
- `position: relative` on `sd-select`(host) — v14 구조
- `._sd-select-all-bar` 스타일 — v14 추가

### 대안 검토

1. **sd-select 호스트에 border 적용**: `:host`에 border/radius를 두는 방법. v12에서도 sd-dropdown에 두었고, sd-dropdown에 tabindex/focus가 있어 focus-within이 자연스러움. 거부.
2. **CSS wrapper div 추가**: Template에 새 컨테이너 div 추가. Template 변경이 필요하고 Feature 경계(스타일만 복원) 위반. 거부.
