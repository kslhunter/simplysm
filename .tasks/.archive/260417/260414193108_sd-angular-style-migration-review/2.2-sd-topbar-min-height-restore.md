## 구현계획

### 배경

sd-topbar는 앱 상단 네비게이션 바 컴포넌트로, `sd-topbar-container`(flex-direction: column, height: 100%) 내에서 사용된다. v14 마이그레이션 과정에서 `min-height`가 `height`로 변경되어 콘텐츠가 `--topbar-height`(3em)를 초과할 경우 잘림이 발생할 수 있다.

### 목표

- `height` → `min-height` 변경으로 v12의 유연한 높이 동작 복원 [근거: Rule "sd-topbar는 최소 높이를 보장하면서 콘텐츠 확장을 허용해야 한다"]

### 비목표

- scrollbar 색상 변수화 변경 [근거: wbs 경계 "scrollbar 색상 변수화는 v14 개선사항이므로 유지"]
- `.sh-topbar` 유틸리티 클래스 변경 (v12에서도 `height` 사용)
- `overflow-x`/`overflow-y` 변경

### 설계

`packages/angular/src/layout/topbar/sd-topbar.ts:39`에서 CSS 속성 변경:

```scss
// Before (v14)
height: var(--topbar-height);

// After (v12 복원)
min-height: var(--topbar-height);
```

`overflow-y: hidden`과의 호환성: v12에서도 동일 조합 사용. `min-height` 사용 시 콘텐츠에 맞게 확장되므로 overflow가 발생하지 않아 문제 없음.

### 대안 검토

대안 없음. v12의 원래 동작을 그대로 복원하는 것이 유일하게 적절한 방법.
