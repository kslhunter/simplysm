## 구현계획

### 배경

`SdResizeEvent` 인터페이스의 `target` 프로퍼티가 `Element`로 선언되어 있으나, `SdResizeDirective`는 항상 `ElementRef.nativeElement`(HTMLElement)를 observe한다 (sd-resize.ts:38). 이로 인해 소비처에서 `event.target`을 사용할 때마다 `as HTMLElement` 캐스팅이 필요하다.

### 목표

- `SdResizeEvent.target` 타입을 `HTMLElement`로 변경하여 소비처에서 불필요한 캐스팅을 제거한다 [근거: Rule "SdResizeEvent.target은 HTMLElement 타입이어야 한다"]

### 비목표

- host binding `$event` 타입 문제 해결 — Feature 1.2 범위 [근거: wbs 경계]
- `SdIntersectionEvent` 변경 — angular 패키지 내 사용처 없음 [근거: wbs 경계]

### 설계

1. `SdResizeEvent.target: Element` → `target: HTMLElement` 변경 [근거: D1]
2. `SdResizeDirective`의 emit에서 `entry.target as HTMLElement` 캐스팅 추가 [근거: D2]
3. 소비처 3건의 `as HTMLElement` 캐스팅 제거 [근거: Rule "불필요한 캐스팅 제거"]

### 대안 검토

- **ElementRef<HTMLElement> 제네릭 사용**: `inject(ElementRef<HTMLElement>)`로 nativeElement 타입을 명시하는 방법도 있으나, ResizeObserverEntry.target은 여전히 Element 타입이므로 캐스팅은 필요하다. 현재 접근법과 동일한 결과.
