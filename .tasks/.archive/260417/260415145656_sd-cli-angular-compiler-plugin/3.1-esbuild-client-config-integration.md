## 구현계획

### 배경
`esbuild-client-config.ts`는 현재 `@angular/build/private`의 `createCompilerPlugin`을 사용하여 Angular AOT 컴파일 + 스타일시트 번들링을 하나의 불투명한 esbuild 플러그인으로 처리한다. Feature 1.1~2.2에서 자체 구현한 `createAngularCompilerPlugin`으로 이를 교체한다. [근거: WBS 프로젝트 개요]

### 목표
- `@angular/build/private`의 `createCompilerPlugin`, `SourceFileCache`, `CompilerPluginOptions`, `BundleStylesheetOptions` 의존성 제거 [근거: Rule "@angular/build/private import 제거"]
- `client.worker.ts`의 watch 모드 호환성 유지 [근거: Rule "sourceFileCache 인터페이스"]
- 기존 테스트 동작 유지 [근거: Rule "테스트 mock 교체"]

### 비목표
- `esbuild-pwa.ts`, `esbuild-index-html.ts`의 `@angular/build/private` 의존성 제거 [근거: WBS 경계]
- `JavaScriptTransformer` 자체 구현 [근거: WBS 기술적 제약]
- `vite-angular-plugin.ts` 수정 [근거: WBS 경계]

### 설계

**`ClientSourceFileCache` 클래스** (`esbuild-client-config.ts` 내부) [근거: D1, Rule "sourceFileCache 인터페이스"]
```typescript
export class ClientSourceFileCache extends AngularSourceFileCache {
  readonly typeScriptFileCache = new Map<string, string | Uint8Array>();
  readonly loadResultCache = new MemoryLoadResultCache();
}
```
- `AngularSourceFileCache` 상속 → `modifiedFiles: Set<string>`, `invalidate(files)` 제공
- `typeScriptFileCache`, `loadResultCache` 추가 → `client.worker.ts`의 `sd-build-start` 플러그인 호환

**`createClientEsbuildContext` 수정** [근거: Rule "createCompilerPlugin import 제거", Rule "옵션 전달"]
1. import 교체: `@angular/build/private`의 4개 심볼 제거, `createAngularCompilerPlugin` + `AngularCompilerPluginOptions` import
2. `ClientSourceFileCache` 인스턴스 생성 (LMDB는 플러그인 내부 `persistentCachePath`로 관리)
3. `createClientTransformStylesheet` 호출하여 `transformStylesheet` 콜백 생성 [근거: D2]
4. `AngularCompilerPluginOptions` 구성 → `createAngularCompilerPlugin` 호출
5. `BundleStylesheetOptions` 관련 코드 전체 제거

**`ClientEsbuildResult` 인터페이스 변경** [근거: Rule "sourceFileCache 인터페이스"]
```typescript
export interface ClientEsbuildResult {
  context: esbuild.BuildContext;
  sourceFileCache: ClientSourceFileCache;
}
```

### 대안 검토
- `sourceFileCache`를 제거하고 `loadResultCache`, `typeScriptFileCache`를 별도 반환 → `client.worker.ts` 수정 범위가 커지고 기존 패턴과 불일치. 기각.
