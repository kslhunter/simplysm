## 구현계획

### 배경

`BuildOutput` 인터페이스(`engines/types.ts:33-42`)에 `includeTests?: boolean` 필드가 있다. check 경로(`TypecheckOrchestrator`)만 `includeTests: true`를 명시하고, non-check 경로(build/watch/dev)는 이 필드를 생략하여 `undefined`로 전달된다. `tsc-build.ts:79`에서 `!options.includeTests`로 평가되므로 기능상 정상이지만, 의도가 암묵적이다.

### 목표

- non-check 경로 6곳에 `includeTests: false`를 명시하여 "tests 제외가 의도된 것"을 코드에서 즉시 확인 가능하게 한다 [근거: wbs "유지보수 시 실수 가능성"]

### 비목표

- `BuildOutput.includeTests` 타입을 required로 변경 [근거: wbs 경계 "optional 유지 — 하위 호환"]
- `TypecheckOrchestrator`의 `includeTests: true` 수정 [근거: wbs 경계]
- `tsc-build.ts:79` 조건식 리팩토링 [근거: wbs 제외 사항 "현재 정상 동작, 변경 리스크 불필요"]

### 설계

6곳의 BuildOutput 객체 리터럴에 `includeTests: false` 프로퍼티를 추가한다.
기존 테스트의 exact match assertion도 함께 업데이트한다.
