## 구현계획

### 배경

`sd-sheet-config-modal`은 `sd-sheet`의 컬럼 설정 모달이다. 하단에 Reset, OK, Cancel 3개 버튼이 있으며, v12에서는 모두 `[buttonStyle]="'min-width: 60px;'"` 바인딩으로 최소 너비를 보장했으나, v14 마이그레이션 시 누락되었다.

### 목표

- 3개 버튼에 `[buttonStyle]="'min-width: 60px;'"` 바인딩 복원 [근거: Rule "3개 버튼에 최소 너비 60px 적용"]

### 비목표

- `$signal`→`signal`, `$effect`→`effect`, 배열 메서드 표준화 등 v14 개선 유지 [근거: WBS 경계]

### 설계

`sd-sheet-config.modal.ts` 템플릿의 3개 `<sd-button>` 요소에 `[buttonStyle]="'min-width: 60px;'"` 속성 추가. `SdButton`의 `buttonStyle` input (line 207)이 이미 존재하며 `[style]` 바인딩 (line 22)으로 적용됨.
