## 구현계획

### 배경
sd-modal-select-button은 v14에서 `sd-additional-button` 래퍼를 제거하고 직접 flex 레이아웃으로 전환하면서 호스트 크기 스타일과 이벤트 전파 처리가 누락되었다. [근거: v12 원본 비교]

### 목표
- sd-modal-select-button 호스트에 `width: 100%`, `min-width: 3em` 복원 [근거: Rule "부모 폭을 채우고 최소 너비를 보장"]
- search 버튼 클릭 시 `preventDefault()`/`stopPropagation()` 복원 [근거: Rule "클릭은 부모로 전파되지 않는다"]

### 비목표
- sd-button link 테마 변경 [근거: 설계 결정 D1 — v14 유지]
- sd-additional-button 래퍼 복원 [근거: wbs 경계 "sd-additional-button은 차이 없음"]
- sd-button ripple 셀렉터 변경 복원 [근거: wbs 경계 "v14 개선이므로 복원하지 않음"]

### 설계

**sd-modal-select-button CSS 변경** (`sd-modal-select-button.ts:70`):
호스트 스타일에 `width: 100%; min-width: 3em;` 추가

**sd-modal-select-button 이벤트 처리** (`sd-modal-select-button.ts:60,191`):
1. 템플릿의 `(click)="onSearchClick()"` → `(click)="onSearchClick($event)"` 변경
2. `onSearchClick()` 메서드 시그니처에 `event: MouseEvent` 매개변수 추가
3. 메서드 본문 첫 줄에 `event.preventDefault(); event.stopPropagation();` 추가

### 대안 검토
- **래퍼 복원 방식**: `sd-additional-button` 래퍼를 다시 도입하면 `width/min-width`가 자연스럽게 해결되지만, v14에서 래퍼 제거는 의도적 구조 개선이므로 채택하지 않음
- **CSS `pointer-events` 방식**: 이벤트 전파 차단에 CSS를 사용할 수 있으나, `preventDefault()`도 필요하므로 JS 핸들러가 적절
