## 구현계획

### 배경

sd-topbar-menu은 상단 네비게이션 바의 드롭다운 메뉴를 렌더링한다. v14 마이그레이션에서 sd-list-item의 `[layout]="'flat'"` 속성이 `[open]="true"`로 변경되었고, 중첩 리스트 배경색 스타일이 누락되었다.

### 목표

- sd-list-item에 `[layout]="'flat'"` 적용하여 v12의 비대화형 섹션 헤딩 동작 복원 [근거: Rule "메뉴 항목은 flat 레이아웃"]
- 중첩 리스트에 `var(--trans-lightest)` 배경색 복원 [근거: Rule "중첩 리스트에 배경색 적용"]

### 비목표

- padding 방식(`contentClass`/`contentStyle` vs `style.*`) 변경은 v14 개선이므로 유지 [근거: WBS 경계]
- 드롭다운 참조 방식, 라우터링크 셀렉터 등의 변경은 v14 개선이므로 유지 [근거: WBS 경계]

### 설계

**1. 템플릿 변경** (`sd-topbar-menu.ts` line 86):
- `[open]="true"` → `[layout]="'flat'"`
- flat 레이아웃에서 sd-list-item은: collapse-icon 미표시, children 항상 열림, content에 `font-size: var(--font-size-sm)`, `opacity: 0.7`, `cursor: default` 적용

**2. 스타일 추가** (`sd-topbar-menu.ts`):
```scss
sd-topbar-menu {
  sd-list sd-list {
    background: var(--trans-lightest);
  }
}
```

### 대안 검토

이 Feature는 v12 원본의 정확한 복원이므로 대안이 없다. 변경량이 최소이고 사이드이펙트가 제한적이다.
