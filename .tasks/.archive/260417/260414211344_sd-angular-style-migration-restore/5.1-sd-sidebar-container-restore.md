## 구현계획

### 배경
`SdSidebarContainer`는 사이드바 레이아웃을 제공하는 컴포넌트로, 모바일 뷰에서 backdrop을 통해 사이드바를 토글한다. v14 마이그레이션 중 이벤트 타입과 동작이 변경되었다.

### 목표
- backdrop 이벤트를 `mousedown` → `click`으로 복원 [근거: Rule "backdrop 이벤트는 click이다"]
- backdrop 클릭 동작을 `set(false)` → `update((v) => !v)`로 복원 [근거: Rule "backdrop 클릭 시 toggle 값을 반전한다"]

### 비목표
- SCSS 변수 참조 방식 변경 [근거: wbs 경계 "SCSS 변수 참조는 v14 개선이므로 유지"]
- `<ng-content />` self-closing [근거: wbs 경계]
- `toSignal`/`effect` 기반 라우터 이벤트 구독 [근거: wbs 경계]

### 설계
**변경 파일:** `packages/angular/src/layout/sidebar/sd-sidebar-container.ts`

1. 템플릿 L17: `(mousedown)` → `(click)` [근거: Rule "backdrop 이벤트는 click이다"]
2. `onBackdropClick()` 메서드 L90-91: `this.toggle.set(false)` → `this.toggle.update((v) => !v)` [근거: Rule "backdrop 클릭 시 toggle 값을 반전한다"]
