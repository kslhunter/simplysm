## 구현계획

### 배경

`writeEmitResults` 함수는 Angular emit 결과를 디스크에 쓰면서, .js 파일 내 side-effect SCSS import를 감지하여 즉시 `compileScssFile`로 컴파일한다 (`ngtsc-build-core.ts:262-266`). 이 때 `trackDeps`로 `scssDependencies`에는 의존성을 기록하지만, `sideEffectScssDeps`에는 기록하지 않는다. `sideEffectScssDeps`는 `compileSideEffectScss` 함수 내부에서만 갱신되므로 (`ngtsc-build-core.ts:147-149`), SCSS 변경 없이 .ts에서 새 side-effect import를 추가하면 `compileSideEffectScss`가 스킵되어 의존성 정보가 누락된다. [근거: review.md LOGIC-001]

### 목표

- `writeEmitResults`에서 `compileScssFile` 호출 후 `sideEffectScssDeps`에 의존성을 기록한다 [근거: Rule "sideEffectScssDeps에 의존성을 기록한다"]
- `sideEffectScssDeps` 미제공 시 기존 동작 유지 [근거: Rule "기존 동작에 변화가 없다"]

### 비목표

- `compileSideEffectScss`의 기존 로직 변경 [근거: wbs 경계]
- `buildWatchEvent`의 분기 로직 변경 [근거: wbs 경계]

### 설계

**1. `SideEffectScssOptions` 확장** (`ngtsc-build-core.ts:56-63`)

```typescript
export interface SideEffectScssOptions {
  loadPaths: string[];
  scssErrors: string[];
  scssDependencies: Map<string, Set<string>>;
  registry?: Map<string, SideEffectScssEntry>;
  registryReverseIndex?: Map<string, Set<string>>;
  /** side-effect SCSS별 의존성 맵. compileScssFile 후 갱신. 증분 판별용 */
  sideEffectScssDeps?: Map<string, Set<string>>;
}
```

**2. `writeEmitResults` 내부 갱신** (`ngtsc-build-core.ts:262-266`)

기존 `compileScssFile` + `trackDeps` 호출 후 `sideEffectScssDeps` 갱신 추가:

```typescript
try {
  const result = compileScssFile(scssAbsPath, scss.loadPaths);
  fs.mkdirSync(path.dirname(cssAbsPath), { recursive: true });
  fs.writeFileSync(cssAbsPath, result.css, "utf-8");
  trackDeps(scss.scssDependencies, sourceFileName, result.dependencies);
  // side-effect SCSS 의존성 기록 (증분 판별용)
  if (scss.sideEffectScssDeps != null) {
    scss.sideEffectScssDeps.set(scssAbsPath, new Set(result.dependencies));
  }
} catch (err) {
  scss.scssErrors.push(formatScssError(err, scssAbsPath));
}
```

[근거: `compileSideEffectScss` 내부의 동일 패턴 (`ngtsc-build-core.ts:147-149`)]

**3. 호출부 수정** (`library-build.worker.ts`)

`build()` 함수 (line 97-103)와 `buildWatchEvent()` 함수 (line 190-202)의 `SideEffectScssOptions` 구성에 `sideEffectScssDeps` 추가:

```typescript
writeEmitResults(filteredEmitResults, info.pkgDir, {
  loadPaths,
  scssErrors: sideEffectScssErrors,
  scssDependencies: combinedScssDeps,
  registry: compiler.sideEffectScssRegistry,
  registryReverseIndex,
  sideEffectScssDeps, // 추가
});
```

### 대안 검토

| 대안 | 미선택 사유 |
|------|------------|
| `buildWatchEvent`에서 새 registry 항목 감지 후 `compileSideEffectScss` 강제 호출 | 불필요한 재컴파일 발생 (writeEmitResults에서 이미 컴파일됨). 의존성 기록만 필요 |
