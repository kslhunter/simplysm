## 구현계획

### 배경

`queryable.ts`의 `QueryableRecord<TData>` 타입은 `DataRecord`(스키마 데이터)를 SQL 표현식 타입으로 매핑한다. optional relation(`TData[K] extends DataRecord | undefined`)은 현재 `NullableQueryableRecord`로 매핑되어 내부 모든 컬럼에 `| undefined`를 전파한다. 이를 `QueryableRecord` 자체로 통일하여 전파를 제거한다.

### 목표

- `QueryableRecord` 타입에서 `NullableQueryableRecord` 참조를 `QueryableRecord`로 교체
- `NullableQueryableRecord` 타입, `__nnOriginalData` symbol, `nn()` 함수 삭제

### 비목표

- `QueryableWriteRecord`, `UnwrapQueryableRecord` 타입 변경
- `join`/`joinSingle` 메서드 시그니처 변경
- `ExprUnit.n` getter 변경

### 설계

변경 대상은 `queryable.ts` 1개 파일이다.

**`QueryableRecord` 타입 변경** — 2개 분기 수정:

```typescript
// 변경 전 (1890-1892):
: TData[K] extends (infer U)[] | undefined
  ? U extends DataRecord
    ? NullableQueryableRecord<U>[] | undefined
// 변경 후:
: TData[K] extends (infer U)[] | undefined
  ? U extends DataRecord
    ? QueryableRecord<U>[] | undefined

// 변경 전 (1896-1897):
: TData[K] extends DataRecord | undefined
  ? NullableQueryableRecord<Exclude<TData[K], undefined>> | undefined
// 변경 후:
: TData[K] extends DataRecord | undefined
  ? QueryableRecord<Exclude<TData[K], undefined>> | undefined
```

**삭제 대상** — 연속 블록:

- `queryable.ts:1905` — `declare const __nnOriginalData: unique symbol;`
- `queryable.ts:1907-1926` — `NullableQueryableRecord` 타입 정의
- `queryable.ts:1928-1936` — `nn()` 함수 오버로드 + 구현
