## 구현계획

### 배경

sd-cli의 커맨드(`check`, `replace-deps`, `publish`) 및 오케스트레이터(`BaseOrchestrator`, `BuildOrchestrator`, `WatchOrchestrator`)에서 `process.stdout.write` 직접 사용, `consola` 태그 없는 직접 사용, `fail()` severity, DRY-RUN `debug` severity 등의 비일관성이 존재한다. Feature 1.1에서 확립한 severity 기준(D2)과 `withTag` 패턴을 적용하여 통일한다. [근거: wbs 비일관성 #1,#2,#4,#5,#6]

### 목표

- `process.stdout.write` 8건을 consola 태그 로거로 전환 [근거: Rule "process.stdout.write → consola"]
- `consola` 직접 사용 1건을 `withTag`으로 전환 [근거: Rule "withTag 전환"]
- `fail()` 1건을 `error()`로 전환 [근거: Rule "fail → error"]
- DRY-RUN `debug` 2건을 `info`로 전환 [근거: Rule "DRY-RUN info"]
- BuildOrchestrator start/success 쌍 정상화 [근거: Rule "D2 일관 적용"]

### 비목표

- 변경 불필요로 확인된 7개 파일(device.ts, git-phase.ts 등) 수정 [근거: 코드 확인 완료]
- 로그 메시지 내용(한국어 텍스트) 변경 [근거: wbs 경계]
- 새로운 로그 추가 [근거: wbs 경계]

**check.ts formatSection 유지 + info 통합:**
- 기존 포맷(구분선, 아이콘) 보존, consola info로 감싸기
