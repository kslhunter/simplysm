```markdown
## ✅ Always (반드시)
### `injectViewTypeSignal()` 호출 시점 — 생성자 또는 필드 이니셜라이저에서만
### page 컴포넌트가 `<sd-topbar-container>`와 `<sd-topbar>`를 소유한다
### 시트 셀 내부 컨트롤에 `[inset]="true" [size]="'sm'"` 명시
### input 변경을 effect 내부에서 filter·lastFilter·page에 반영

## ⚠️ Ask first (조건부)
### 공유 데이터 사용 화면은 `_refresh()` 선두에서 `_sdSharedData.wait()` 호출
### `SdCommandDirective` 부착 위치 — 마스터-디테일 구조에서 중복 방지
### 삭제 방식 결정 — soft-delete vs 물리 삭제

## 🚫 Never (금지)
### input 의존 데이터 로딩에 `void this._initAsync()` 금지
### signal 필드 초기값에서 다른 signal 읽기 금지
### `mark(sig)`를 "저장 감지"로 사용 금지

## 예외 케이스
### 시트 셀 `[inset]="true" [size]="'sm'"` 예외 — 복합 구조 / 큰 시트 행
### 공유 데이터 미사용 화면 — `_sdSharedData.wait()` 불필요
### isDeleted 컬럼 부재 — soft-delete 확장 미사용
```
