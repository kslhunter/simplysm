# 페이지/모달 컨테이너 직접 조립

소비 화면이 `<sd-busy-container>` · `<sd-topbar-container>` · `<sd-topbar>` 표준 컴포넌트를 직접 조립하여 하나의 컴포넌트를 page·modal·control 3뷰로 재사용한다.

## When to use / When NOT to use
- ✅ 한 컴포넌트를 page·modal·control 중 둘 이상으로 재사용
- ✅ page 전용 / modal 전용 / control 전용도 각 분기만 골라 사용 가능
- ❌ 단일 화면 컨테이너 추상(`<sd-base-container>`) 재도입 — 분기·타이틀·권한이 다시 감춰져 변경이 어려움
- ❌ 리스트 화면 본문 — [`crud-list.md`](./crud-list.md)
- ❌ 상세 폼 본문 — [`crud-detail.md`](./crud-detail.md)
