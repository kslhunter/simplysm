## 검증 항목

### 상단 구조 (Rule: sibling diff 스타일 템플릿 정렬)

- 1행이 `← [CRUD 리스트 레시피 진입점](../crud-list.md)` 브레드크럼이다
- H1 제목이 `# 확장 A: inline 편집/저장`이다
- H1 다음에 `> **선행:** 없음 (최소 뼈대 §3에 직접 얹음)` 블록쿼트가 있다
- 요약 문단(1~2문장)이 있다
- 요약 문단 다음에 `> **적용 조건:**`로 시작하는 블록쿼트가 있다 — inline 편집 vs 모달 편집(확장 F) 선택 기준을 1~2줄로 대비하고 `./extension-f-modal-edit.md` 링크를 포함한다
- `**이 확장이 도입하는 요소:**` 불릿 블록이 있다
- 번호 주석(`// 1)` ~ `// 10)`)이 붙은 TypeScript 코드 블록이 1개 존재한다
- 코드 블록 뒤에 `**포인트:**` 불릿 섹션이 있다
- 포인트 뒤에 `**🚫 흔한 실수**` 또는 `## 🚫 흔한 실수` 서브섹션이 있다
- 파일 말미에 `## Cross-reference` 섹션이 있다

### 진입점 2.1 정합 (Rule: 최소 뼈대와 diff 정합)

- `_itemsSnapshot` 식별자가 코드 블록에 존재한다
- `obj.clone(r.items)` 호출이 `_refresh` diff에 존재한다
- `diffs = computed(() => this.items().oneWayDiffs(this._itemsSnapshot, "id"))` 파생이 코드 블록에 존재한다
- `canEdit = computed(...)` 파생에 `perms().includes("edit")`와 `viewType() === "page"` 두 조건이 모두 포함된다
- `formCtrl = viewChild<SdForm>("formCtrl")` 선언이 코드 블록에 존재한다
- `setupCanDeactivate(() => this._checkIgnoreChanges())` 호출이 생성자 diff에 존재한다
- `onSaveButtonClick`, `onSubmit`, `onAddItemButtonClick`, `onRemoveNewItemButtonClick`, `_upsertItem`, `_checkIgnoreChanges`, `getIsItemChanged` 모두 코드 블록에 존재한다

### import 정합 (Rule: 시그니처 정합성)

- `import { ... viewChild ... } from "@angular/core"` 또는 동등 형태로 `viewChild`가 `@angular/core` 경로에서 import된다
- `ArgumentError`, `DateTime`, `obj`는 `@simplysm/core-common`에서 import된다 (`str`는 기존에도 존재)
- `expr`는 `@simplysm/orm-common`에서 import된다
- `SdAnchor`, `SdForm`, `SdItemOfTemplate`, `SdSharedDataSelect`, `FormatPipe`, `setupCanDeactivate`, `SdCommandDirective`는 `@simplysm/angular`에서 import된다
- `oneWayDiffs` 활성화 관련으로 "side-effect" 또는 `import "@simplysm/core-common"` 언급이 주석 또는 본문에 존재한다

### 적용 조건 블록쿼트 (Rule: When to use 대체)

- `> **적용 조건:**` 블록쿼트가 "상호 배타", "확장 F" 키워드를 포함한다
- `./extension-f-modal-edit.md` 링크가 블록쿼트 내부 또는 인접 위치에 존재한다

### Anti-patterns 섹션 (Rule: `items` 물리 제거 ❌/✅ 블록 1건)

- `**🚫 흔한 실수**` 서브섹션 내부에 "### " 헤더를 가진 anti-pattern 항목이 1건 존재한다
- 해당 anti-pattern 제목 또는 본문에 "items", "물리 제거" 또는 "기존 row" 키워드가 있다
- 코드 블록 내부에 `// ❌` 주석과 `// ✅` 주석이 모두 존재한다
- ❌ 예시에 `items.update((list) => list.filter` 또는 `filter((it) => it !== item)` 패턴이 있다
- ✅ 예시에 `isDeleted: true` 플래그 설정이 있다
- 근거 줄에 `oneWayDiffs` + `create`, `update`, `same` 열거(또는 "delete를 다루지 않는다" 서술)가 존재한다
- 확장 B(`./extension-b-selection.md`) 또는 확장 C(`./extension-c-inline-delete.md`) 링크가 존재한다

### 공통 규칙 위임 (Rule: 중복 본문 금지, D4)

- `../_common-rules.md` 링크가 3회 이상 등장한다 (적용 조건 블록 + 포인트 내 `mark`/`setupCanDeactivate`/`[inset]/[size]` 관련 1-hop 링크 + 🚫 흔한 실수 위임 안내)
- "시트 셀 내부 컨트롤" `[inset]="true" [size]="'sm'"` 규칙 본문 전체 재서술이 없다 — 1줄 요약 + anchor 링크 형태로 축약된다
- `mark` shallow copy 상세 설명(공통 규칙 본문과 동일한 ❌/✅ 블록) 본문 재서술이 없다
