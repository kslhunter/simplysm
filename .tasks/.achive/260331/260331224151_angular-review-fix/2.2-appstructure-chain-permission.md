## 구현계획

### 배경

`SdAppStructureUtils`는 앱 구조 트리를 탐색하여 타이틀 생성, 권한 판정을 수행하는 정적 유틸리티 클래스다. `getItemChainByFullCode`가 트리 탐색의 핵심 메서드이며, `getTitleByFullCode`와 `getPermsByFullCode`가 이를 사용한다.

### 목표

- LOGIC-007: `getItemChainByFullCode`의 중간 코드 누락 시 partial chain 대신 빈 배열 반환
- LOGIC-014: `getPermsByFullCode`의 `permRecord` 미로딩 상태에서 안전한 기본값(빈 배열) 반환

### 비목표

- 메뉴 계산 로직(`getMenus`, `getFlatMenus`) 변경 — 이미 올바르게 동작
- 권한 구조 조회(`getPermissions`, `getFlatPermissions`) 변경 — `permRecord`를 사용하지 않음

### 설계

#### LOGIC-007: getItemChainByFullCode 루프 수정

현재 루프에서 `cursor`가 undefined일 때 `cursorChildren = []`로 설정하고 계속 진행하여 partial chain이 생성된다. 수정: `cursor == null`이면 즉시 빈 배열 반환.

```typescript
// Before
for (const currCode of codeChain) {
  cursor = cursorChildren.single((item) => item.code === currCode);
  cursorChildren = cursor != null && "children" in cursor ? cursor.children : [];
  if (cursor) {
    result.push(cursor);
  }
}

// After
for (const currCode of codeChain) {
  cursor = cursorChildren.single((item) => item.code === currCode);
  if (cursor == null) return [];
  cursorChildren = "children" in cursor ? cursor.children : [];
  result.push(cursor);
}
```

#### LOGIC-014: getPermsByFullCode 가드 추가

`permRecord === undefined`일 때 함수 진입 시 빈 배열 반환. 이후 로직은 변경 없음.

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| LOGIC-007: 빈 배열 반환 | 채택 | 메서드 시그니처와 일관, caller가 이미 빈 배열 처리 |
| LOGIC-007: throw Error | 미채택 | `getPermsByFullCode`에서 try-catch 필요, 기존 패턴과 불일치 |
| LOGIC-014: 빈 배열 반환 | 채택 | 안전한 기본값 (최소 권한 원칙), `getMenus`와 일관 |
| LOGIC-014: 전체 권한 부여 유지 | 미채택 | 로딩 중 인가되지 않은 접근 허용 위험 |
