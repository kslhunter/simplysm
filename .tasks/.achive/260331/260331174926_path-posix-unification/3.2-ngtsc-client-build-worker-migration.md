## 구현계획

### 배경

ngtsc-build.worker.ts는 Angular ngtsc 빌드의 watch 모드를 담당하는 워커로, TypeScript 소스 파일 경로를 수집하고 비교하는 로직에서 `sf.fileName.replace(/\\/g, "/")` 형태의 ad-hoc POSIX 변환을 4곳에서 수행한다. Feature 1.1에서 도입된 `posix()` 함수로 이를 통일한다.

### 목표

- ngtsc-build.worker.ts의 ad-hoc `.replace(/\\/g, "/")` 4건을 `posix()`로 교체
- `@simplysm/core-node`에서 `posix` import 추가

### 비목표

- client.worker.ts 변경 (D1: 마이그레이션 불필요)
- 워커 로직 변경 — 경로 변환 함수만 교체

### 설계

`posix()` 함수는 `p.replace(/\\/g, "/") as PosixPath`와 동일한 동작이므로, 반환 타입만 `string`에서 `PosixPath`로 변경된다. `extractSourceFilePaths`의 반환 타입은 `Set<string>`에서 `Set<PosixPath>`로 강화할 수 있으나, 하위 사용처(`lastSourceFilePaths.has(f.path)`)에서 `f.path`가 이미 `PosixPath`이므로 타입 호환성이 유지된다.

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| `posix()` 사용 | 채택 | 단순 슬래시 변환이므로 `posix()`가 적합. 코드베이스 일관성 확보 |
| `posixResolve()` 사용 | 미채택 | `sf.fileName`은 이미 절대 경로이므로 resolve 불필요 |
