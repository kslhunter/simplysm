## 구현계획

### 배경

path-posix-unification 태스크에서 `norm()`/`NormPath` 제거 및 `posix()`/`posixResolve()` 통일이 완료되었으나, 리뷰에서 2건의 일관성 잔존 이슈가 발견되었다.

### 목표

- `vitest-plugin.ts`의 로컬 `normalizePath()` 함수를 `pathx.posix()`로 대체
- `ngtsc-build.worker.ts`의 watch 경로 생성을 `pathx.posixResolve()`로 통일

### 비목표

- `ngtsc-build.worker.ts:122`의 `path.join(info.pkgDir, "src")` — watch 경로가 아닌 소스 필터 용도이며 즉시 `pathx.posix()`로 정규화되므로 변경 불필요

### 설계

#### vitest-plugin.ts

- `import { pathx } from "@simplysm/core-node";` 추가
- `normalizePath(filePath)` → `pathx.posix(filePath)` (line 103)
- `normalizePath(id)` → `pathx.posix(id)` (line 113)
- `normalizePath` 함수 정의 삭제 (lines 123-125)
- `import path from "path";`는 lines 58-59에서 사용 중이므로 유지

#### ngtsc-build.worker.ts

- lines 236-247의 `path.join()` → `pathx.posixResolve()` 교체 (8건)
- `import path from "path";`는 line 122에서 사용 중이므로 유지

### 대안 검토

없음 — 다른 worker에서 이미 확립된 패턴을 그대로 적용하는 것이므로 대안이 불필요하다.
