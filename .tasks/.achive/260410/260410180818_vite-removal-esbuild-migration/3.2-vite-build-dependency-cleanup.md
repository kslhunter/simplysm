## 구현계획

### 배경
Feature 3.1에서 빌드 파이프라인이 Vite에서 esbuild로 전환 완료됨. `engines/index.ts`가 `EsbuildClientEngine`을 사용하고, 빌드용 Vite 유틸 파일들(`vite-config.ts`, `vite-pwa-plugin.ts`, `vite-scope-watch-plugin.ts`, `vite-postcss-inline-plugin.ts`)이 이미 삭제됨. 이 Feature에서는 남은 의존성과 타입을 정리한다.

### 목표
- 빌드 전용 Vite 의존성 제거 (`vite-plugin-pwa`, `vite-plugin-solid`) [근거: wbs 범위]
- Vitest용 `vite`, `vite-tsconfig-paths`를 devDependencies로 이동 [근거: wbs 범위]
- `SdPwaWorkboxConfig` 타입 및 `SdPwaConfig.workbox` 필드 제거 [근거: Feature 1.3 D4]
- 미사용 `ViteEngine.ts` 파일 삭제 [근거: D1 결정]

### 비목표
- `vite` 패키지 완전 제거 — Vitest 의존 [근거: wbs 경계]
- `vite-angular-plugin.ts` 수정 — Vitest용으로 존속 [근거: wbs 경계]
- `SdPwaManifestConfig`, `SdPwaConfig.manifest` 변경 — `esbuild-pwa.ts`에서 활발히 사용 중 [근거: 코드 확인]
- 테스트 파일 업데이트 — Feature 3.3 범위 [근거: wbs Feature 3.3]

### 설계

#### 1. package.json 수정 [근거: wbs 범위 1, 2항]
- `dependencies`에서 제거: `vite-plugin-pwa` (^1.2.0), `vite-plugin-solid` (^2.11.12)
- `dependencies` → `devDependencies` 이동: `vite` (^7.3.2), `vite-tsconfig-paths` (^6.1.1)

#### 2. sd-config.types.ts 수정 [근거: Feature 1.3 D4]
- `SdPwaWorkboxConfig` 인터페이스 삭제 (lines 195-199)
- `SdPwaConfig.workbox` 필드 삭제 (line 206)
- `SdPwaManifestConfig`, `SdPwaConfig.manifest`, `SdPwaConfig` 인터페이스는 유지

#### 3. ViteEngine.ts 삭제 [근거: D1 결정]
- `engines/ViteEngine.ts` 파일 삭제
- `engines/index.ts`에서 이미 미참조이므로 추가 코드 변경 불필요

#### 4. pnpm-lock.yaml 갱신
- `pnpm install` 실행으로 lockfile 자동 갱신

### 대안 검토
- **ViteEngine.ts 유지 안**: Feature 경계 준수(Feature 3.1 범위)이나, engines/index.ts에서 이미 미참조된 미사용 파일이 잔류. D1 결정으로 삭제 선택.
