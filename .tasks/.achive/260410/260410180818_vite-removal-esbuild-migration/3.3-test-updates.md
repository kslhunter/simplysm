## 구현계획

### 배경
Feature 3.1에서 ViteEngine → EsbuildClientEngine 전환이 완료되고, Feature 3.2에서 Vite 빌드 의존성이 정리됨. 소스 코드 변경에 따라 테스트 정합성을 보장해야 함. [근거: wbs Feature 3.3 근거 "기존 테스트가 Vite API를 모킹하고 있어 전면 업데이트 필요"]

이전 Feature에서 이미 상당수 테스트가 수정/생성/삭제됨:
- 삭제됨: vite-config.spec.ts, vite-engine.spec.ts, vite-pwa-plugin.spec.ts, vite-scope-watch-plugin.spec.ts, client-worker.spec.ts, client-worker-legacy.spec.ts, linker-disk-cache.spec.ts, vite-angular-plugin-hmr.spec.ts, vite-angular-plugin-scss-hmr.spec.ts, vite-postcss-inline-plugin.spec.ts
- 생성됨: esbuild-client-engine.spec.ts, esbuild-client-config.spec.ts, dev-http-server.spec.ts, hmr-service.spec.ts, hmr-client-script.spec.ts, esbuild-index-html.spec.ts, esbuild-pwa.spec.ts, esbuild-scss-plugin.spec.ts, replace-deps-watch.spec.ts 등
- 수정됨: vite-angular-plugin.spec.ts, vite-angular-plugin-legacy-watch.spec.ts, vite-angular-plugin-vitest.spec.ts, base-engine.spec.ts, engine-selection.spec.ts, engine-adapter-isolation.spec.ts, angular-build.spec.ts
