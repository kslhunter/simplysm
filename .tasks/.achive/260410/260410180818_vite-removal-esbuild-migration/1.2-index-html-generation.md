### IndexHtmlGenerator API (node_modules 확인)
```typescript
class IndexHtmlGenerator {
  constructor(options: IndexHtmlGeneratorOptions);
  process(options: IndexHtmlGeneratorProcessOptions): Promise<IndexHtmlProcessResult>;
}

interface IndexHtmlGeneratorOptions {
  indexPath: string;
  entrypoints: [name: string, isModule: boolean][];
  sri?: boolean;
  crossOrigin?: 'none' | 'anonymous' | 'use-credentials';
  postTransform?: IndexHtmlTransform;
  deployUrl?: string;
  optimization?: NormalizedOptimizationOptions;
  cache?: NormalizedCachedOptions;
  imageDomains?: string[];
  generateDedicatedSSRContent?: boolean;
  autoCsp?: AutoCspOptions;
}

interface IndexHtmlGeneratorProcessOptions {
  lang: string | undefined;
  baseHref: string | undefined;
  outputPath: string;
  files: FileInfo[];
  hints?: { url: string; mode: HintMode; as?: string }[];
}

interface IndexHtmlProcessResult {
  csrContent: string;
  ssrContent?: string;
  warnings: string[];
  errors: string[];
}

interface FileInfo {
  file: string;
  name?: string;
  extension: string;
}

type IndexHtmlTransform = (content: string) => Promise<string>;
type Entrypoint = [name: string, isModule: boolean];
```

## 구현계획

### 배경
Feature 1.1a에서 `createClientEsbuildContext`(`esbuild-client-config.ts`)가 `metafile: true`로 esbuild context를 생성한다. 현재 Vite가 index.html 처리를 자동으로 수행하지만, Vite 제거 시 `IndexHtmlGenerator`(`@angular/build/private`)로 대체해야 한다.

### 목표
- esbuild metafile에서 JS/CSS 파일을 추출하여 index.html에 script/link 태그 자동 주입 [근거: Rule "metafile → FileInfo 변환"]
- build 모드에서 SRI 해시 생성 [근거: Rule "SRI build 모드만"]
- dev 모드에서 HMR 스크립트 주입 훅 제공 [근거: Rule "postTransform HMR 훅"]
- polyfills entry를 script 태그로 주입 [근거: Rule "모든 entrypoints isModule=true"]

### 비목표
- HMR 클라이언트 스크립트 내용 구현 [근거: WBS 경계 "Feature 2.2에서 처리"]
- PWA manifest/SW 스크립트 주입 [근거: WBS 경계 "Feature 1.3에서 처리"]
- HTML 최적화(critical CSS inlining) [근거: D5 결정]
- SSR 관련 기능 [근거: WBS "sd-cli 미사용"]

### 설계

**새 파일**: `packages/sd-cli/src/utils/esbuild-index-html.ts`

```typescript
import type esbuild from "esbuild";
import {
  IndexHtmlGenerator,
  type IndexHtmlTransform,
} from "@angular/build/private";
import path from "path";

export interface GenerateIndexHtmlOptions {
  /** src/index.html 경로 */
  indexPath: string;
  /** esbuild 빌드 결과 metafile */
  metafile: esbuild.Metafile;
  /** 출력 디렉토리 (dist/) */
  outdir: string;
  /** <base href> (기본: "/") */
  baseHref?: string;
  /** 빌드 모드 */
  mode: "dev" | "build";
  /** entryPoints의 이름 목록 (main, polyfills 등) */
  entryNames: string[];
  /** HTML 후처리 훅 (HMR 스크립트 주입용) */
  postTransform?: IndexHtmlTransform;
}

export interface GenerateIndexHtmlResult {
  content: string;
  warnings: string[];
  errors: string[];
}
```

**핵심 로직:**

1. `extractFilesFromMetafile(metafile, outdir)`:
   - `metafile.outputs` 순회
   - key에서 `path.relative(outdir, key)`로 상대경로 변환
   - `.js`, `.css` 확장자만 포함
   - `entryPoint` 필드 존재 시 `name`에 파일명(확장자 제외) 설정
   - `FileInfo[]` 반환

2. `entryNames` → `Entrypoint[]` 변환:
   - `entryNames.map(n => [n, true] as [string, boolean])`

3. `IndexHtmlGenerator` 인스턴스 생성:
   - `indexPath`, `entrypoints`, `sri: mode === "build"`, `postTransform`

4. `generator.process()` 호출:
   - `lang: undefined`, `baseHref`, `outputPath: outdir`, `files`

5. 결과 반환:
   - `{content: result.csrContent, warnings: result.warnings, errors: result.errors}`

### 대안 검토
| 방안 | 설명 | 선택 여부 |
