## 구현계획

### 배경

`SdThemeProvider`가 `dark` WritableSignal로 다크 모드 상태를 관리하고, `provideSdAngular.ts`의 `provideEnvironmentInitializer`에서 localStorage 동기화를 처리하는 구조가 이미 구축되어 있다. 동일한 패턴으로 폰트 크기 상태를 추가한다.

기존 CSS 변수 시스템(`_variables.scss`)의 `font-size` 항목들이 `rem` 단위를 사용하므로, HTML root `font-size`를 변경하면 모든 rem 기반 크기가 자동으로 비례 조절된다. [근거: `_variables.scss:87-97` font-size 맵이 rem 단위 사용]

### 목표

- `SdThemeProvider`에 폰트 크기 signal + 프리셋 + 증감 메서드 추가 [근거: Rule "기본 폰트 크기", "프리셋", "증가/감소"]
- HTML root `font-size`를 signal에 연동하는 effect 추가 [근거: Rule "HTML root font-size 연동"]
- localStorage에 폰트 크기 설정을 영속화 [근거: Rule "localStorage 영속화"]

### 비목표

- UI 컴포넌트 (스테퍼, 드롭다운 등) [근거: wbs 경계 "UI 컴포넌트는 Feature 1.2에서 다룸"]
- 프리셋 값 목록의 커스터마이징 [근거: wbs 경계 "프리셋 커스터마이징은 다루지 않음"]

### 설계

#### SdThemeProvider 변경 (`sd-theme-provider.ts`)

기존 `dark` signal 옆에 폰트 크기 관련 상태와 메서드를 추가한다:

```typescript
// 프리셋 배열 (readonly)
readonly fontSizePresets: readonly number[] = [12, 14, 16, 20, 24, 28];

// 현재 폰트 크기 signal (기본값 16)
fontSize = signal<number>(16);

// constructor 내 effect 추가
effect(() => {
  document.documentElement.style.fontSize = `${this.fontSize()}px`;
});

// 증감 메서드
increaseFontSize(): void { ... }  // 프리셋에서 현재값보다 큰 첫 번째 값으로 이동
decreaseFontSize(): void { ... }  // 프리셋에서 현재값보다 작은 마지막 값으로 이동
```

[근거: 기존 `dark` signal 패턴. 증감 메서드는 `find`/역순 순회로 프리셋 외 값에도 안전하게 동작]

#### provideSdAngular.ts 변경

기존 dark mode localStorage 동기화 블록(`provideEnvironmentInitializer`, line 50-66) 내에 동일 패턴으로 fontSize 동기화를 추가한다:

```typescript
// font size localStorage 동기화 (dark mode 패턴과 동일)
const savedFontSize = sdLocalStorage.get("sd-theme-font-size");
if (savedFontSize != null) {
  sdTheme.fontSize.set(savedFontSize);
}
let prevFontSize = sdTheme.fontSize();
effect(() => {
  const fontSize = sdTheme.fontSize();
  if (fontSize !== prevFontSize) {
    sdLocalStorage.set("sd-theme-font-size", fontSize);
    prevFontSize = fontSize;
  }
});
```

[근거: `provideSdAngular.ts:50-66` dark mode 동기화 패턴 재사용]

### 대안 검토

| 대안 | 설명 | 미선택 사유 |
|------|------|------------|
| CSS 변수 방식 (`--font-size-base` 변경) | CSS custom property를 변경하여 간접적으로 폰트 크기 조절 | wbs에서 "html root font-size 조정" 방식을 명시적으로 선택함. rem 기반 시스템에서 root font-size 변경이 더 직관적이고 모든 rem 값에 자동 적용됨 |
| 증감 메서드를 외부 유틸리티로 분리 | SdThemeProvider 외부에 `adjustThemeFontSize()` 같은 함수 배치 | 테마 상태 관리는 SdThemeProvider의 단일 책임. 분리하면 상태와 로직이 흩어져 응집도 저하 |
