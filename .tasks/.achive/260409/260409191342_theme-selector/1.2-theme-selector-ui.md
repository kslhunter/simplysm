## 구현계획

### 배경

Feature 1.1에서 `SdThemeProvider`에 `fontSize` signal, `fontSizePresets`, `increaseFontSize()`/`decreaseFontSize()` 메서드, HTML root font-size effect, localStorage 동기화가 모두 구현되었다. 기존 `dark` signal과 함께 테마 상태 관리 인프라가 완비된 상태이다.

코드베이스의 드롭다운 버튼 패턴(`sd-topbar-user.ts`)과 아이콘 버튼 패턴(`sd-topbar.ts`)을 활용하여 테마 선택기 UI를 구성한다. [근거: `sd-topbar-user.ts` sd-dropdown + sd-button 구조, `sd-topbar.ts` 아이콘 버튼]

### 목표

- `sd-theme-selector` standalone 컴포넌트 생성 [근거: Rule "드롭다운 트리거"]
- 폰트 크기 스테퍼 UI 구현 (경계 비활성화 포함) [근거: Rule "폰트 크기 스테퍼", "스테퍼 경계 비활성화"]
- 다크 모드 sd-switch 토글 구현 [근거: Rule "다크 모드 토글"]
- index.ts에 export 추가

### 비목표

- 상태 관리/localStorage 로직 [근거: Feature 1.1에서 처리 완료]
- topbar 등 특정 위치에의 배치 [근거: wbs 경계 "소비 프로젝트 영역"]

### 설계

#### 컴포넌트 구조 (`sd-theme-selector.ts`)

기존 컴포넌트 패턴(OnPush, ViewEncapsulation.None, standalone) 준수. [근거: CLAUDE.md Key Patterns]

```
sd-dropdown
├── sd-button (inline, link-gray) > ng-icon (tablerPalette)
└── sd-dropdown-popup
    └── div (padding wrapper)
        ├── div (row: "글자 크기" + stepper)
        │   ├── span "글자 크기"
        │   └── div (stepper row)
        │       ├── sd-button [-] (disabled when min)
        │       ├── span "16px"
        │       └── sd-button [+] (disabled when max)
        └── div (row: "다크 모드" + switch)
            ├── span "다크 모드"
            └── sd-switch [(value)]="sdTheme.dark"
```

**imports:** `SdDropdown`, `SdDropdownPopup`, `SdButton`, `SdSwitch`, `NgIcon`
**inject:** `SdThemeProvider`
**computed signals:**
- `isMinFontSize`: `fontSize() <= fontSizePresets[0]`
- `isMaxFontSize`: `fontSize() >= fontSizePresets[last]`

[근거: `sd-topbar-user.ts` sd-dropdown 사용 패턴, `sd-switch.ts` value model() 바인딩]

#### 팝업 콘텐츠 스타일링

`sd-dropdown`은 팝업을 `document.body`로 이동시키므로(`sd-dropdown.ts:70`), 팝업 내부 스타일은 `sd-theme-selector` 하위 선택자로 접근 불가. 유틸리티 클래스(`flex-row`, `p-default`, `gap-*`)와 인라인 스타일로 레이아웃 처리. [근거: `sd-dropdown.ts:70` body appendChild]

#### index.ts 변경

`// ui/theme` 섹션을 추가하여 `SdThemeSelector`를 export. [근거: 기존 index.ts export 패턴]

### 대안 검토

| 대안 | 설명 | 미선택 사유 |
|------|------|------------|
| sd-list 기반 팝업 | sd-topbar-user처럼 sd-list/sd-list-item으로 메뉴 구성 | 스테퍼 UI와 스위치를 list item으로 넣기에 부자연스러움. 커스텀 레이아웃이 더 적합 |
| 별도 sd-font-size-stepper 컴포넌트 분리 | 스테퍼를 범용 컴포넌트로 추출 | wbs에서 "테마 선택기에 직접 구현" 결정. 현재 재사용 수요 없음 |
