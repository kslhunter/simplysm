## 구현계획

### 배경

excel 패키지의 `ExcelWorkbook`에 `async [Symbol.asyncDispose]()` 래퍼 메서드가 존재하며, `ExcelWrapper.read()`에서 `await using` 구문으로 리소스를 관리한다. dist 출력물에 이 구문들이 그대로 노출되어 Node.js 20 기반 소비앱에서 파싱 에러를 유발한다. [근거: wbs 배경]

### 목표

- `async [Symbol.asyncDispose]()` 래퍼 메서드 제거 [근거: Rule "래퍼 메서드 완전 제거"]
- `await using` 코드 구문을 try-finally + `close()`로 대체 [근거: Rule "try-finally 대체"]
- JSDoc의 `await using` 예시 제거 [근거: Rule "JSDoc 예시 변경"]

### 비목표

- `close()` 메서드 변경 [근거: wbs 경계 "기존 메서드 유지"]
- LLM 참조 문서 변경 [근거: Feature 1.4에서 별도 처리]

### 설계

1. **`excel-workbook.ts`**: `async [Symbol.asyncDispose]()` 메서드 3줄 삭제. 클래스 JSDoc에서 `await using` 예시 블록(line 25~29) 제거, try-finally 예시만 유지. [근거: D1, D2]

2. **`excel-wrapper.ts` read()**: `await using wb = new ExcelWorkbook(file);` → `const wb = new ExcelWorkbook(file);`로 변경하고, 이후 로직 전체를 try 블록으로 감싸며, finally에서 `await wb.close();`를 호출. [근거: D3]

3. **`excel-wrapper.ts` write() JSDoc**: `await using`을 사용하거나` 문구 제거, `사용 후 `close()`를 호출해야 한다.`로 변경. 예시 코드를 try-finally 패턴으로 변경. [근거: D2]

### 대안 검토

해당 없음. Feature 1.1과 동일하게 유일한 접근 방식이다.
