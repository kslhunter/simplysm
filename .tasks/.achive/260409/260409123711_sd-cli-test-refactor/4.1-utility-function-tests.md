### 설계

#### 1. core-node importOriginal 패턴 도입 [근거: Rule "로직 복제 모킹 제거"]

현행 — core-node 전체 모킹, 순수 함수까지 로직 복제:
```typescript
vi.mock("@simplysm/core-node", () => ({
  pathx: {
    posix: vi.fn((p: string) => p.replace(/\\/g, "/")),        // 실제 로직 복제
    posixResolve: vi.fn((...args) => args.join("/").replace(/\\/g, "/")), // 실제 로직 복제
    isChildPath: vi.fn((child, parent) => child.startsWith(parent + "/")), // 실제 로직 복제
  },
  fsx: { exists: vi.fn() },
}));
```

변경 — importOriginal로 순수 함수 복원:
```typescript
vi.mock("@simplysm/core-node", async (importOriginal) => {
  const actual = await importOriginal<typeof import("@simplysm/core-node")>();
  return {
    ...actual,                              // pathx 순수 함수 실제 사용
    fsx: { exists: vi.fn() },              // I/O만 모킹
    FsWatcher: { watch: vi.fn() },         // I/O만 모킹
    Worker: { create: vi.fn() },           // Worker만 모킹
  };
});
```

적용 대상: `copy-src`, `sd-config`, `tsc-build`, `typecheck-env` (4개 파일)
