## 구현계획

### 배경

`replace-deps.ts` (411줄)에 4가지 기능이 하나의 파일에 집중되어 있다:
- 패턴 매칭/해석: `resolveReplaceDepEntries`, `parseWorkspaceGlobs`, `collectSearchRoots`, `resolveAllReplaceDepEntries`
- 실행: `setupReplaceDeps` (일회성 복사), `watchReplaceDeps` (감시 모드)

해석 로직은 publish.ts에서도 독립적으로 사용되고 (`parseWorkspaceGlobs`), 실행 로직과 관심사가 다르다.

### 목표
- 해석과 실행 로직을 별도 파일로 분리하여 파일당 책임 단일화 [근거: wbs STRUCT-002]

### 비목표
- replace-deps 기능의 동작 변경 [근거: wbs 경계]
- 새로운 기능 추가 [근거: wbs 경계]

### 설계

**파일 구조 (분할 후):**

```
utils/
├── replace-deps-resolve.ts  ← 신규 (~170줄)
│   ├── resolveReplaceDepEntries()    (export)
│   ├── parseWorkspaceGlobs()         (export)
│   ├── collectSearchRoots()          (내부)
│   ├── resolveAllReplaceDepEntries() (export — replace-deps.ts에서 사용)
│   └── ReplaceDepEntry              (export interface)

└── replace-deps.ts          ← 기존 (~240줄)

    ├── watchReplaceDeps()            (export)
    └── WatchReplaceDepResult         (export interface)
```
