## 구현계획

### 배경

@simplysm/angular 패키지에서 overlay 관련 provider 5개(busy, toast, activated-modal, print, theme)가 `core/providers/`에 있어 관련 컴포넌트와 물리적으로 분리되어 있다. SdModalProvider는 이미 `ui/overlay/modal/`에 동거하고 있어, 나머지도 같은 패턴으로 통일해야 한다. [근거: WBS "SdModalProvider는 이미 ui/overlay/modal/에 있으나, 같은 역할의 SdBusyProvider/SdToastProvider/SdActivatedModalProvider는 core/providers/에 있는 비일관적 배치"]

### 목표

- overlay/theme/print provider를 관련 컴포넌트 폴더로 이동하여 기능 단위 동거 패턴 통일 [근거: Rule "Overlay provider는 해당 component 폴더에 동거한다"]
- provideSdAngular.ts를 src/ 루트로 이동하여 composition root 역할 명확화 [근거: Rule "Composition root는 src/ 루트에 위치한다"]
- 모든 import/export 경로를 새 위치에 맞게 업데이트 [근거: Rule "기존 테스트가 모두 통과한다"]

### 비목표

- 파일 내용(로직, 타입, 시그니처) 변경 [근거: WBS 경계 "파일 내용은 변경하지 않음"]
- 공개 API(index.ts export 이름/타입) 변경 [근거: WBS 경계]
- 범용 서비스(config, log 등) 이동 [근거: WBS 경계]
- 테스트 파일 위치 이동 [근거: WBS "기존 테스트 import 경로 업데이트"]
