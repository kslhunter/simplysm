## 구현계획

### 배경

`worker-events.ts`에는 이전 구현의 잔재인 `registerWorkerEventHandlers()` 함수와 관련 타입(`BaseWorkerInfo`, `WorkerEventHandlerOptions`)이 남아 있다. 실제 프로덕션 코드(`BaseEngine`, `EsbuildClientEngine`)는 `engine-watch-events.ts`의 `setupWatchEvents()`를 사용한다. `registerWorkerEventHandlers`는 `src/` 내에서 0곳 import되며, 테스트(`worker-events.spec.ts`)에서만 참조된다.

### 목표
- 미사용 함수 및 관련 타입 제거로 dead code 해소 [근거: STRUCT-001]
- 이벤트 데이터 타입만 남겨서 파일의 역할을 명확화 [근거: wbs 범위]

### 비목표
- `engine-watch-events.ts` 수정 [근거: wbs 경계]
- `worker-events.ts` 파일 삭제 [근거: wbs 경계 "이벤트 데이터 타입이 남아있으므로"]

### 설계

단순한 코드 삭제 작업. 구조 변경 없음:
1. `worker-events.ts`에서 미사용 export 3개(`registerWorkerEventHandlers`, `BaseWorkerInfo`, `WorkerEventHandlerOptions`)와 관련 import(`consola`, `BuildResult`, `SdPackageConfig`, `RebuildManager`, `formatBuildMessages`)/변수(`workerEventsLogger`) 삭제
2. `worker-events.spec.ts` 파일 전체 삭제
3. `pnpm check sd-cli`로 검증

### 대안 검토

없음. 단순 삭제 작업이므로 대안이 필요하지 않음.
