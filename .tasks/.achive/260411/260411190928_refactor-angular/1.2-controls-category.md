## 구현계획

### 배경

Feature 1.1에서 core/ 내부가 기능별로 재구조화되고 인프라 디렉토리가 core/로 통합되었다. 현재 src/ top-level에 UI 기본요소 디렉토리(button, checkbox 등)가 layout, data, features와 같은 레벨에 혼재하고 있다. 이 디렉토리들은 의존성 분석상 core/만 의존하는 동일 계층으로, controls/ 카테고리로 그룹화하여 아키텍처 계층을 반영한다. [근거: wbs "의존성 분석: 이 디렉토리들은 core/만 의존하는 UI 기본요소 계층"]

### 목표

- 11개 UI 컨트롤 디렉토리를 controls/ 카테고리로 그룹화 [근거: Rule "11개 디렉토리가 controls/ 하위로 이동"]
- 모든 import/export 경로를 새 위치에 맞게 갱신 [근거: Rule "core/ 참조 갱신", "외부 참조 갱신", "index.ts 갱신"]
- tests/ 미러링 유지 [근거: 설계 결정 D1]

### 비목표

- 각 디렉토리 내부 파일 구조 변경 [근거: wbs 경계 "각 디렉토리 내부 파일 구조는 변경하지 않음"]
- 코드 로직 변경 [근거: wbs 경계 "코드 로직 변경 없음"]
- scss/ 디렉토리 이동 [근거: wbs 제외 사항]

### 설계

#### 파일 이동 전략

Feature 1.1과 동일하게 `git mv`로 이동하여 git 히스토리를 보존한다. controls/ 내 상호 참조는 같은 depth 이동이므로 경로 변경 불필요 (설계 결정 D2). [근거: Feature 1.1 확립 패턴]

#### import 경로 수정 분류

| 분류 | 변경 내용 | 영향 파일 수 |
|------|-----------|-------------|
| A. controls/ 내부 → core/ | `../core/` → `../../core/` | ~12개 |
| B. controls/ 내 상호 참조 | 변경 없음 (같은 depth) | 0개 |
| C. 외부 src/ → controls/ | `../button/` → `../controls/button/` 등 | ~30개 |
| D. core/ → controls/ | `../button/` → `../../controls/button/` (core/modal/ 등에서) | ~3개 |
| E. index.ts | `./button/` → `./controls/button/` 등 | ~50개 export 문 |
| F. tests/ | `../../src/button/` → `../../src/controls/button/` 등 | ~25개 |

#### 분류 A 상세 (controls/ 내부 → core/ 참조)

| 파일 | 현재 import | 변경 후 |
|------|-----------|---------|
| button/sd-button.ts | `../core/ripple/sd-ripple` | `../../core/ripple/sd-ripple` |
| button/sd-modal-select-button.ts | `../core/modal/`, `../core/validation/`, `../core/select-modal-output-result` | `../../core/` prefix |
| checkbox/sd-checkbox.ts | `../core/ripple/setupRipple`, `../core/setupModelHook` | `../../core/` prefix |
| select/sd-select.ts | `../core/template/`, `../core/ripple/`, `../core/validation/` | `../../core/` prefix |
| select/sd-select-button.ts | `../core/ripple/setupRipple` | `../../core/` prefix |
| input/sd-textfield.ts | `../core/validation/setupInvalid` | `../../core/` prefix |
| input/sd-textarea.ts | `../core/validation/setupInvalid` | `../../core/` prefix |
| collapse/sd-collapse.ts | `../core/events/sd-resize-event.plugin` | `../../core/` prefix |
| list/sd-list-item.ts | `../core/ripple/setupRipple` | `../../core/` prefix |

#### 분류 D 상세 (core/ 내부 → controls/ 참조)

| 파일 | 현재 import | 변경 후 |
|------|-----------|---------|
| core/modal/sd-confirm-modal.ts | `../../button/sd-button` | `../../controls/button/sd-button` |

### 대안 검토

| 대안 | 검토 결과 |
|------|-----------|
| 디렉토리별 개별 이동+수정 | 불필요한 중간 단계. 설계 결정 D2에 의해 일괄 이동이 안전하고 효율적 |
| tsconfig path alias 도입 | 현재 코드베이스가 상대경로 사용. 일관성 유지를 위해 제외 |
