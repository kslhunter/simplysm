## 구현계획

### 배경

현재 v14 sd-cli의 Client 빌드는 Vite + Angular 컴파일 플러그인(`sdAngularPlugin`) 기반이다. `createClientViteConfig()`에서 플러그인 체인을 구성하며, `client.worker.ts`가 dev/build 모드를 분기한다. v14 _back에 `vite-plugin-pwa` 기반 PWA 구현이 존재했으나 현재 버전에서 제거된 상태이다.

### 목표

- `vite-plugin-pwa`를 Client 프로덕션 빌드에 통합하여 PWA manifest + service worker를 자동 생성한다
- `sd.config.ts`의 `pwa` 필드로 커스터마이징 지원 (기본 활성화, `false`로 비활성화)
- `sharp`를 사용하여 원본 아이콘에서 PWA 아이콘을 자동 생성한다

### 비목표

- dev 모드에서의 service worker 등록 (D2 결정)
- `@angular/service-worker` (ngsw) 통합
- 오프라인 전략 커스터마이징 (Workbox runtimeCaching 등) — 기본 precache만 지원

### 설계

#### 타입 정의

```typescript
// sd-config.types.ts에 추가

export interface SdPwaManifestConfig {
  name?: string;
  short_name?: string;
  display?: string;
  theme_color?: string;
  background_color?: string;
  icons?: Array<{ src: string; sizes: string; type?: string }>;
}

export interface SdPwaWorkboxConfig {
  globPatterns?: string[];
}

export interface SdPwaConfig {
  manifest?: SdPwaManifestConfig;
  workbox?: SdPwaWorkboxConfig;
}

export interface SdClientPackageConfig {
  // ... 기존 필드
  /** PWA 설정. false로 비활성화. 미설정 시 기본값으로 활성화 */
  pwa?: false | SdPwaConfig;
}
```

#### VitePWA 플러그인 통합

`createClientViteConfig()`에 `pwa` 옵션 추가:
- `mode === "build"` && `pwa !== false`일 때만 VitePWA 플러그인 포함
- manifest 기본값: `name`/`short_name` = package.json name (scope 제거), `display` = "standalone", `theme_color`/`background_color` = "#ffffff"
- workbox 기본값: `globPatterns: ["**/*.{js,css,html,ico,png,svg,woff2}"]`
- `registerType: "prompt"`, `injectRegister: "script"`

#### 아이콘 자동 생성

`generatePwaIcons()` 유틸 함수:
- 입력: `pkgDir` (패키지 디렉토리)
- `public/icon.png` 또는 `public/icon.svg` 탐색
- sharp로 192x192, 512x512 리사이즈 → `public/icons/icon-192x192.png`, `public/icons/icon-512x512.png`에 저장
- 반환: `ManifestIcon[]` 배열 (없으면 빈 배열)
- `pwa.manifest.icons`가 커스텀 설정되어 있으면 자동 생성 스킵

#### 데이터 흐름

```
sd.config.ts (pwa 필드)
  ↓
client.worker.ts (ClientBuildInfo에 pwa 포함)
  ↓
createClientViteConfig() (pwa 옵션)
  ↓
[mode === "build" && pwa !== false]
  ├→ generatePwaIcons() → icons 배열
  └→ VitePWA({ manifest, workbox }) 플러그인 추가
```
