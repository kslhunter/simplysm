## 구현계획

### 배경

`@simplysm/excel`은 Excel OOXML(.xlsx)을 ZIP+XML로 직접 처리하는 라이브러리다. 코드 리뷰에서 5건의 이슈가 발견되었으며, 모두 내부 로직 수정으로 해결 가능하다.

### 목표

- 5건의 리뷰 이슈를 모두 수정한다
- 기존 테스트를 업데이트하고, 새 테스트를 추가한다
- 공개 API 시그니처 변경 없이 내부 동작만 수정한다

### 비목표

- 성능 최적화 (예: setDataMatrix 병렬화)
- 새 기능 추가
- 타임존 DST 관련 에지케이스 처리

### 설계

#### LOGIC-001: stringifyColAddr bijective base-26 수정

while 루프에서 `remained -= 1`을 추가하고 오프셋을 65로 통일.

#### LOGIC-002: convertNumFmtCodeToName 시간 형식 판별

- "h" 또는 "hh" 뒤에 오는 "mm"을 치환한 문자열에서 날짜 판별
- `hasTime` 판별에서 `/hh/i`를 `/h{1,2}/i`로 변경하여 단일 "h"도 시간으로 인식

#### LOGIC-003: insertCopyRow 병합 확장

- `insertCopyRow`의 마지막 `copyRow` 호출을 `skipMerge: true`로 변경
- `shiftMergeCells`가 이미 관통 병합을 확장하므로, 추가로 단일행 병합만 별도 복사

#### LOGIC-004: getDataTable 중복 헤더 검사

- `headerMap.set` 전에 `headerMap.has` 검사 추가, 중복 시 에러 throw

#### DESIGN-001: ExcelWrapper.write 에러 시 리소스 해제

- try-catch로 감싸서 에러 시 `wb.close()` 호출 후 재throw

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| LOGIC-002: "mm"을 h/hh 뒤에서 치환 후 판별 | 채택 | 기존 날짜 포맷 판별 로직 최소 변경 |
| LOGIC-002: 전체 포맷을 토큰으로 파싱 | 미채택 | 과잉 구현. 정규식 수준으로 충분 |
| LOGIC-003: copyRow 내부에서 병합 확장 처리 | 미채택 | copyRow의 단순 복사 책임이 복잡해짐 |
| LOGIC-003: insertCopyRow에서 skipMerge + 단일행만 복사 | 채택 | shiftMergeCells가 이미 확장 처리. 최소 변경 |
