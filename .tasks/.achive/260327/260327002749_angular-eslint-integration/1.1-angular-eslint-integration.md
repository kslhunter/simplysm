# Feature 1.1 Angular ESLint 통합

## 참조 자료

### 현재 구조
- `packages/lint/package.json`: `@simplysm/lint` 퍼블리시 패키지
- `packages/lint/src/eslint-recommended.ts`: JS/TS/tests 블록으로 구성된 공용 ESLint config, `defineConfig()` 래퍼 사용
- `packages/lint/src/eslint-plugin.ts`: 커스텀 룰 (`no-hard-private`, `no-subpath-imports-from-simplysm`, `ts-no-throw-not-implemented-error`)
- `eslint.config.ts` (루트): `eslint-recommended`를 spread하여 전체 적용

### angular-eslint 구조 (공식 문서 기반)
- `angular.configs.tsRecommended`: Angular TS 규칙
- `angular.configs.templateRecommended`: Angular HTML 템플릿 규칙
- `angular.configs.templateAccessibility`: 접근성 규칙
- `angular.processInlineTemplates`: 인라인 템플릿 프로세서
- 공식 래퍼: `tseslint.config()`

### 소비자 환경
- 모든 소비자가 Angular 사용 monorepo
- 이 프로젝트와 유사한 패키지 구조

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | 별도 export vs recommended 통합 | recommended 통합 | 모든 소비자가 Angular 사용, 분리 불필요 |
| D2 | component-selector/directive-selector prefix | recommended에서 제외 | 프로젝트마다 prefix가 다름, 소비자가 직접 설정 |
| D3 | ESLint 래퍼 함수 | `tseslint.config()`로 통일 | angular-eslint 공식 권장, `defineConfig()` 교체 |
| D4 | angular-eslint 버전 | `^21.3.1` | ESLint ^9, typescript-eslint ^8 호환, peerDep: @angular/cli >= 21 |

## 구현계획

### 배경

`@simplysm/lint` 패키지의 `eslint-recommended` config은 JS/TS 프로젝트를 위한 공용 ESLint 설정이다. 현재 `defineConfig()` 래퍼를 사용하며, Angular 관련 규칙이 없다. 모든 소비자가 Angular monorepo이므로 Angular ESLint 규칙을 recommended에 통합한다.

### 목표

- `eslint-recommended`에 Angular ESLint TS/템플릿 규칙 추가
- `defineConfig()` → `tseslint.config()` 래퍼 교체
- 기존 JS/TS/tests 규칙 유지

### 비목표

- `component-selector`, `directive-selector` prefix 설정 (소비자가 직접 설정)
- `eslint-plugin.ts` 변경 (커스텀 룰은 현재 상태 유지)
- 별도 `eslint-angular` export 생성

### 설계

#### eslint-recommended.ts 변경

- `defineConfig()`, `globalIgnores` import 제거 → `tseslint.config()` 사용
- `globalIgnores([...])` → `{ ignores: [...] }` 평문 객체로 교체
- `import angular from "angular-eslint"` 추가
- 기존 TS 블록(`files: ["**/*.ts"]`)에 `extends: [...angular.configs.tsRecommended]` + `processor: angular.processInlineTemplates` 추가
- 새 HTML 블록 추가: `files: ["**/*.html"]`, `extends: [...angular.configs.templateRecommended, ...angular.configs.templateAccessibility]`

#### package.json 변경

- `angular-eslint: "^21.3.1"` dependency 추가

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| recommended에 통합 | 채택 | 모든 소비자가 Angular 사용, 별도 export 불필요 |
| 별도 eslint-angular export | 미채택 | non-Angular 소비자 없음, 분리 이점 없음 |
| defineConfig() 유지 + angular 추가 | 미채택 | angular-eslint 공식이 tseslint.config() 기준, 생태계 호환성 |
