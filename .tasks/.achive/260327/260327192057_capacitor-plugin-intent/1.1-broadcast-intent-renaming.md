## 구현계획

### 배경

`capacitor-plugin-broadcast` 패키지를 `capacitor-plugin-intent`로 리네이밍한다. Epic 2에서 추가될 startActivityForResult 기능을 포함하는 더 넓은 범위의 플러그인명을 반영하기 위함이다. 패키지 구조: TypeScript (src/ 4파일) + Android Kotlin (android/ 1파일) + 설정 파일. 모노레포 내 다른 패키지가 이 패키지에 의존하지 않으므로 외부 영향 범위가 없다.

### 목표

- 패키지 디렉토리, npm 이름, Capacitor 등록명, Android namespace를 broadcast에서 intent로 일괄 변경
- TypeScript 공개 API(인터페이스, 클래스, 타입) 이름을 Intent 접두사로 변경
- Android Kotlin 패키지 경로와 클래스명을 intent로 변경
- 모노레포 빌드 설정과 문서 참조 업데이트

### 비목표

- startActivityForResult 기능 추가 (Feature 2.1)
- npm 구 패키지(`@simplysm/capacitor-plugin-broadcast`) deprecation (배포 전략)
- 메서드별 JSDoc "브로드캐스트" 표현 변경 (기능 자체의 설명이므로 유지)
- Android 소스 경로 `kotlin/` → `java/` 통일 (기존 구조 유지)
