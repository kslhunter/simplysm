## 구현계획

### 배경

`loadDaumPostcodeScript()` 함수(`sd-address-search.modal.ts:44-85`)에서 스크립트 로드 실패 시 `<script id="daum_address">` 요소가 DOM에 남아, 재시도 시 이미 실패한 요소를 찾아 이벤트 리스너를 등록하지만 이벤트가 발생하지 않아 Promise가 hang된다. [근거: review.md LOGIC-005]

### 목표
- onerror/error 핸들러에서 스크립트 요소를 DOM에서 제거하여 재시도 가능하게 함 [근거: Rule "스크립트 로드 실패 시 DOM에서 스크립트 요소를 제거"]
- Feature 1.1 문서 설계 섹션을 D2 결정에 맞게 수정 [근거: Rule "D2 결정과 설계 섹션 일관성"]

### 비목표
- 정상 흐름(성공, 이미 로드) 변경 [근거: wbs 경계]

### 설계

#### LOGIC-005: onerror에 element.remove() 추가

현재 (`sd-address-search.modal.ts`):

```typescript
// 새 스크립트 분기 (:79-82)
scriptEl.onerror = (): void => {
  reject(new Error("주소 검색 스크립트를 불러올 수 없습니다."));
};

// 기존 스크립트 분기 (:60-65)
existing.addEventListener("error", () => {
  reject(new Error("주소 검색 스크립트를 불러올 수 없습니다."));
}, { once: true });
```

변경:

```typescript
// 새 스크립트 분기
scriptEl.onerror = (): void => {
  scriptEl.remove();
  reject(new Error("주소 검색 스크립트를 불러올 수 없습니다."));
};

// 기존 스크립트 분기
existing.addEventListener("error", () => {
  existing.remove();
  reject(new Error("주소 검색 스크립트를 불러올 수 없습니다."));
}, { once: true });
```

영향 파일: `packages/angular/src/features/address/sd-address-search.modal.ts`
