# Feature 1.1 CompilerPluginOptions를 Angular CLI 표준에 맞게 수정

## 참조 자료

- WBS: [wbs.md](./wbs.md)
- 디버그 분석: [debug.md](../260412181207_debug-jit-forbid-orphan/debug.md)
- Angular CLI 소스: `createCompilerPluginOptions` 함수 (`packages/angular/build/src/tools/esbuild/compiler-plugin-options.ts`)
- 에러 원문: `JIT mode support ("supportJitMode" option) cannot be disabled when forbidOrphanComponents is set to true`

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---|---|---|
| D1 | `includeTestMetadata` 값 | `isDev` (dev: true, build: false) | Angular CLI: `!optimizationOptions.scripts` — dev에서 scripts 최적화 꺼짐 → true |
| D2 | `browserOnlyBuild` 처리 | 제거 | `CompilerPluginOptions` 공식 인터페이스에 존재하지 않음 |
| D3 | `incremental` 값 | `isDev` | Angular CLI: `!!options.watch` — watch(dev) 모드에서만 incremental |

## 구현계획

### 배경

`packages/sd-cli/src/esbuild/esbuild-client-config.ts`의 `createClientEsbuildContext` 함수에서 `@angular/build/private`의 `createCompilerPlugin`을 호출할 때 `CompilerPluginOptions`를 구성한다. Angular 21.2.7에서 `supportJitMode = !!pluginOptions.includeTestMetadata`로 매핑되는데, sd-cli가 `includeTestMetadata`를 전달하지 않아 `supportJitMode: false`가 되어 `forbidOrphanComponents: true`와 충돌한다. [근거: 디버그 분석]

### 목표

- `CompilerPluginOptions`를 Angular CLI의 `createCompilerPluginOptions`와 일치시킨다 [근거: Rule "Angular CLI 패턴"]
- 공식 인터페이스에 없는 속성을 제거한다 [근거: Rule "공식 인터페이스"]

### 비목표

- `BundleStylesheetOptions`의 `inlineStyleLanguage` 타입 캐스팅 정리 [근거: wbs 경계]
- 프로덕션 빌드에서 `forbidOrphanComponents` + `includeTestMetadata: false` 조합 처리 [근거: wbs 경계 — Angular 자체 제약]

### 설계

**변경 파일:**

1. `packages/sd-cli/src/esbuild/esbuild-client-config.ts:68-78`
   - `pluginOptions` 타입: `CompilerPluginOptions` (캐스팅 제거)
   - `includeTestMetadata: isDev` 추가
   - `browserOnlyBuild: true` 제거
   - `incremental: isDev`로 변경

2. `packages/sd-cli/tests/utils/esbuild-client-config.acc.spec.ts:111`
   - `browserOnlyBuild` assertion → `includeTestMetadata` assertion

### 대안 검토

- `includeTestMetadata: true` (항상) — 프로덕션에서도 TestBed 메타데이터가 포함되어 번들 크기 증가. Angular CLI 패턴과 불일치.
