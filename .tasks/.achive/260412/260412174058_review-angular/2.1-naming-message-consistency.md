## 구현계획

### 배경
Angular 패키지의 일관성 이슈 수정. 프로퍼티명, 파일명, 메시지 텍스트, 로컬 변수명의 4가지 네이밍/메시지 통일 작업. 모두 동작 변경 없는 순수 rename/text 수정이다. [근거: review.md]

### 목표
- 프로퍼티명을 Angular 표준과 일치시킨다 [근거: Rule "canDeactiveFn → canDeactivateFn"]
- 파일명을 프로젝트 컨벤션과 일치시킨다 [근거: Rule "sd-{name}.ts 컨벤션"]
- 토스트 메시지 띄어쓰기를 통일한다 [근거: Rule "보조용언 붙여쓰기"]
- 변수명이 실제 의미를 반영하게 한다 [근거: Rule "팝업 배치 방향 반영"]

### 비목표

- 기존 동작의 의미론적 변경 [근거: wbs 경계]
