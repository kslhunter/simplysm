## 구현계획

### 배경

`packages/angular`의 여러 컴포넌트/유틸리티에서 리소스 정리 누락, 에러 무시, 비동기 취소 미구현 등 방어 로직이 빠져 있다. 같은 코드베이스 내에 올바른 참조 패턴(`injectDataSheetRefreshManager.ts`)이 있으므로 이를 기준으로 통일한다.

### 목표
- effect 내 비동기 작업에 취소 메커니즘 적용 [근거: Rule "effect 재실행 시 이전 비동기 작업이 취소되어야 한다"]
- drag/resize 리스너 누수 방지 [근거: Rule "drag/resize 시작 시 기존 리스너를 정리해야 한다"]
- 모달 생성 실패 시 상태 복구 [근거: Rule "모달 생성 실패 시 modalCount가 복구되어야 한다"]
- 외부 스크립트 로드 에러 처리 및 로드 완료 보장 [근거: Rule "외부 스크립트 로드 실패 시 에러를 표시해야 한다"]

### 비목표
- 기존 동작의 의미론적 변경 [근거: wbs 경계 "방어 로직 추가만"]
- 다른 컴포넌트의 유사 패턴 수정 (Feature 1.1 범위 외)

#### DESIGN-005: `sd-address-search.modal.ts` 에러 처리 + 스크립트 로드 보장

모듈 레벨 상태 없이 스크립트 로드를 관리한다. `typeof daum` 확인 + 기존 스크립트 load 이벤트 대기 방식으로 race condition을 처리하고, 에러를 catch하여 사용자에게 표시한다. 실패 시 스크립트 요소를 DOM에서 제거하여 재시도를 가능하게 한다.

```typescript
function loadDaumPostcodeScript(): Promise<void> {
  const existing = document.getElementById("daum_address");
  if (existing != null) {
    if (typeof daum !== "undefined") {
      return Promise.resolve();
    }
    return new Promise<void>((resolve, reject) => {
      existing.addEventListener("load", () => {
        daum!.postcode.load(() => { resolve(); });
      }, { once: true });
      existing.addEventListener("error", () => {
        existing.remove();
        reject(new Error("주소 검색 스크립트를 불러올 수 없습니다."));
      }, { once: true });
    });
  }

  return new Promise<void>((resolve, reject) => {
    const scriptEl = document.createElement("script");
    scriptEl.src = "//t1.daumcdn.net/mapjsapi/bundle/postcode/prod/postcode.v2.js";
    scriptEl.setAttribute("id", "daum_address");
    scriptEl.onload = (): void => { daum!.postcode.load(() => { resolve(); }); };
    scriptEl.onerror = (): void => {
      scriptEl.remove();
      reject(new Error("주소 검색 스크립트를 불러올 수 없습니다."));
    };
    document.head.appendChild(scriptEl);
  });
}

// _initAsync 변경
private async _initAsync() {
  try {
    await loadDaumPostcodeScript();
    ... // Postcode 초기화
    this.initialized.set(true);
  } catch (err) {
    this.errorMessage.set(err instanceof Error ? err.message : String(err));
    this.initialized.set(true);
  }
}
```

에러 표시를 위해 `errorMessage` 시그널을 추가하고 템플릿에서 조건부 렌더링한다.

영향 파일: `packages/angular/src/features/address/sd-address-search.modal.ts`
