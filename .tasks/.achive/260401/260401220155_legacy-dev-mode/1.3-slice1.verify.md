# Feature 1.3 Slice 1 — LLM 검증

## 검증 항목
- [x] ViteEngine.startWatch()가 serverReady 이벤트를 수신하여 port를 설정한다: `ViteEngine.ts:93-95`에서 `this._worker!.on("serverReady", ...)` → `this.port = event.port`. legacy HTTP 서버도 동일한 `serverReady` 이벤트를 발행하므로 기존 코드 변경 없이 동작
- [x] DevWatchOrchestrator._getClientPort()가 ViteEngine.port를 읽는다: `DevWatchOrchestrator.ts:478-480`에서 `engine?.port` 반환. ViteEngine.port가 설정되면 정상 동작
- [x] DevWatchOrchestrator._collectClientPorts()가 server-connected client 포트를 수집한다: `DevWatchOrchestrator.ts:484-493`에서 serverClientsMap의 client별 포트 수집 → server runtime에 전달
- [x] server-runtime.worker.ts가 clientPorts로 @fastify/http-proxy 등록: `server-runtime.worker.ts:144-154`에서 `server.fastify.register(proxy, { prefix: /{name}, upstream: http://127.0.0.1:{port}, websocket: true })`. legacy HTTP 서버 포트로 프록시 정상 등록
- [x] HTTP 서버가 0.0.0.0에 bind하므로 127.0.0.1 프록시 접근 가능: `client.worker.ts`에서 `httpServer.listen(port, "0.0.0.0", ...)` → 127.0.0.1에서도 접근 가능
- [x] stopWatch()에서 legacyHttpServer를 rollupWatcher보다 후순위로 close: 코드 확인 결과 rollupWatcher → legacyHttpServer → viteServer 순으로 close. 순서 정상 (watcher 먼저 닫아야 추가 빌드 이벤트 방지)
