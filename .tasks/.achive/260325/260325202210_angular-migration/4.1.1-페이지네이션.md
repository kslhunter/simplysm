    Scenario: 이전 그룹으로 이동한다
      Given totalPageCount=20, visiblePageCount=10, currentPage=15
      When "이전 그룹" 버튼을 클릭한다
      Then currentPage가 9로 변경된다 (이전 그룹으로 전환)

    Scenario: 첫 페이지로 이동한다
      Given totalPageCount=20, currentPage=15
      When "첫 페이지" 버튼을 클릭한다
      Then currentPage가 0으로 변경된다

    Scenario: 마지막 페이지로 이동한다

      When "마지막 페이지" 버튼을 클릭한다
      Then currentPage가 19로 변경된다

    Scenario: 첫 그룹에서 이전 방향 버튼이 비활성화된다

      Then "첫 페이지" 버튼이 disabled이다

      Given totalPageCount=30, visiblePageCount=10, currentPage=15
      Then 모든 탐색 버튼이 활성화되어 있다

    Scenario: totalPageCount가 0이면 모든 버튼이 비활성화된다
      Given totalPageCount=0
      Then 모든 탐색 버튼이 disabled이다

  Rule: 현재 페이지를 시각적으로 강조한다

    Scenario: 현재 페이지 번호에 밑줄이 표시된다
      Given totalPageCount=20, visiblePageCount=10, currentPage=3
      Then 페이지 번호 "4" 텍스트에 밑줄이 표시된다
      And 다른 페이지 번호에는 밑줄이 없다

## 구현계획

### 배경

v14 Angular 패키지(`@simplysm/angular`)에 페이지네이션 컴포넌트를 마이그레이션한다. v12 `SdPaginationControl`은 독립 컴포넌트로, `SdAnchorControl`과 `NgIcon`만 의존한다. v14에서는 `$computed` → native `computed`, 서브디렉토리 구조, 아이콘 객체 패턴 등의 변환이 필요하다.

### 목표

- v12 SdPaginationControl을 v14 패턴으로 1:1 마이그레이션
- 기존 동작 100% 보존
- v14 코딩 컨벤션 준수 (native computed, signal inputs, 서브디렉토리 구조)

### 비목표

- 페이지네이션 기능 변경/추가 (무한 스크롤, 페이지 크기 변경 등)
- 다른 컴포넌트에서의 페이지네이션 통합 (data/sheet 등은 Epic 6에서 처리)

### 설계

#### 파일 구조

```
packages/angular/src/ui/navigation/pagination/
  sd-pagination.control.ts    # 컴포넌트
```

#### 컴포넌트 API

| 종류 | 이름 | 타입 | 기본값 | 설명 |
|------|------|------|--------|------|
| model | currentPage | number | 0 | 현재 페이지 (0-based) |
| input | totalPageCount | number | 0 | 전체 페이지 수 |
| input | visiblePageCount | number | 10 | 한 그룹에 표시할 페이지 수 |

#### v12 → v14 변환

| v12 | v14 | 근거 |
|-----|-----|------|
| `$computed(() => ...)` | `computed(() => ...)` from `@angular/core` | v14에서 `$computed` 제거됨 |
| `protected readonly tablerX = tablerX` | `icons = { tablerX }` | v14 아이콘 패턴 (`sd-collapse-icon.control.ts` 참조) |
| `@use "../../../scss/..."` | `@use "../../../../scss/..."` | 서브디렉토리 1단계 추가 |
| `index.ts` export 없음 | `export { SdPaginationControl } from "..."` | v14 export 패턴 |
