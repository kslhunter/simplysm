# Feature 3.2 모달

## 참조 자료

- [wbs.md](./wbs.md)

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | 포커스 트랩 범위 | Tab 순환 구현 | WCAG 2.4.3 준수, 접근성 향상. v12는 초기 포커스+복귀만 제공 |
| D2 | SdBusyProvider 처리 | modalCount signal만 유지 | forward dependency 없음. busy 연동은 Feature 3.4에서 추가 |
| D3 | 동적 입력 바인딩 | setInput() + outputToObservable() | v12 inputBinding/outputBinding 미포팅, Angular 21 표준 API 사용 |
| D4 | 타이밍 API | afterNextRender | v12 requestAnimationFrame+setTimeout(100ms) 대체, Angular 17+ 표준 |
| D5 | TUndefToOptional | angular 패키지 내 로컬 정의 | v14 core-common에 미존재, TDirectiveInputSignals 전용 |

## 구현계획

### 배경

Angular 21 마이그레이션의 일환으로 v12 모달 시스템을 v14로 포팅한다. v14에는 이미 SdDropdownControl(3.1), 커맨드 플러그인(1.5), 뷰 시그널(1.11), SdSystemConfigProvider(1.9)가 구현되어 있다. 모달은 SdDropdownControl과 유사한 오버레이 패턴을 따르되, 동적 컴포넌트 생성(createComponent + projectableNodes)과 포커스 트랩이 추가된다.

### 목표

- SdModalProvider.showAsync API로 프로그래밍 방식 모달 생성/결과 반환
- SdModalControl 컴포넌트로 모달 UI 렌더링 (크기 조절, 이동, float/fill)
- SdActivatedModalProvider로 모달 컨텍스트 DI 주입
- TDirectiveInputSignals 타입으로 타입 안전한 동적 입력 바인딩
- Tab 순환 포커스 트랩 (D1: WCAG 2.4.3)

### 비목표

- 커맨드 플러그인 모달 컨텍스트 필터링 (Feature 3.2.1)
- 뷰 시그널 모달 통합 (Feature 3.2.1)
- 드롭다운 모바일 모달 형식 (Feature 3.2.1)
- SdBusyProvider 연동 (Feature 3.4, D2)

#### 인터페이스 및 타입

```typescript
// TDirectiveInputSignals.ts
type TUndefToOptional<T> = {
  [K in keyof T as undefined extends T[K] ? never : K]: T[K];
} & {
  [K in keyof T as undefined extends T[K] ? K : never]?: Exclude<T[K], undefined>;
};

export type TDirectiveInputSignals<T> = TUndefToOptional<{
  [P in keyof T as T[P] extends InputSignal<any> ? P : never]:
    T[P] extends InputSignal<any> ? ReturnType<T[P]> : never;
}>;

// sd-modal.provider.ts
export interface ISdModal<O> {
  initialized: Signal<boolean>;
  close: OutputEmitterRef<O | undefined>;
  actionTplRef?: TemplateRef<any>;
}

export interface ISdModalInfo<T extends ISdModal<any>> {
  title: string;
  type: Type<T>;
  inputs: Omit<TDirectiveInputSignals<T>, "initialized" | "close" | "actionTplRef">;
}

export interface ISdModalOptions {
  key?: string;
  hideHeader?: boolean;
  hideCloseButton?: boolean;
  useCloseByBackdrop?: boolean;
  useCloseByEscapeKey?: boolean;
  float?: boolean;
  fill?: boolean;
  resizable?: boolean;
  movable?: boolean;
  position?: "bottom-right" | "top-right";
  minHeightPx?: number;
  minWidthPx?: number;
  heightPx?: number;
  widthPx?: number;
  headerStyle?: string;
  noFirstControlFocusing?: boolean;
}
```

#### SdModalProvider

```typescript
@Injectable({ providedIn: "root" })
export class SdModalProvider {
  modalCount = signal(0);

  async showAsync<T extends ISdModal<any>>(
    modal: ISdModalInfo<T>,
    options?: ISdModalOptions,
  ): Promise<Parameters<T["close"]["emit"]>[0] | undefined>;
}
```

showAsync 내부 플로우:
1. `modalCount.update(v => v + 1)`
2. SdActivatedModalProvider 인스턴스 생성
3. `createComponent(modal.type, { environmentInjector, elementInjector })` — elementInjector에 SdActivatedModalProvider 주입
4. `componentRef.setInput(key, value)` — modal.inputs 바인딩 (D3)
5. `outputToObservable(compRef.instance.close).subscribe()` — close 구독 (D3)
6. `createComponent(SdModalControl, { projectableNodes: [[compEl]] })`
7. `modalRef.setInput()` — options 바인딩
8. `document.body.appendChild(modalEl)` + `appRef.attachView()` x 2
9. `afterNextRender`로 initialized 대기 후 포커스 설정 (D4)
10. open.set(true) → CSS 애니메이션 시작
11. 닫힘 시: transitionend → destroy → `modalCount.update(v => v - 1)` → Promise resolve

#### SdActivatedModalProvider

```typescript
@Injectable()
export class SdActivatedModalProvider<T extends ISdModal<any>> {
  modalComponent = signal<SdModalControl | undefined>(undefined);
  contentComponent = signal<T | undefined>(undefined);
  canDeactivefn: () => boolean = () => true;
}
```

#### SdModalControl 템플릿 구조

```html
<div class="_backdrop" (click)="onBackdropClick()"></div>
<div class="_dialog" #dialogEl tabindex="-1"
     (focus)="onDialogFocus()" (keydown)="onDialogKeydown($event)">
  @if (!hideHeader()) {
    <div class="_header" (mousedown)="onHeaderMouseDown($event)">
      <span class="_title">{{ title() }}</span>
      @if (actionTplRef()) {
        <ng-container *ngTemplateOutlet="actionTplRef()!" />
      }
      @if (!hideCloseButton()) {
        <button class="_close-btn" (click)="onCloseButtonClick()">×</button>
      }
    </div>
  }
  <div class="_content"><ng-content /></div>
  @if (resizable()) {
    <!-- 8방향 리사이즈 핸들 -->
  }
</div>
```

host bindings: `data-sd-open`, `data-sd-init`, `data-sd-float`, `data-sd-fill`, `data-sd-position`

#### 포커스 트랩 구현 (D1)

SdModalControl의 `onDialogKeydown`에서 Tab/Shift+Tab 처리:
- `tabbable` 라이브러리의 `isFocusable()` 활용 (v14 core-browser 의존성에 이미 포함)
- `TreeWalker`로 모달 내 focusable 요소 수집 (findFirstFocusableChild 패턴 참고)
- 마지막 요소에서 Tab → 첫 요소, 첫 요소에서 Shift+Tab → 마지막 요소

#### 다중 모달 z-index

포커스 시 `document.body.findAll("sd-modal")`에서 최대 z-index를 구해 +1 설정 (v14 core-browser findAll 활용)

#### key 기반 설정 저장

SdSystemConfigProvider.getAsync/setAsync 사용. 키 형식: `sd-modal.{key}`. 저장 대상: position, left, top, right, bottom, width, height
