# Feature 1.2.1 rem/em 사이징 전환 및 크기 테마 제거

## 참조 자료

- [wbs.md](./wbs.md)

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | rem 변환 기준값 | 12px (compact 기본 폰트 크기, 1rem = 12px) | `_variables.scss`의 font-size-default가 12px이므로 자연스러운 기준 |
| D2 | 하드코드 px 처리 | 크기→rem, border 너비(구분 표시)→px 유지 | border는 크기보다 구분 표시 용도. 스크롤바 크기, shadow blur 등은 스케일링 대상 |

## 구현계획

### 배경

Feature 1.2에서 구현된 SCSS 테마 시스템(compact/mobile/kiosk 3종 + 다크모드)과 SdThemeProvider에서 크기 테마를 제거하고, px 기반 크기 변수를 rem으로 전환한다. 이를 통해 html font-size 하나로 전체 UI 배율을 조정할 수 있게 한다.

### 목표

- mobile/kiosk 테마 파일 삭제 및 관련 SCSS 코드 제거
- 크기 CSS 변수(gap, font-size, elevation-size)를 rem으로 전환 (1rem = 12px)
- 하드코드 크기 px(scrollbar, shadow blur)을 rem으로 전환 (border 너비 제외)
- SdThemeProvider에서 theme signal/TSdTheme 제거, dark만 유지
- 관련 테스트 갱신

### 비목표

- consuming app의 html font-size 설정 (앱 책임)
- 다크모드 변경 (dark signal 및 .sd-theme-dark 유지)
- 컴포넌트별 SCSS의 px→rem (각 UI Feature에서 처리)
- theme-variant 레이어명 변경 (코스메틱, 기능 변경 아님)

### 설계

#### SCSS 변경

**삭제:**
- `scss/themes/_variables-mobile.scss`
- `scss/themes/_variables-kiosk.scss`

**`_theme-variables.scss`:**
- `@use "../themes/variables-mobile"`, `@use "../themes/variables-kiosk"` import 삭제
- `@layer base, theme, theme-variant, utilities` → `@layer base, theme-variant, utilities`
- `@layer theme { ... }` 블록 전체 삭제

**`_variables.scss` px→rem 변환표 (1rem = 12px):**

| 변수 | 기존 | 변경 |
|------|------|------|
| gap-xxs | 1px | 0.0833rem |
| gap-xs | 2px | 0.1667rem |
| gap-sm | 4px | 0.3333rem |
| gap-default | 6px | 0.5rem |
| gap-lg | 8px | 0.6667rem |
| gap-xl | 12px | 1rem |
| gap-xxl | 18px | 1.5rem |
| font-size-sm | 11px | 0.9167rem |
| font-size-default | 12px | 1rem |
| font-size-lg | 14px | 1.1667rem |
| font-size-h1 | 24px | 2rem |
| font-size-h2 | 18px | 1.5rem |
| font-size-h3 | 16px | 1.3333rem |
| font-size-h4 | 14px | 1.1667rem |
| font-size-h5 | 12px | 1rem |
| font-size-h6 | 11px | 0.9167rem |
| elevation-size | 1px | 0.0833rem |

변경 안 함: sidebar(15em), topbar(3em), line-height(1.5em), line-height-strip-unit(1.5), 0, auto, animation-duration(0.2s)

**`_styles.scss` 하드코드 px:**

| 위치 | 기존 | 변경 | 근거 |
|------|------|------|------|
| scrollbar width | 12px | 1rem | 크기 |
| scrollbar height | 12px | 1rem | 크기 |
| scrollbar border-radius | 8px | 0.6667rem | 크기 |
| scrollbar border | 2px | px 유지 | border 너비 |
| hr height | 1px | px 유지 | 구분선 |
| .bd border | 1px | px 유지 | border 너비 |
| .bd{dir} border | 1px | px 유지 | border 너비 |

**`_mixins.scss` 하드코드 px:**

| 위치 | 기존 | 변경 | 근거 |
|------|------|------|------|
| elevation inset blur | 2px | 0.1667rem | 크기 |
| form-control border | 1px | px 유지 | border 너비 |

#### TypeScript 변경

**`sd-theme-provider.ts`:**
- `theme = signal<TSdTheme>("compact")` 삭제
- `TSdTheme` 타입 삭제
- effect: `document.body.className = this.dark() ? "sd-theme-dark" : ""`

**`index.ts`:**
- `type TSdTheme` export 제거

**`theme-provider.spec.ts`:**
- "theme signal의 기본값이 compact이다" → 삭제
- "theme 변경 시 className 갱신" → 삭제
- "compact + dark false → sd-theme-compact만" → "dark false → className 비어있음"으로 변경
- "dark 활성화 시 sd-theme-dark 추가" → className이 정확히 "sd-theme-dark"인지 검증

**`testbed-setup.spec.ts`:**
- `expect(provider.theme()).toBe("compact")` → `expect(provider.dark()).toBe(false)`

### 대안 검토

| 접근 방식 | 선택 | 이유 |
|-----------|------|------|
| SCSS rem() 함수로 동적 변환 | 미채택 | 정적 값 변환이므로 직접 rem 리터럴이 더 단순 |
| theme-variant → theme 레이어명 변경 | 미채택 | 기능 변경 없는 코스메틱. 향후 레이어 추가 가능성 |
