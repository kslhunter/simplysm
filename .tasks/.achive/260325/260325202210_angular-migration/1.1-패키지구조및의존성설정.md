## 구현계획

### 배경

v14 모노레포에서 @simplysm/angular 패키지의 기본 구조(package.json, sd.config.ts, styles.css, src/index.ts)가 이미 구성되어 있다. Angular 컴파일러 전용 옵션(angularCompilerOptions)을 포함한 tsconfig.json이 누락되어 있어 이를 추가해야 한다.

### 목표

- 패키지 구조의 완전성 확보 (tsconfig.json 생성)
- 기존 구성 파일의 v14 컨벤션 준수 검증

### 비목표

- Angular 빌드 파이프라인 구현 (sd-cli 별도 태스크)
- 컴포넌트/디렉티브 소스 코드 마이그레이션 (후속 Feature)
- SCSS/스타일 시스템 구축 (Feature 1.2)

### 설계

tsconfig.json은 루트 tsconfig.json을 확장(extends)하여 중복을 최소화하고, Angular 컴파일러 전용 옵션만 추가한다.

```json
{
  "extends": "../../tsconfig.json",
  "angularCompilerOptions": {
    "strictTemplates": true,
    "strictInjectionParameters": true,
    "strictInputAccessModifiers": true,
    "strictStandalone": true,
    "typeCheckHostBindings": true,
    "forbidOrphanComponents": true,
    "enableI18nLegacyMessageIdFormat": false,
    "extendedDiagnostics": {
      "defaultCategory": "error"
    }
  }
}
```

- v12의 `compilerOptions.lib`/`outDir`은 루트 tsconfig.json에서 이미 설정되므로 생략
- Angular 19~21 신규 strict 옵션 모두 활성화: `strictStandalone`, `typeCheckHostBindings`, `forbidOrphanComponents`, `extendedDiagnostics`

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| 로컬 tsconfig.json으로 angularCompilerOptions 설정 | 채택 | 다른 패키지에 영향 없이 Angular 전용 옵션 설정 가능 |
| 루트 tsconfig.json에 angularCompilerOptions 추가 | 미채택 | 비Angular 패키지에 불필요한 옵션 노출 |
