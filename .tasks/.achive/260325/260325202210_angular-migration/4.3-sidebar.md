## 구현계획

### 배경

v12의 사이드바 네비게이션 시스템(4개 컴포넌트)을 v14 Angular 21 패턴으로 마이그레이션한다. v14에는 SCSS 변수(`--sidebar-width`, `--z-index-sidebar`)와 의존 컴포넌트(SdList, SdCollapse, sd-router-link 등)가 이미 마이그레이션되어 있다.

### 목표

- SdSidebarContainerControl, SdSidebarControl, SdSidebarMenuControl, SdSidebarUserControl 4개 컴포넌트 마이그레이션
- v14 signal API 및 의존 컴포넌트와 통합
- 반응형 토글, 계층 메뉴, 라우터 연동 동작 유지

### 비목표

- Topbar의 사이드바 토글 버튼 (Feature 4.4)
- 새로운 사이드바 기능 추가 (마이그레이션 범위)

### 설계

#### 컴포넌트 구조

```
packages/angular/src/ui/navigation/sidebar/
├── sd-sidebar-container.control.ts  # 토글 상태 관리, 백드롭, 라우팅 연동
├── sd-sidebar.control.ts            # 부모 toggle 참조, 슬라이드 애니메이션
├── sd-sidebar-menu.control.ts       # 계층 메뉴 렌더링, 라우터 연동
└── sd-sidebar-user.control.ts       # 사용자 정보/collapse 메뉴
```

#### v12 → v14 변환 매핑

| v12 | v14 |
|-----|-----|
| `$signal(false)` | `signal(false)` |
| `$computed(() => ...)` | `computed(() => ...)` |
| `inject(X, forwardRef(() => X))` | `inject<X>(forwardRef(() => X))` (v14 패턴 동일) |
| `querystring.parse(q)` | `Object.fromEntries(new URLSearchParams(q))` |
| `[contentClass]="'pv-default'"` | SCSS: depth 0 항목 `._content`에 padding-block |
| `[contentStyle]="'text-indent: ...'` | `[style.padding-left.em]="(depth+1)*0.5"` on host |
| `menuTitle` input | 제거 (미사용) |

#### API

| 컴포넌트 | Public 프로퍼티 | Input | 기타 |
|----------|---------------|-------|------|
| SdSidebarContainerControl | `toggle: WritableSignal<boolean>` | — | Router optional inject |
| SdSidebarControl | `toggle: Signal<boolean>` (from parent) | — | parent inject via forwardRef |
| SdSidebarMenuControl | `fullPageCode: Signal<string>` | `menus`, `layout`, `getMenuIsSelectedFn` | useFullPageCodeSignal |
| SdSidebarUserControl | `menuOpen: WritableSignal<boolean>` | `userMenu` | — |

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| SdDockControl을 sidebar로 활용 | 미채택 | sidebar 특화 동작(반응형 토글, 백드롭, 라우팅 연동) 필요 |
| contentClass/contentStyle을 v14 SdListItemControl에 추가 | 미채택 | 기존 v14 API 변경 최소화, SCSS/host style로 충분 |
