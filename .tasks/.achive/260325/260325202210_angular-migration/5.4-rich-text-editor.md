## 구현계획

### 배경

v12의 `SdQuillEditorControl`(Quill 2.x wrapper)을 v14에서 TipTap 3 기반으로 재구현한다. TipTap은 headless 에디터로, toolbar UI를 컴포넌트 내부에 직접 구현한다. v14의 signal 기반 API와 폼 유효성 검증(`setupInvalid`) 패턴을 따른다.

### 목표

- TipTap 3 기반 리치 텍스트 에디터 컴포넌트 (`SdTiptapEditorControl`)
- v12 동등 서식 기능 + 이미지 리사이즈
- Signal 기반 양방향 바인딩, disabled/readonly/required/validatorFn/placeholder
- Extensions input으로 기능 커스터마이제이션

### 비목표

- 이미지 업로드 서버 연동
- Collaborative editing
- Bubble menu / Floating menu

### 설계

#### npm 의존성

```
@tiptap/core
@tiptap/starter-kit        # bold, italic, strike, heading, lists, blockquote, codeBlock, history
@tiptap/extension-underline # StarterKit에 미포함
@tiptap/extension-color     # 텍스트 색상
@tiptap/extension-text-style # color extension 필수 의존
@tiptap/extension-highlight  # 배경 색상
@tiptap/extension-text-align # 정렬
@tiptap/extension-image      # 이미지 노드 + 리사이즈
@tiptap/extension-placeholder # placeholder
```

#### 컴포넌트 API

```typescript
@Component({ selector: "sd-tiptap-editor" })
export class SdTiptapEditorControl {
  value = model<string>();
  disabled = input(false, { transform: booleanAttribute });
  readonly = input(false, { transform: booleanAttribute });
  required = input(false, { transform: booleanAttribute });
  placeholder = input<string>();
  validatorFn = input<(value: string | undefined) => string | undefined>();
  extensions = input<Extension[]>();  // 미지정 시 DEFAULT_EXTENSIONS
}
```

#### 기본 Extension 세트

```typescript
const DEFAULT_EXTENSIONS = [
  StarterKit,                                          // bold, italic, strike, heading, lists, blockquote, codeBlock, history
  Underline,                                           // 밑줄
  TextStyle,                                           // color 의존
  Color,                                               // 텍스트 색상
  Highlight.configure({ multicolor: true }),            // 배경 색상
  TextAlign.configure({ types: ["heading", "paragraph"] }), // 정렬
  Image.configure({ inline: false, allowBase64: true }),// 이미지 노드
  // Placeholder는 placeholder input 존재 시 동적 추가
];
```

#### 양방향 바인딩 (TipTap Core 직접)

- `editor.on('update')` → `this.value.set(html === '' ? undefined : html)`
- `effect()` → value 변경 시 `editor.commands.setContent(value ?? '')`
- 양방향 무한 루프 방지: update 이벤트 핸들러 내에서 값 비교 후 set

#### Toolbar

- 컴포넌트 template에 내장, `<div class="_toolbar">` 안에 버튼 그룹 배치
- 각 버튼: `editor.chain().focus().toggle*().run()` 실행
- 활성 상태: `editor.isActive('bold')` → CSS class로 표시
- Visibility: `editor.can()` 체크로 사용 가능한 기능만 표시 (extensions input 변경 시 자동 적응)
- 색상: 프리셋 색상 그리드 (v12 Quill의 기본 팔레트와 동등)
- disabled 시: toolbar `display: none`
- v12 toolbar 매핑: h1/h2, bold, italic, underline, strike, text color, bg color, ordered list, bullet list, indent ±, blockquote, code-block, alignment(4종), clean

#### Host Bindings

```typescript
host: {
  "[attr.data-sd-disabled]": "disabled()",
  "[attr.data-sd-readonly]": "readonly()",
}
```

#### SCSS 스타일링

- `form-control-base()` mixin 미적용 (에디터는 일반 폼 컨트롤과 레이아웃이 다름)
- CSS 변수 사용: `--border-radius-default`, `--gap-*`, `--theme-*`, `--trans-*`, `--font-size-*`
- v12 스타일 패턴 참조: border, toolbar, container, disabled 상태
- `data-sd-disabled`/`data-sd-readonly` 속성 기반 SCSS 셀렉터
