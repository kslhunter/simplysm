## 구현계획

### 배경

Angular 21 마이그레이션 프로젝트에서 칸반 보드 UI 컴포넌트를 마이그레이션한다. 소스(v12)에는 `sd-kanban-board`, `sd-kanban-lane`, `sd-kanban` 3개 컴포넌트와 `sd-card` directive가 있다. 대상에는 의존 컴포넌트(`SdBusyContainerControl`, `SdCheckboxControl`, `SdAnchorControl`, `NgIcon`, `SdEventsDirective`)가 이미 존재한다. `SdCardDirective`만 TS 파일이 누락되어 있다.

### 목표

- 소스 kanban 3개 컴포넌트를 Angular 21 signal 기반으로 마이그레이션
- 누락된 `SdCardDirective` TS 파일 생성
- `index.ts`에 export 추가

### 비목표

- kanban SCSS 전역 스타일 변경 (인라인 스타일로 충분)
- 새로운 기능 추가 (소스 동작 그대로 마이그레이션)

### 설계

#### 커스텀 유틸리티 → 네이티브 Angular API 매핑

| 소스 | 대상 |
|------|------|
| `$signal<T>()` | `signal<T \| undefined>(undefined)` |
| `$signal(value)` | `signal(value)` |
| `$computed(() => ...)` | `computed(() => ...)` |
| `transformBoolean` | `booleanAttribute` |
| `injectElementRef()` | `inject<ElementRef<HTMLElement>>(ElementRef)` |
| `model<T[]>([])` | `model<T[]>([])` (동일) |
| `output<T>()` | `output<T>()` (동일) |

#### 컴포넌트 구조

```
packages/angular/src/ui/layout/
├── sd-card.directive.ts          (신규 — `.card` CSS 클래스 부여)
└── kanban/
    ├── sd-kanban-board.control.ts (신규)
    ├── sd-kanban-lane.control.ts  (신규)
    └── sd-kanban.control.ts       (신규)
```

#### DI 구조

- `SdKanbanBoardControl` — 최상위 컨테이너, `dragKanban`/`selectedValues` 상태 보유
- `SdKanbanLaneControl` — Board를 `inject(forwardRef(() => SdKanbanBoardControl))`로 주입
- `SdKanbanControl` — Board와 Lane 모두 `inject(forwardRef(...))`로 주입

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| 소스 구조 그대로 마이그레이션 | 채택 | 검증된 구조, 기존 패턴 유지 |
| 카드 드래그를 CDK DragDrop으로 교체 | 미채택 | 소스 동작을 정확히 재현하는 것이 목표, CDK 의존성 추가 불필요 |
