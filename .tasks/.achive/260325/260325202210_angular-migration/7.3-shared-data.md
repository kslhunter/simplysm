# Feature 7.3 공유 데이터 관리

## 참조 자료

- [wbs.md](./wbs.md)

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | `__searchText`/`__isHidden` 위치 | `ISharedDataBase`에 추가 | 공유 데이터의 본질적 속성. Provider 단계에서 이미 필요하며, 별도 인터페이스 분리는 무의미한 indirection |
| D2 | `__parentKey` 위치 | `ISharedDataBase`에 optional 추가 | `__searchText`/`__isHidden`과 동일 패턴. 트리가 아닌 데이터는 생략 가능 |

## 구현계획

### 배경

v14에 `SdSharedDataProvider`와 `SharedDataHandle`이 이미 존재하지만, `ISharedDataBase`에는 `__valueKey`만 있어 검색/숨김/트리 기능을 지원하지 못한다. 공유 데이터를 UI에서 선택하는 3가지 형태(셀렉트, 버튼, 목록)의 컴포넌트가 미구현 상태이다.

기존 v14 의존 컴포넌트:
- `SdSelectControl` (드롭다운 셀렉트, `items`/`getChildrenFn`/`selectMode` 지원)
- `AbsSdDataSelectButton` + `SdDataSelectButtonControl` (모달 기반 선택 버튼)
- `SdListControl` + `SdListItemControl` (목록)
- `SdModalProvider` (모달), `SdPaginationControl` (페이지네이션)
- `setupModelHook` (모델 변경 검증)

### 목표

- `ISharedDataBase`에 `__searchText`, `__isHidden`, `__parentKey?` 추가
- `SdSharedDataSelectControl`: 셀렉트 형태 공유 데이터 선택 (검색, 트리, 모달)
- `SdSharedDataSelectButtonControl`: 버튼 형태 공유 데이터 선택 (`AbsSdDataSelectButton` 확장)
- `SdSharedDataSelectListControl`: 목록 형태 공유 데이터 선택 (검색, 페이지네이션, 모달)

### 비목표

- `SdSharedDataProvider` 로직 변경 (이미 구현 완료)
- 공유 데이터 등록/이벤트 관련 기능 (Provider 영역)

### 설계

#### ISharedDataBase 인터페이스 확장

```typescript
export interface ISharedDataBase<TKey extends string | number> {
  __valueKey: TKey;
  __searchText: string;
  __isHidden: boolean;
  __parentKey?: TKey;
}
```

#### SdSharedDataSelectControl

`SdSelectControl`을 래핑하여 공유 데이터 전용 검색/필터/트리 로직을 추가한다.

- 제네릭: `<TItem extends ISharedDataBase<string | number>>`
- `viewChild(SdSelectControl)`로 `dropdownOpen` 상태 접근
- `rootDisplayItems` computed: `filterFn` + `__parentKey` 필터 + 정렬
- `itemByParentKeyMap` computed: 트리 구조용 부모-자식 맵
- `selectedKeys` computed: value에서 키 배열 추출
- `isIncludeSearchText()`: 공백 분리 AND 검색 + 트리 자식 포함
- 모달: `SdModalProvider.showAsync()`

#### SdSharedDataSelectButtonControl

`AbsSdDataSelectButton`을 확장하여 `load(keys)` 구현. items input에서 키로 필터링.

- 제네릭: `<TItem extends ISharedDataBase<number>>`
- `load(keys)`: `items().filter(item => keys.includes(item.__valueKey))`
- 템플릿: `SdDataSelectButtonControl` 위임

#### SdSharedDataSelectListControl

인라인 목록으로 공유 데이터를 선택. 검색, 페이지네이션, `canChangeFn` 지원.

- `selectedItem` model + `setupModelHook(selectedItem, canChangeFn)`
- `displayItems` computed: `__isHidden` 필터 + 검색 + `filterFn` + 페이지네이션
- `effect`로 items 변경 시 selectedItem 동기화
- 모달: `SdModalProvider.showAsync()`

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| `ISharedDataBase` 확장 (A) | 채택 | 공유 데이터의 본질적 속성. UI 인터페이스 분리는 무의미한 indirection |
| 별도 `ISharedDataSelectItem` (B) | 미채택 | Provider와 컴포넌트에서 동일 데이터를 다른 타입으로 다루게 됨 |
| `__parentKey`를 `ISharedDataBase`에 optional 추가 (B) | 채택 | `__searchText`/`__isHidden`과 동일 패턴. 트리 미사용 시 생략 가능 |
| 함수 기반 `getParentKeyFn` (A) | 미채택 | 인터페이스에 속성이 있으므로 별도 함수 불필요 |
