## 구현계획

### 배경

`packages/lint/src/rules/`에 기존 3개 규칙이 `createRule()` 패턴으로 작성되어 있다. 원본(workspaces-12)의 4개 JS 규칙을 동일 패턴의 TypeScript로 변환하여 추가한다.

### 목표

- 4개 규칙을 TypeScript로 변환하여 `packages/lint`에 통합
- `eslint-plugin.ts`에 등록, `eslint-recommended.ts`에서 활성화

### 비목표

- 규칙 로직 변경/개선

### 설계

- `ng-template-no-todo-comments`: `createRule` 래핑, raw text regex 로직 유지, 반환 타입은 빈 객체 (`return {}`)
- `ng-template-sd-require-binding-attrs`: `createRule` 래핑, `@angular-eslint/utils`의 `getTemplateParserServices` 사용, schema로 옵션 타입 정의 (package.json에 `@angular-eslint/utils` 의존성 추가 필요)
- `ts-no-unused-injects`: `createRule` 래핑, `traverseNode` 헬퍼 인라인, `AST_NODE_TYPES`로 노드 타입 비교
- `ts-no-unused-protected-readonly`: `createRule` 래핑, `traverseNode` 헬퍼 인라인, `escapeRegExp` 인라인
- HTML 블록에 `rules` 섹션 추가 (현재는 `extends`만 있음)

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| traverseNode를 공유 유틸로 추출 | 미채택 | 두 구현이 약간 다르고 단순한 헬퍼 |
| ESLint scope analysis 사용 | 미채택 | 원본 로직이 수동 AST 순회로 검증됨 |
