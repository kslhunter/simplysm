## 구현계획

### 배경

`setupCloserWhenSingleSelectionChange()`는 모달에서 단일 선택 시 자동으로 close를 emit하는 feature-specific setup 함수이다. 현재 `core/utils/setups/`에 위치하지만, core의 범용 setup 함수들(setupRipple, setupInvalid 등)과 달리 모달 선택이라는 특정 도메인에 한정된 로직이다. [근거: refactor.md ARCH-002]

### 목표

- `setupCloserWhenSingleSelectionChange`를 유일한 사용처인 `features/data-view/`로 이동하여 레이어 배치 불일치를 해소한다 [근거: Rule "파일 이동 후 모든 import/export 경로가 올바르게 갱신"]

### 비목표

- 함수 시그니처/로직 변경 [근거: wbs 경계]
- 다른 setup 함수 이동 [근거: wbs 범위]

### 설계

단순 파일 이동 + import/export 경로 갱신. 기존 git mv 패턴(Feature 1.1에서 SdBusyProvider, SdToastProvider 이동 시 사용)과 동일.

### 대안 검토

- `features/shared/setups/`에 배치 → 사용처가 `data-view` 1곳이므로 불필요한 중간 디렉토리. 기각.
