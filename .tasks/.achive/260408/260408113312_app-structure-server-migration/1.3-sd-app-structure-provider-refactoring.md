## 구현계획

### 배경

Feature 1.1에서 공유 타입/유틸이 service-common으로 추출되었고, Feature 1.2에서 서버 서비스(`AppStructureService`)가 정의되었다. 현재 `SdAppStructureProvider`는 `abstract items`로 클라이언트가 items를 정적 정의하고 있다. 이를 서버에서 fetch하는 구조로 변경하여 데이터 흐름을 단방향화(서버 → 클라이언트)한다. [근거: wbs 프로젝트 개요]

### 목표

- `abstract items` 제거, signal 기반 items + `abstract serviceKey` + `fetchItems()` 메서드 도입 [근거: Rule "abstract items를 제거하고 signal 기반 items로 대체", 설계 결정 D1]
- service-common에 `AppStructureService` 인터페이스 추가 [근거: 설계 결정 D2]
- 사용처(`SdBaseContainer`, `injectViewTitleSignal`)에서 미로딩 시 try/catch로 안전 처리 [근거: 설계 결정 D3]

### 비목표

- `abstract usableModules`, `abstract permRecord` 변경 [근거: wbs 경계]
- 소비 프로젝트 Provider 상속 구현 변경 [근거: wbs 경계 "breaking change 문서화만 수행"]

변경 후:
```typescript
export abstract class SdAppStructureProvider<TModule = unknown> {
  private readonly _clientFactory = inject(SdServiceClientFactoryProvider);
  private readonly _config = inject(SdAngularConfigProvider);

  abstract serviceKey: string;
  abstract usableModules: Signal<TModule[] | undefined>;
  abstract permRecord: Signal<Record<string, boolean> | undefined>;

  readonly items = signal<AppStructureItem<TModule>[]>([]);

  async fetchItems(): Promise<void> {
    const client = this._clientFactory.get(this.serviceKey);
    const svc = client.getService<AppStructureService>("AppStructure");
    const itemsMap = await svc.getItems();
    this.items.set((itemsMap[this._config.clientName] ?? []) as AppStructureItem<TModule>[]);
  }
```

### 대안 검토

| 대안 | 불채택 사유 |

| Provider 내부에서 미로딩 시 빈 문자열 반환 | 사용자 선택 D3에 의해 throw 유지 + 호출측 catch 채택 |

### Breaking Changes

소비 프로젝트에서 `SdAppStructureProvider`를 상속하는 클래스에 다음 변경이 필요하다:

1. **`items` 정의 제거**: 더 이상 `items`를 직접 정의하지 않는다. `items`는 base class의 `WritableSignal`이다.
2. **`serviceKey` 추가**: `abstract serviceKey: string`을 구현해야 한다. (예: `serviceKey = "main"`)
3. **`fetchItems()` 호출**: connection 후 `await sdAppStructure.fetchItems()`를 호출하여 서버에서 items를 fetch해야 한다.
4. **`items` 참조 변경**: `this.items` → `this.items()` (signal 호출). 예: `getPermissionsByStructure(this.items())`.
