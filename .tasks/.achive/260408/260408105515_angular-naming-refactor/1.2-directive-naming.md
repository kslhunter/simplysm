## 구현계획

### 배경

Feature 1.1에서 66개 컴포넌트의 `Control` 접미사가 제거된 상태이다. 이제 11개 디렉티브의 `Directive` 접미사를 제거하고, 속성 selector를 camelCase로 변환한다.

디렉티브는 3가지 유형으로 나뉜다:
1. **속성 selector 변경 필요** (6개): SdRipple, SdShowEffect, SdInvalid, SdRouterLink, SdPane, SdCard
2. **selector 변경 불필요 — 이벤트/ng-template** (3개): SdEvents, SdTypedTemplate, SdItemOfTemplate
3. **selector 변경 불필요 — 요소 selector** (2개): SdSheetColumn, SdDataSheetColumn

### 목표

- 11개 디렉티브 클래스명에서 `Directive` 접미사 제거 [근거: Rule "Directive 접미사 제거"]
- 11개 파일명에서 `.directive` 접미사 제거 [근거: Rule "Directive 접미사 제거"]
- 6개 속성 selector를 camelCase로 변환 [근거: Rule "속성 selector camelCase 변환"]
- 4개 input alias를 새 selector와 일치 [근거: Rule "input alias 일치"]
- 패키지 내부 모든 참조 정합성 유지 [근거: Rule "import/템플릿 참조 업데이트"]

### 비목표

- 요소 selector(`sd-sheet-column`, `sd-data-sheet-column`, `sd-pane`의 요소 부분) 변경 [근거: WBS 경계]
- `ng-template[typed]`, `ng-template[itemOf]` selector 변경 [근거: WBS 경계, `sd-` prefix 아님]
- 변수명, 메서드명, 프로퍼티명 변경 [근거: WBS 경계]
- SdEventsDirective의 이벤트 기반 selector 변경 [근거: 설계 결정 D1]

### 설계

각 디렉티브에 대해 아래 순서로 변경한다:

1. `git mv`로 파일 이름 변경 (`.directive.ts` → `.ts`)
2. 파일 내 `class` 선언에서 `Directive` 접미사 제거
3. `@Directive({ selector })` 변경 (해당되는 경우):
   - `[sd-xxx]` → `[sdXxx]`
   - `sd-xxx,[sd-xxx]` → `sd-xxx,[sdXxx]` (이중 selector)
4. `input()` alias 변경 (해당되는 경우): `"sd-xxx"` → `"sdXxx"`
5. 패키지 내부 모든 import 경로에서 `.directive` 제거
6. 패키지 내부 모든 import 심볼에서 `Directive` 접미사 제거
7. 컴포넌트 `imports` 배열의 클래스 참조 변경
8. 템플릿의 속성 바인딩 변경: `[sd-xxx]` → `[sdXxx]`
9. `contentChild`/`contentChildren` 등 class 참조 변경
10. `index.ts` export 경로 및 이름 변경
11. 테스트 파일의 import/참조/템플릿/querySelector 변경

**주의사항:**
- 테스트의 `querySelector("[sdCard]")`는 DOM이 속성명을 소문자로 저장하므로 `querySelector("[sdcard]")`로 작성해야 함
- `SdDataSheetColumnDirective extends SdSheetColumnDirective`의 extends 참조도 변경 필요
- `SdTypedTemplateDirective`와 `SdItemOfTemplateDirective`의 `static ngTemplateContextGuard` 내 self-reference도 변경 필요

### 대안 검토

없음. 기계적 rename이므로 대안 설계 불필요.
