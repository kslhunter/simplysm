## 구현계획

### 배경

Feature 2.4 리뷰에서 발견된 2건의 코드 품질 이슈를 수정한다.

### 목표

- `loadPaths` 생성 로직을 단일 헬퍼 함수로 추출 (LOGIC-001)
- `vitest-plugin`에 명시적 `cwd` 옵션 추가 (DESIGN-001)

### 비목표

- loadPaths 구성 자체의 변경 (경로 추가/제거)

### 설계

#### LOGIC-001: loadPaths 헬퍼 추출

`ngtsc-build-core.ts`에 `buildScssLoadPaths(info: NgtscBuildInfo): string[]` 헬퍼 함수를 추출. `createNgtscProgramWithHost` 내부와 `runNgtscBuild`/`runNgtscRebuild`의 `compileGlobalScss` 호출 모두 이 헬퍼를 사용.

#### DESIGN-001: vitest-plugin cwd 옵션

`AngularVitestPluginOptions`에 `cwd?: string` 옵션 추가. 미지정 시 기존 동작(`pkgDir + "/../.."`)을 유지하여 하위 호환성 보장.

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| 헬퍼 함수 추출 | 채택 | 반환값 변경 없이 단순 |
| NgtscProgramWithHostResult에 loadPaths 포함 | 미채택 | 반환 인터페이스 변경 필요, 호출자 코드 증가 |
| cwd 필수 옵션 | 미채택 | 기존 호출자 변경 필요, 하위 호환성 깨짐 |

### Vertical Slices

- **Scenarios:**
