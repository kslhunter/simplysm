# sd-claude auth CLI — 수동 검증

## 전제 조건

- `@simplysm/sd-claude` 패키지가 설치되어 `sd-claude` 명령이 PATH에 있다
- Claude Code에 로그인된 계정이 있다
- `~/.claude/` 디렉토리에 `.credentials.json`이 존재한다

## 수행 절차

### 1. save 테스트

1. `sd-claude auth save` 실행
2. "프로필 '{orgName}' 저장 완료" 메시지 확인
3. `~/.claude/profiles.json`에 계정 정보 저장 확인

### 2. save 두 번째 계정

1. 다른 계정으로 수동 로그인: `claude auth login`
2. `sd-claude auth save` 실행
3. profiles.json에 2개 계정 저장 확인

### 3. switch 대화형 전환

1. `sd-claude auth switch` 실행
2. 계정 목록이 번호와 함께 표시되는지 확인
3. 현재 계정에 `*` 마커 표시 확인
4. 전환할 계정 번호 입력
5. "'{orgName}' 계정으로 전환 완료" 메시지 확인
6. `claude auth status`로 전환 확인

### 4. switch 단일 계정

1. profiles.json에서 한 계정만 남기고 삭제
2. `sd-claude auth switch` 실행
3. "전환할 수 있는 계정이 없습니다" 메시지 확인

## 기대 결과

- save: 현재 계정의 orgName, refreshToken, usage가 profiles.json에 저장된다
- switch: 대화형 번호 선택으로 계정 전환이 완료되고, 이전 계정 백업 + 새 계정 활성화된다
