## 구현계획

### 배경

Feature 1.1~1.3에 이어 Data(Sheet/List), Overlay(Modal/Toast/Dropdown), Visual(Progress) 영역의 코드 리뷰 이슈 12건을 수정한다. 각 이슈는 독립적 버그/성능/일관성 개선이며, 기존 코드베이스의 Angular signal, effect, DestroyRef, computed 패턴을 따른다.

### 목표

- 12건의 코드 리뷰 이슈 수정 (Critical 1, Medium 6, Low 5)
- 각 수정에 대한 테스트 추가

### 비목표

- Sheet/Modal/Toast의 전체 리팩토링
- 새로운 기능 추가

### 설계

#### LOGIC-005: Sheet 리사이즈 후 소팅 방지

현재: `setTimeout(300ms)`으로 `_isOnResizing` 플래그 해제.
변경: mouseup의 `event.timeStamp`를 `_lastResizeEndTimeStamp`에 저장. `onHeaderClick`에서 `event.timeStamp - _lastResizeEndTimeStamp < 50`이면 소팅 스킵. `_isOnResizing` 플래그와 setTimeout 제거.

#### LOGIC-015: Sheet 헤더 머지 spanStartHeaders

현재: `canMerge=true`일 때 `spanStartHeaders[row]` 미갱신.
변경: 머지 시에도 `spanStartHeaders[row] = headers`로 갱신하여, 다음 컬럼이 최근 머지된 컬럼의 headers와 비교하도록 수정.

#### LOGIC-016: Sheet 클립보드 null 처리

현재: `td.textContent`(string|null)를 직접 `writeText`에 전달.
변경: `td.textContent ?? ""`로 null을 빈 문자열로 대체.

#### PERF-002: getCellStyle/getDataCellClass signal 중복 읽기

현재: `getItemCellStyleFn()`/`getItemCellClassFn()`를 조건부와 호출부에서 2회 읽음.
변경: 로컬 변수에 1회 캐시하여 사용.

#### PERF-003: getColumnCellTpl/getColumnSummaryTpl 선형 탐색

현재: `columnControls().find(c => c.key() === key)`로 O(N) 탐색.
변경: `columnControls()`를 key 기반 `Map`으로 캐시하는 `computed` signal 추가. `Map.get(key)`으로 O(1) 조회.

#### LOGIC-017: Modal z-index 가드

현재: `_bringToFront`가 매번 maxZ+1 설정.
변경: 현재 z-index가 이미 maxZ 이상이면 조기 리턴.

#### DESIGN-001: Modal 드래그/리사이즈 리스너 cleanup

현재: `DestroyRef` 미사용. 드래그 중 파괴 시 document 리스너 leak.
변경: `DestroyRef`를 inject하고 `onDestroy`에서 document 리스너 해제.

#### LOGIC-018: Toast progress setTimeout cleanup

현재: `effect` 내 `setTimeout`이 cleanup 없이 중복 등록 가능.
변경: `effect`의 `onCleanup` 콜백으로 이전 setTimeout을 `clearTimeout`.

#### LOGIC-019: Toast dismiss 양방향 정리

현재: `transitionend`와 `setTimeout` 두 경로가 독립적으로 `_destroyToast` 호출.
변경: `transitionend`에서 `clearTimeout` + `setTimeout`에서 `removeEventListener`. `transitionend`에 `{ once: true }`와 `propertyName` 필터 적용.

#### LOGIC-024: Progress bar width clamp

현재: `value() * 100 + '%'`로 100% 초과 가능.
변경: `Math.min(value() * 100, 100) + '%'`로 clamp.

#### CONSIST-005: Dropdown popup 단위 통일

현재: `clientHeight > 300`(px) 비교 후 `height = "18.75rem"` 설정.
변경: `height = "300px"`로 px 단위 통일.

#### DESIGN-006: List item flat layout ripple

현재: `setupRipple(() => !this.readonly() && !(this.layout() === "flat" && this.hasChildren()))` — flat+자식없음 시 ripple 활성.
변경: `setupRipple(() => !this.readonly() && this.layout() !== "flat")` — flat이면 무조건 ripple 비활성.

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| LOGIC-005: timeStamp 비교 | 채택 | 확정적 방식, 프로젝트 금지 패턴(setTimeout) 회피 |
| LOGIC-005: mouseup stopPropagation | 미채택 | document 레벨 mouseup은 th의 click 생성을 막지 못함 |
| LOGIC-017: z-index 주기적 재정규화 | 미채택 | 구현 복잡도 대비 효과 미미. 가드만으로 충분 |
| LOGIC-018: CSS animation + animationend | 미채택 | progress 100% 후 1초 대기는 의도적 UX이므로 effect cleanup이 적합 |
