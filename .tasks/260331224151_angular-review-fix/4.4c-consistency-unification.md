## 구현계획

### 배경

리뷰(CONSIST-002~006)에서 발견된 일관성 이슈 5건을 수정한다. 각 이슈는 독립적인 파일을 수정하므로 파일 충돌 없이 병렬 작업이 가능하다.

### 목표

- DOCUMENT 토큰 사용을 DI 패턴으로 통일
- 메뉴 인터페이스 중복 제거
- Fixed cell 배경색을 context별로 분기
- SharedData valueKey 타입 통일
- Sheet 이벤트 타입 분리로 타입 안전성 확보

### 비목표

- SSR 지원 (프로젝트 범위 외)
- ISdMenu<TModule>(sd-app-structure.provider.ts)과의 통합 (다른 용도의 인터페이스)

### 설계

#### CONSIST-002: DOCUMENT 토큰

- 3개 command 플러그인(Insert, Save, Refresh)에 `private readonly _document = inject(DOCUMENT)` 필드 추가
- `document.addEventListener` → `this._document.addEventListener`로 변경
- `findTopOpenModalEl()`에 `doc: Document` 매개변수 추가, 호출부에서 `this._document` 전달
- `SdOptionEventPlugin`에도 동일하게 `_document` 필드 추가, `supports()`에서 사용

#### CONSIST-003: 메뉴 인터페이스

- `ISdSidebarMenu`, `ISdTopbarMenu` 정의 제거
- 두 컴포넌트에서 `ISdMenu`(menu-utils.ts)를 직접 import하여 사용
- index.ts에서 `ISdSidebarMenu`, `ISdTopbarMenu` re-export 제거
- ISdMenu는 이미 index.ts에서 export 중 (line 38)
- test fixture 파일도 함께 수정

#### CONSIST-004: Fixed cell 배경색

- `_getFixedStyle(colDef, zIndex, background)` — 세 번째 매개변수로 배경색 CSS 변수 전달
- `_headerColumnStyles`에서 호출 시 `var(--theme-secondary-lightest)` 전달
- `_dataColumnBaseStyles`에서 호출 시 기존 `var(--control-color)` 전달 (기본값)

#### CONSIST-005: SharedData valueKey 타입

- `SdSharedDataSelectButtonControl`의 제네릭 제약을 `ISharedDataBase<number>` → `ISharedDataBase<string | number>`로 변경
- `TSelectModeValue<number>` → `TSelectModeValue<string | number>`로 변경
- `AbsSdDataSelectButton<TItem, number, TMode>` → `AbsSdDataSelectButton<TItem, string | number, TMode>`로 변경
- `load(keys: number[])` → `load(keys: (string | number)[])` 변경

#### CONSIST-006: Sheet 이벤트 타입

- `ISdSheetItemKeydownEventParam<T>` 유지 (key 없는 버전, 기존 itemKeydown용)에서 `key?` 제거
- `ISdSheetCellKeydownEventParam<T>` 신규 타입 추가 (key 필수)
- `cellKeydown` output의 타입을 `ISdSheetCellKeydownEventParam<T>`로 변경

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| _getFixedStyle에 boolean isHeader 매개변수 | 미채택 | 배경색 값을 호출부에서 결정하는 것이 더 유연 |
| ISdSheetItemKeydownEventParam을 union type으로 | 미채택 | 별도 타입이 더 명확하고 IDE 자동완성에 유리 |
