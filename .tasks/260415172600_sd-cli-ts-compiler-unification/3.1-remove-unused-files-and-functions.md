## 구현계획

### 배경

SdTsCompiler 통합(Feature 1.1~2.4)이 완료되어, 이전의 개별 컴파일러 구현(`runTscPackageBuild`, `AngularCompiler`, `AngularBuildPipeline`)은 더 이상 사용되지 않는다. 이들을 깨끗하게 제거하여 코드베이스를 정리한다. [근거: wbs "통합 후 기존 개별 구현은 사용처가 없어지므로 제거 대상"]

### 목표

- 미사용 파일 2개 삭제: `tsc-build.ts`, `angular-build-pipeline.ts` [근거: Rule "미사용 파일은 전체 삭제"]
- 미사용 클래스/함수 제거: `AngularCompiler`, `buildCompilerOptions`, `buildScssLoadPaths` [근거: Rule "부분 사용 파일은 미사용 export만 제거"]
- `writeEmitResults` 함수를 `ngtsc-build-core.ts`로 이동 [근거: 설계 결정 D1]
- 관련 테스트 파일 정리 [근거: Rule "삭제된 코드의 테스트도 제거"]

### 비목표

- `utils/tsconfig.ts` 변경 [근거: wbs 경계 "typecheck 전용 유틸은 유지"]
- `angular-build.ts` 변경 [근거: wbs 경계 "SdTsCompiler에서 import하므로 유지"]
- TypecheckOrchestrator 변경 [근거: wbs 제외 사항]

### 설계

**파일 삭제 목록:**
- `src/utils/tsc-build.ts` — 전체 삭제 (227줄)
- `src/angular/angular-build-pipeline.ts` — `writeEmitResults` 이동 후 전체 삭제 (362줄)

**코드 제거 목록:**
- `src/angular/angular-compiler.ts`:
  - 제거: `AngularCompiler` 클래스, `AngularCompilerOptions` 인터페이스, `hasTemplateExtension()`, `ensureSourceFileVersions()`, `NgtscProgram`/`OptimizeFor` import (AngularCompiler 전용), `NgCompiler` 타입 별칭
  - 유지: `EmitResult`, `EmitOptions`, `AngularSourceFileCache`, `augmentHostWithCaching`
- `src/angular/ngtsc-build-core.ts`:
  - 제거: `buildCompilerOptions()`, `buildScssLoadPaths()`, 관련 미사용 import (`BuildOutput`, `TypecheckEnv`)
  - 유지: 나머지 전부 (`trackDeps`, `formatScssError`, `SideEffectScssEntry`, `SideEffectScssOptions`, `createLibraryTransformStylesheet`, `compileSideEffectScss`, `compileGlobalScss`, `NgtscBuildInfo`, `NgtscBuildResult`, `NgtscCombinedBuildEvent`)

### 대안 검토

`writeEmitResults`를 독립 파일(`emit-result-writer.ts`)로 분리하는 방안도 고려했으나, 이 함수가 의존하는 `trackDeps`, `formatScssError`, `SideEffectScssOptions`가 모두 `ngtsc-build-core.ts`에 있어 응집도가 낮아진다. 사용자 선택에 따라 `ngtsc-build-core.ts`로 이동한다.
