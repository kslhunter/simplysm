      Then ._backdrop이 화면 전체를 덮는다
      And ._backdrop의 배경이 반투명이다

  Rule: dialog는 화면 중앙에 위치
    # 근거: 표준 모달 패턴

      Given open이 true이다
      Then ._dialog가 수평/수직 중앙에 위치한다
      And ._dialog에 배경색과 그림자가 있다
      And ._dialog에 border-radius가 적용된다

  Rule: header는 제목과 닫기 버튼을 포함
    # 근거: template ._header > ._title + ._close-btn
    Scenario: 헤더 레이아웃
      Given open이 true이고 hideHeader가 false이다
      Then ._header가 flex row 레이아웃이다
      And ._title이 좌측에 위치한다
      And ._close-btn이 우측에 위치한다

  Rule: resize handle은 방향별 커서 표시
    # 근거: template 8방향 ._resize-handle
    Scenario: resize handle에 방향별 커서
      Given open이 true이고 resizable이 true이다
      Then 각 resize handle에 방향에 맞는 커서가 표시된다

  Rule: float 모달은 작은 크기
    # 근거: input float
    Scenario: float 모달 스타일
      Given data-sd-float가 설정되었다
      Then dialog가 작은 크기로 표시된다

  Rule: fill 모달은 전체 채움
    # 근거: input fill
    Scenario: fill 모달 스타일
      Given data-sd-fill이 설정되었다
      Then dialog가 거의 전체 화면을 채운다

  Rule: position 모달은 지정 위치
    # 근거: input position
    Scenario: bottom-right 위치
      Given data-sd-position이 "bottom-right"이다
      Then dialog가 우하단에 위치한다

    Scenario: top-right 위치
      Given data-sd-position이 "top-right"이다
      Then dialog가 우상단에 위치한다

## 구현계획

### 배경

sd-modal.control.ts는 완성된 template과 로직을 보유하나 `styles` 속성만 누락. 동일 overlay 카테고리 형제 컴포넌트(sd-busy-container, sd-dropdown-popup, sd-toast-container)가 인라인 SCSS 패턴을 사용. [근거: 코드 확인]

### 목표

- sd-modal.control.ts에 인라인 SCSS `styles` 추가 [근거: 전체 Rule]
- 기존 테스트 통과 유지 [근거: 프로젝트 안정성]

### 비목표

- 애니메이션/트랜지션 [근거: wbs 경계]
- template/로직 변경 [근거: wbs 경계]

### 설계

- SCSS import: `@use "../../../../scss/commons/variables"`, `@use "../../../../scss/commons/mixins"`, `@use "sass:map"` [근거: 형제 컴포넌트 패턴]
- 호스트 셀렉터: `sd-modal { ... }` (ViewEncapsulation.None) [근거: 형제 컴포넌트 패턴]
- z-index: `map.get(variables.$vars, z-index, modal)` [근거: _variables.scss modal: 4000]
- elevation: `@include mixins.elevation(8)` [근거: dropdown-popup은 4 사용, 모달은 더 높은 레벨]
- CSS 변수: --gap-*, --theme-*, --trans-*, --control-color, --border-color-* 등 활용 [근거: 기존 변수 시스템]
- 상태 선택자: `&[data-sd-open]`, `&[data-sd-float]`, `&[data-sd-fill]`, `&[data-sd-position]` [근거: host 바인딩]

### 대안 검토

- 전역 SCSS 파일로 분리: 일관성 부족으로 기각 [근거: 형제 컴포넌트 모두 인라인]
