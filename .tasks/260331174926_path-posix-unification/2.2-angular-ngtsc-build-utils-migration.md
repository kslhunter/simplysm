## 구현계획

### 배경

sd-cli의 Angular/ngtsc 빌드 유틸리티 3개 파일에 `.replace(/\\/g, "/")` 패턴이 산재해 있다. Feature 1.1에서 `pathx.posix()`와 `pathx.posixResolve()`가 core-node에 도입되었으므로, 이 ad-hoc 패턴을 `pathx.posix()`로 통일한다.

### 목표

- ngtsc-build-core.ts, angular-compiler.ts, vite-angular-plugin.ts의 모든 `.replace(/\\/g, "/")` 패턴을 `pathx.posix()`로 교체
- vite-angular-plugin.ts의 중복 `normalizePath` 함수 제거

### 비목표

- SCSS 경로 처리 변경 (fs API에 직접 전달되는 `path.join`/`path.resolve` 결과는 변환 대상 아님)
- `path.join`/`path.resolve`/`path.dirname` 자체를 `posixResolve`로 교체 (fs API용 경로는 플랫폼 네이티브 유지)

### 설계

각 파일에서 `.replace(/\\/g, "/")` 패턴을 `pathx.posix()`로 1:1 교체한다. 모든 교체는 동일 동작이며 반환 타입만 `string` → `PosixPath`로 변경된다.

| 파일 | 라인 | 현재 코드 | 변경 후 |
|------|------|----------|--------|
| ngtsc-build-core.ts | 321 | `pkgSrcDir.replace(/\\/g, "/")` | `pathx.posix(pkgSrcDir)` |
| ngtsc-build-core.ts | 362 | `fileName.replace(/\\/g, "/")` | `pathx.posix(fileName)` |
| angular-compiler.ts | 72 | `file.replace(/\\/g, "/")` | `pathx.posix(file)` |
| angular-compiler.ts | 315 | `relativePath.replace(/\\/g, "/")` | `pathx.posix(relativePath)` |
| angular-compiler.ts | 396 | `f.replace(/\\/g, "/")` | `pathx.posix(f)` |
| angular-compiler.ts | 406 | `resourceDep.replace(/\\/g, "/")` | `pathx.posix(resourceDep)` |
| vite-angular-plugin.ts | 전체 | `normalizePath(x)` 호출 (8건) | `pathx.posix(x)` |
| vite-angular-plugin.ts | 422-424 | `normalizePath` 함수 정의 | 삭제 |

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| `pathx.posix()` 사용 | 채택 | Feature 1.1에서 도입한 표준 유틸리티, 코드베이스 통일 목적에 부합 |
| 로컬 `normalizePath` 유지 | 미채택 | core-node에 동일 기능이 있으므로 중복 |
