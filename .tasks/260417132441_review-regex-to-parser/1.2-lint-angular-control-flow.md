## 구현계획

### 배경

`ts-no-unused-protected-readonly` 규칙은 `@Component`의 `protected readonly` 필드가 인라인 템플릿과 클래스 본문에서 모두 미사용일 때 autofix로 제거한다. 템플릿 참조 탐지는 `@angular/compiler`의 `parseTemplate`로 얻은 AST를 리플렉션 기반으로 순회하며 `ImplicitReceiver`/`ThisReceiver` 위의 `PropertyRead` 이름을 수집한다. 현재 구현은 Angular 17+ 제어 흐름 블록(`@if`/`@for`/`@switch`/`@defer`)의 **고유 속성**(`expression`, `trackBy`, `branches`, `groups`, `triggers`, `placeholder`/`loading`/`error` 등)을 탐색하지 않아 블록 내부에서 참조된 필드가 `false positive`로 오탐된다. 또한 AST 노드 타입 식별을 `constructor.name` 문자열 비교로 수행하여 Angular 내부 클래스명 변경 시 조용히 실패한다.

### 목표

- `@if`/`@for`/`@switch` 블록의 표현식·로컬 변수가 정확히 처리됨 [근거: Rule "@if 블록 지원", "@for 블록 지원", "@switch 블록 지원"]
- `@defer`/`@placeholder`/`@loading`/`@error` 블록의 트리거·자식 참조도 처리됨 [근거: D1]
- AST 노드 타입 식별을 `instanceof`로 교체 — `PropertyRead`/`ImplicitReceiver`/`ThisReceiver`/`LetDeclaration` [근거: Rule "AST 노드 타입은 instanceof로 식별"]
- 기존 테스트 전체 통과 보장 [근거: WBS "기존 테스트 통과"]

### 비목표

### 설계

#### import 추가 (현재 2개 → 확장)

`@angular/compiler`는 템플릿 AST 노드 클래스를 `TmplAst*` 네임스페이스로 export한다. 표현식 AST(`PropertyRead`/`ImplicitReceiver`/`ThisReceiver`)는 alias가 없으므로 그대로 import.

```ts
import {
  parseTemplate,
  PropertyRead,
  ImplicitReceiver,
  ThisReceiver,
  TmplAstLetDeclaration,
  TmplAstIfBlock,
  TmplAstIfBlockBranch,
  TmplAstForLoopBlock,
  TmplAstSwitchBlock,
  TmplAstSwitchBlockCaseGroup,
  TmplAstSwitchBlockCase,
  TmplAstDeferredBlock,
  TmplAstBoundDeferredTrigger,
} from "@angular/compiler";
```

**주의:** `LetDeclaration`(expression용)과 `TmplAstLetDeclaration`(template AST용)이 별개 클래스다. `parseTemplate()` 결과의 `@let` 노드는 `TmplAstLetDeclaration`이므로 반드시 `TmplAst*` alias를 사용한다.

#### `collectExprIdentifiers` 변경 (`ts-no-unused-protected-readonly.ts:30-57`)

- `ast.constructor?.name === "PropertyRead"` → `ast instanceof PropertyRead`
- `ast.receiver?.constructor?.name === "ImplicitReceiver"|"ThisReceiver"` → `ast.receiver instanceof ImplicitReceiver || ast.receiver instanceof ThisReceiver`

#### `collectTemplateNodeIdentifiers` 변경 (`ts-no-unused-protected-readonly.ts:63-118`)

- `node.constructor?.name === "LetDeclaration"` → `node instanceof LetDeclaration`
- **로컬 변수 등록 추가:**
  - `node instanceof IfBlockBranch` 이고 `node.expressionAlias != null` → `currentLocals.add(node.expressionAlias.name)`
  - `node instanceof ForLoopBlock` → `currentLocals.add(node.item.name)` + `contextVariables.forEach(v => currentLocals.add(v.name))`
- **블록 표현식 수집:**
  - `IfBlockBranch.expression` (nullable)
  - `ForLoopBlock.expression`, `ForLoopBlock.trackBy`
  - `SwitchBlock.expression`
  - `SwitchBlockCase.expression` (nullable, `@default`는 null)
  - `DeferredBlock.triggers / prefetchTriggers / hydrateTriggers` 내 `BoundDeferredTrigger.value` (나머지 idle/immediate/hover/timer/interaction/viewport/never는 식별자 표현식 없음)
- **블록 특수 자식 재귀:**
  - `IfBlock.branches[]` → 각 `IfBlockBranch`를 재귀 호출
  - `SwitchBlock.groups[]` → 각 `SwitchBlockCaseGroup`를 재귀 호출
  - `SwitchBlockCaseGroup.cases[]` → 각 `SwitchBlockCase`를 재귀 호출 (`children`은 기존 `node.children` 경로로 커버됨)
  - `ForLoopBlock.empty?.children` → 재귀 호출
  - `DeferredBlock.placeholder?.children`, `loading?.children`, `error?.children` → 재귀 호출

#### 영향 범위

- `packages/lint/src/rules/ts-no-unused-protected-readonly.ts` (단일 파일 수정)
- `packages/lint/tests/ts-no-unused-protected-readonly.spec.ts` (테스트 보강)
