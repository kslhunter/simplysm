## 구현계획

### 배경

`SdDataDetailBase<T, R>`(`sd-data-detail.base.ts:29`)는 `load`/`submit`/`toggleDelete`/`canUse`/`canEdit`/`canDelete`/`prepareRefreshEffect` 7개 abstract·optional 멤버를 요구하고, 내부에서 `effect` + `queueMicrotask` + `setupCanDeactivate` + `withBusy` + `sdToast.try`를 조합하여 상세 폼의 라이프사이클을 감춘다. `<sd-data-detail>` 컴포넌트(`sd-data-detail.ts:192`)는 `injectParent<SdDataDetailBase<any>>()` 역참조로 부모 Base 인스턴스의 signal·메서드에 접근하여 3뷰(page/modal/control)의 버튼 레이아웃을 렌더링한다. 이 상속·역참조 구조는 LLM 에이전트 세션에서 (1) 7개 멤버의 역할 암기 부담, (2) `injectParent`의 Angular internal `_lView[8]` 트릭 의존, (3) 부모 Base 파일 동반 열람 필요를 발생시킨다(WBS "배경" 5행).

본 Feature는 위 두 파일과 관련 테스트·문서를 모두 제거하고, 소비 화면이 `<sd-form>`·`<sd-busy-container>`·`<sd-topbar-container>`·`<sd-topbar>` 표준 컴포넌트를 직접 조립하도록 전환한다. 조립 절차는 `packages/angular/docs/recipes/crud-detail.md`에 완성 예제와 변형 2종으로 박제하여 복사·수정만으로 상세 폼을 완성 가능하게 한다.
