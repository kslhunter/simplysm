#### 4. 관용 규칙 3종 (10번 섹션)

WBS 89-91행을 그대로 수록:

- **규칙 1 (셀 내부 컨트롤 `inset`/`size`)**: `<sd-sheet-column>`의 `[cell]` 템플릿 안에 삽입되는 컨트롤(`sd-textfield`/`sd-select`/`sd-checkbox`/`sd-numpad`/`sd-date-range-picker`/`sd-textarea`)은 `[inset]="true" [size]="'sm'"` 명시. 예외: 복합 구조(텍스트+컨트롤) `[inset]="false"`, 큰 시트 행은 `[size]` 생략. 누락 시 컴파일 에러 없이 스타일 깨짐 → "자주 하는 실수"에 명시.
- **규칙 2 (`mark(sig)` 역할)**: `mark(sig)`는 **UI 동기화**용이지 "저장 감지"가 아니다. `obj.equal`(`packages/core-common/src/utils/obj.ts:172`)이 deep equal로 값 차이를 감지하므로 signal mutation은 mark 없이도 submit에서 감지된다. mark의 실제 역할은 **signal 참조 갱신 → OnPush 템플릿 재렌더링 + 다른 computed/effect 의존성 갱신**. Chrome 61 호환성(Proxy 폴리필 불가)으로 자동 notify 불가하여 명시적 호출 필요. `"mark 없으면 저장이 안 된다"` 식 서술 금지.
- **규칙 3 (`sortingDefs` + `orderBy` 체인)**: `orderBy` string overload 사용. `qr.orderBy(s.key, s.desc ? "DESC" : "ASC")` 형태 권장(`packages/orm-common/src/exec/queryable.ts:420` 완료). 체인 경로는 `"user.name"` 형태 지원.
