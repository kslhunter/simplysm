### 유사 기능: `setupCanDeactivate`의 page 판정 패턴

본 Feature의 `injectViewTypeSignal` 수정은 `setupCanDeactivate`의 라우트 식별 로직과 동일 패턴을 적용한다.

- 판정 패턴: `packages/angular/src/core/routing/setupCanDeactivate.ts:15-26` — `activatedRoute.routeConfig`·`component`·`reflectComponentType(component)?.selector` vs `elRef.nativeElement.tagName.toLowerCase()` 비교
  ```typescript
  if (activatedRoute) {
    if (!activatedRoute.routeConfig) return;
    const component = activatedRoute.component;
    if (component == null || typeof component === "string") return;
    if (
      reflectComponentType(component)?.selector !==
      elRef.nativeElement.tagName.toLowerCase()
    ) {
      return;
    }
    // ... page 확정 처리
  }
  ```
- `ElementRef` 주입: `packages/angular/src/core/routing/setupCanDeactivate.ts:8` `const elRef = inject(ElementRef);`
- optional provider 주입: `packages/angular/src/core/routing/setupCanDeactivate.ts:6-7` `inject(SdActivatedModalProvider, { optional: true })` + `inject(ActivatedRoute, { optional: true })`

### 유사 기능: 테스트에서 `reflectComponentType` 메타데이터 모킹

수정된 `injectViewTypeSignal` 테스트는 `activatedRoute.component`가 `ɵcmp`(compiled component) 메타데이터를 갖는 클래스여야 한다.

- 테스트 헬퍼: `packages/angular/tests/core/routing/view-signals-router-guard.spec.ts:11-16`
  ```typescript
  function createTestComponent(selector: string) {
    const comp = class {} as unknown as Record<string, unknown>;
    comp["ɵcmp"] = { selectors: [[selector]] };
    return comp;
  }
  ```
- `ElementRef` mock provider: `packages/angular/tests/core/routing/view-signals-router-guard.spec.ts:244-247` `{ provide: ElementRef, useValue: { nativeElement: { tagName: "TEST-COMP" } } }`

### 배경

Feature 1.1~5.1이 완료되어 `SdBaseContainer`를 제외한 4종 유틸(`TXT_CHANGE_IGNORE_CONFIRM`, `withBusy`, `setupCumulateSelectedKeys`, `injectParent`)의 src 내 호출부가 모두 사라졌다. 본 Feature는 (1) 5개 심볼(4종 + `SdBaseContainer`) 파일 삭제와 (2) `injectViewTypeSignal` 시그니처 수정, 그리고 이들의 (3) index.ts export·테스트·문서 정합성 확보를 통해 본 WBS 프로젝트의 추상화 제거를 마무리한다.

#### 1. `injectViewTypeSignal.ts` 수정

`setupCanDeactivate.ts:5-42` 패턴을 그대로 차용한다. `SdActivatedModalProvider` 우선, 그다음 `ActivatedRoute.component`의 selector와 host tagName 비교.

**변경 후 (`packages/angular/src/core/routing/injectViewTypeSignal.ts`)**:
```typescript
import { computed, ElementRef, inject, reflectComponentType, type Signal } from "@angular/core";
import { ActivatedRoute } from "@angular/router";
import { SdActivatedModalProvider } from "../modal/sd-activated-modal.provider";
import { injectCurrentPageCodeSignal } from "./injectCurrentPageCodeSignal";
import { injectFullPageCodeSignal } from "./injectFullPageCodeSignal";

export function injectViewTypeSignal(): Signal<SdViewType> {
  const sdActivatedModal = inject(SdActivatedModalProvider, { optional: true });
  const activatedRoute = inject(ActivatedRoute, { optional: true });
  const elRef = inject(ElementRef);

  const fullPageCode = injectFullPageCodeSignal();
  const currPageCode = injectCurrentPageCodeSignal();

  return computed<SdViewType>(() => {
    if (sdActivatedModal != null) {
      return "modal";
    }

    if (activatedRoute) {
      const component = activatedRoute.component;
      if (component == null || typeof component === "string") {
        return "control";
      }
      if (
        reflectComponentType(component)?.selector !==
        elRef.nativeElement.tagName.toLowerCase()
      ) {
        return "control";
      }
      if (fullPageCode() === currPageCode?.()) {
        return "page";
      }
    }

    return "control";
  });
}

export type SdViewType = "page" | "modal" | "control";
```

- 기각 사유: WBS 핵심 제거 대상이 `injectParent` 포함 "internal API 트릭"이고, 이 판정은 `this._parent`의 reference를 통한 역참조에 의존했다. `SdBaseContainer` 삭제로 부모 참조 자체가 불필요해졌고, `setupCanDeactivate`가 이미 공식 API 기반 동일 판정을 제공하므로 일관성 차원에서 같은 패턴을 적용하는 것이 자연스럽다. 추가로 `wbs.md:320`에 "ElementRef.tagName + reflectComponentType(...).selector 비교로 대체"가 명시되어 있다

**대안 2: `injectViewTypeSignal`을 아예 제거하고 소비 화면이 `inject(SdActivatedModalProvider, { optional: true })` + 수동 체크**

- 동기: 추상화 최소화
- 기각 사유: wbs.md:318-320에 "`injectViewTypeSignal`·`SdViewType` export 유지, 수정만 수행" 명시. 라우팅 유틸로 유지하기로 사용자 결정됨
