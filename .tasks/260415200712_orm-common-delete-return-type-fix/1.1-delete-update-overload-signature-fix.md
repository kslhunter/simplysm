## 구현계획

### 배경
`Queryable` 클래스의 CUD 메서드(`insert`, `update`, `delete`, `upsert`) 중 `outputColumns`를 받는 오버로드는 반환 타입으로 `Pick<TFrom["$inferColumns"], K>[]`를 사용해야 한다. `insert`와 `upsert`는 올바르게 `$inferColumns`를 참조하지만, `update`와 `delete`는 `$columns`를 참조하여 `ColumnBuilder` 타입이 반환된다. [근거: 코드 확인]

### 목표
- `update`/`delete` 오버로드의 반환 타입을 `$inferColumns`로 수정하여 4개 CUD 메서드의 일관성 확보 [근거: Rule "outputColumns 지정 시 반환 타입은 추론된 원시 타입이어야 함"]

### 비목표
- 런타임 로직 변경 [근거: wbs 경계 "타입 시그니처만 수정"]

### 설계
`queryable.ts`에서 `update`/`delete`의 오버로드 시그니처, 구현부 시그니처, `executeDefs` 제네릭 인자에서 `TFrom["$columns"]`를 `TFrom["$inferColumns"]`로 변경한다. [근거: `insert` 패턴 참조]

### 대안 검토
없음 — 명백한 타입 불일치 버그이므로 다른 접근이 불필요하다.

- **구현 내용:** `queryable.ts`의 `update` (1487-1495) 및 `delete` (1525-1531)에서 `$columns` → `$inferColumns` 일괄 변경
