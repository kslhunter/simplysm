## 구현계획

### 배경

`SdModal`(v14)은 signal input 기반 standalone 컴포넌트이다. 헤더 영역(`._header` div)은 `hideHeader()` 조건으로 표시/숨김되며, 현재 인라인 스타일 바인딩이 없다. `SdModalProvider`는 `SdModalOptions` 인터페이스를 통해 옵션을 `setInput`으로 전달한다.

### 목표

- 모달 헤더에 인라인 스타일을 적용할 수 있는 `headerStyle` input 복원 [근거: Rule "headerStyle input으로 모달 헤더에 인라인 스타일 적용"]
- `SdModalProvider.showAsync`에서도 `headerStyle` 옵션 전달 가능 [근거: v14 패턴 — SdModalOptions가 SdModal 설정 가능 input을 미러링]

### 비목표

- `useCloseByBackdrop`/`useCloseByEscapeKey`/`movable` 기본값 변경 [근거: wbs 경계]
- `title` required→optional, `dialogElRef` 제거 [근거: wbs 경계]

### 설계

- `SdModal`에 `headerStyle = input<string | undefined>(undefined)` 추가 [근거: v14 optional input 패턴]
- 템플릿 `._header` div에 `[style]="headerStyle()"` 바인딩 추가 [근거: v12 sd-modal.control.ts:64]
- `SdModalOptions`에 `headerStyle?: string` 필드 추가 [근거: 기존 미러링 패턴 유지]

### 대안 검토

없음. 단순 input 복원으로 대안이 필요한 설계 결정이 없다.
