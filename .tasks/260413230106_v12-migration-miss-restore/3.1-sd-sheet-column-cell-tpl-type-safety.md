## 구현계획

### 배경

`SdSheet`와 `SdSheetColumn`은 시트 UI의 핵심 컴포넌트/디렉티브이다. 현재 v14의 `cellTplRef`는 optional이며 string-based `"cellTpl"` ref를 사용하고, `SdSheetCellContext`의 `$implicit`과 `item`이 `unknown` 타입이어서 소비앱에서 타입 안전성이 없다. v14에는 이미 동일 패턴의 `SdItemOfTemplate` 디렉티브(`sd-item-of-template.ts`)가 존재하며, 이를 참고하여 구현한다. [근거: v14 sd-item-of-template.ts]

### 목표

- SdSheetColumnCellTemplate 디렉티브를 통해 셀 템플릿의 타입 추론 복원 [근거: Rule "ngTemplateContextGuard에 의해 item의 타입이 T로 추론"]
- cellTplRef를 required로 변경하여 컴파일 시점 안전성 확보 [근거: Rule "cellTplRef는 required"]
- v14의 기존 SdItemOfTemplate 패턴과 일관성 유지 [근거: sd-item-of-template.ts 패턴]

### 비목표

- summaryTplRef/headerTplRef의 타입 추론 변경 [근거: WBS 경계 "기존 문자열 ref 패턴 유지"]
- sd-sheet.ts 템플릿 또는 로직 변경 [근거: 기존 getColumnCellTpl/ngTemplateOutletContext 동작 유지]
- SdSheetCellContext 파일 이동 [근거: D3 결정 — 최소 변경]

### 설계

**1. SdSheetColumnCellTemplate 디렉티브** (신규 파일: `packages/angular/src/data/sheet/sd-sheet-column-cell-template.ts`)
[근거: v14 SdItemOfTemplate 패턴 복제]

```typescript
import { Directive, input } from "@angular/core";
import type { SdSheetCellContext } from "./sd-sheet-column";

@Directive({
  selector: "ng-template[cell]",
  standalone: true,
})
export class SdSheetColumnCellTemplate<T> {
  cell = input.required<T[]>();

  static ngTemplateContextGuard<TContextItem>(
    _dir: SdSheetColumnCellTemplate<TContextItem>,
    _ctx: unknown,
  ): _ctx is SdSheetCellContext<TContextItem> {
    return true;
  }
}
```

- `import type`으로 SdSheetCellContext를 참조하여 순환 의존 회피 [근거: D3, verbatimModuleSyntax]
- `SdItemOfTemplate`과 동일 구조 (selector 패턴, input.required, ngTemplateContextGuard)

**2. SdSheetCellContext<T> 제네릭 적용** (수정: `sd-sheet-column.ts`)
[근거: Rule "$implicit과 item은 T 타입"]

```typescript
// Before:
export interface SdSheetCellContext {
  $implicit: unknown;
  item: unknown;
  // ...
}

// After:
export interface SdSheetCellContext<T = unknown> {
  $implicit: T;
  item: T;
  index: number;
  depth: number;
  edit: boolean;
}
```

- `T = unknown` 기본값으로 기존 참조 (`contentChild<TemplateRef<SdSheetCellContext>>`) 하위호환

**3. SdSheetColumn<T = unknown> 제네릭 + cellTplRef required** (수정: `sd-sheet-column.ts`)
[근거: D2, Rule "cellTplRef는 required"]

```typescript
// Before:
export class SdSheetColumn {
  cellTplRef = contentChild<TemplateRef<SdSheetCellContext>>("cellTpl");
}

// After:
export class SdSheetColumn<T = unknown> {
  cellTplRef = contentChild.required<any, TemplateRef<SdSheetCellContext<T>>>(
    SdSheetColumnCellTemplate,
    { read: TemplateRef },
  );
}
```

- `T = unknown` 기본값 → SdDataSheetColumn extends SdSheetColumn 등 기존 참조 호환 [근거: D2]
- contentChild.required → 셀 템플릿 필수화 [근거: v12 패턴]

**4. index.ts export 추가** (수정: `packages/angular/src/index.ts`)
[근거: SdItemOfTemplate/SdItemOfTemplateContext export 패턴]

```typescript
export { SdSheetColumnCellTemplate } from "./data/sheet/sd-sheet-column-cell-template";
// SdSheetColumn export 라인에 type SdSheetCellContext 추가
export { SdSheetColumn, type SdSheetCellContext } from "./data/sheet/sd-sheet-column";
```

**5. sd-sheet.ts 변경 불필요**
[근거: D1 — standalone imports에 추가 불필요]

- `getColumnCellTpl()`: `col?.cellTplRef() ?? null` — required여도 col이 undefined일 수 있으므로 동일 동작
- template의 `@if (getColumnCellTpl(...); as tpl)` — 그대로 유지
- ngTemplateOutletContext의 인라인 객체 — SdSheetCellContext<unknown>에 호환

### 대안 검토

**A. 문자열 ref 유지 + 별도 type guard**
- `#cellTpl` 유지하면서 별도 메커니즘으로 타입 추론
- 선택하지 않은 이유: Angular의 ngTemplateContextGuard는 디렉티브 selector 기반으로만 동작하므로 string ref와 결합 불가

**B. SdSheetCellContext를 sd-sheet-column-cell-template.ts로 이동**
- 디렉티브와 컨텍스트 인터페이스를 같은 파일에 배치 (SdItemOfTemplate 패턴)
- 선택하지 않은 이유: sd-sheet-column.ts → sd-sheet-column-cell-template.ts (런타임), sd-sheet-column-cell-template.ts → sd-sheet-column.ts (런타임)으로 순환 의존 발생. import type으로 한쪽을 끊을 수 있으나, 현재 위치 유지가 변경량 최소
