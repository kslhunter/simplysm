## 구현계획

### 배경

`SdDataSheet`은 `SdDataSheetColumn`(extends `SdSheetColumn`)을 content projection으로 받아, 내부적으로 새로운 `<sd-sheet-column>`을 생성하여 렌더링한다. 이 과정에서 `columnControl`의 속성을 내부 `<sd-sheet-column>`에 개별 바인딩으로 전달하는데, Feature 1.1에서 추가된 `headerStyle`/`tooltip`/`headerTplRef`가 누락되었다. `summaryTplRef`는 동일 위치(line 255-258)에서 `@if + nested ng-template` 패턴으로 이미 전파되고 있다. [근거: sd-data-sheet.ts:244-258]

### 목표

- sd-data-sheet-column에 설정된 headerStyle/tooltip이 내부 sd-sheet-column을 통해 헤더 셀에 반영되도록 한다 [근거: Rule "headerStyle/tooltip이 헤더 셀에 적용된다"]
- sd-data-sheet-column에 선언된 #headerTpl이 내부 sd-sheet-column을 통해 렌더링되도록 한다 [근거: Rule "headerTplRef 전파", summaryTplRef 패턴 일관성]

### 비목표

- SdDataSheetColumn 클래스 변경 [근거: wbs 경계 "SdSheetColumn 상속으로 이미 input 보유"]

```html
  </ng-template>
}
```
