## 구현계획

### 배경

`SdCollapseIcon`은 접기/펼치기 상태를 시각적으로 나타내는 아이콘 컴포넌트이다. 현재 v14에서 아이콘이 `icons.tablerChevronRight`로 하드코딩되어(`sd-collapse-icon.ts:20,42`) 커스터마이징이 불가하다. v12에서는 `icon = input(tablerChevronDown)`으로 커스터마이징이 가능했다(`sd-collapse-icon.control.ts:34`). [근거: WBS 범위]

### 목표

- `icon` signal input을 추가하여 소비앱이 아이콘을 커스터마이징할 수 있도록 한다 [근거: Rule "icon input은 선택적이며 기본값은 tablerChevronRight"]

### 비목표

- 아이콘 방향 변경 (v12 `tablerChevronDown` → v14 `tablerChevronRight`는 의도적 변경) [근거: WBS 경계]

### 설계

- `icons` 인스턴스 프로퍼티(`sd-collapse-icon.ts:42`)를 `icon = input(tablerChevronRight)` signal input으로 대체 [근거: v12 패턴 `sd-collapse-icon.control.ts:34` + v14 signal input 컨벤션]
- 템플릿에서 `[svg]="icons.tablerChevronRight"`를 `[svg]="icon()"` 바인딩으로 변경(`sd-collapse-icon.ts:20`) [근거: v14 signal input 컨벤션]

### 대안 검토

- **`icons` 프로퍼티 유지 + `icon` input 추가**: 프로퍼티가 미사용이 되어 불필요한 코드 증가. 기각.

- **Scenarios:** 기본 아이콘 렌더링, 커스텀 아이콘 렌더링, 커스텀 아이콘과 회전
