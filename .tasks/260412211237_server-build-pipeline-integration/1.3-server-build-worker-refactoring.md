## 구현계획

### 배경

현재 `server-build.worker.ts`에서 esbuild(TS→JS transpile + 번들링)와 tsc(타입체크 + DTS emit)가 수동으로 병렬 실행된다 (`build()` `:146-185`, `rebuildAll()` `:243-296`). Feature 1.1에서 `createTscPlugin`이 구현되고, Feature 1.2에서 `server-esbuild-context.ts`에 tsc 플러그인이 통합되었으므로, 워커의 호출 코드를 플러그인 기반으로 전환한다. [근거: WBS 프로젝트 개요 + Feature 1.1/1.2 완료]

### 목표

- build() js=true에서 로컬 tscPlugin + 단일 esbuild.build()로 tsc 통합 [근거: Rule "build() js=true에서 tscPlugin을 로컬 생성"]
- rebuildAll() js=true에서 esbuildCtx.rebuild() 단일 호출로 tsc 자동 트리거 [근거: Rule "rebuildAll() js=true에서 esbuildCtx.rebuild() 단일 호출"]
- rebuildAll()을 startWatch() 내부 클로저로 이동하여 lastBuilderProgram 로컬 관리 [근거: D1]
- js=false 경로는 직접 runTscPackageBuild() 호출 유지 [근거: Rule "build()/rebuildAll() js=false"]
- 모듈 스코프 watch 상태(lastBuilderProgram, watchInfo, watchLintRunner) 제거 [근거: Rule "모듈 스코프 watch 상태 제거"]

### 비목표

- 외부 인터페이스 변경 (ServerBuildInfo 등) [근거: WBS 경계]
- 프로덕션 아티팩트 로직 변경 [근거: WBS 경계]
- server-watch-manager.ts 코드 변경 [근거: WBS 경계 "실질적 코드 변경 없음"]

**2. rebuildAll()을 startWatch() 내부 클로저로 이동** [근거: D1, Rule R4-R7]

```typescript
async function startWatch(info: ServerWatchInfo): Promise<void> {
  guardStartWatch();
  // 기존 watchInfo = info; 제거 — info 직접 사용

  let lastBuilderProgram: ts.EmitAndSemanticDiagnosticsBuilderProgram | undefined;
  let watchLintRunner: LintWithProgramRunner | undefined;

  async function rebuildAll(): Promise<ServerCombinedBuildEvent> {
    logger.debug(`[${info.name}] rebuildAll 시작`);
    const mainJsPath = pathx.posixResolve(info.pkgDir, "dist", "main.js");

    if (info.output.js) {
      // js=true: esbuildCtx.rebuild() 단일 호출 (tsc 자동 트리거)
      const rebuildResult = await esbuildCtx.rebuild();
      const jsResult = rebuildResult ?? { success: true, errors: undefined, warnings: undefined };

      // lint: context getter 사용
      let lint: LintWithProgramResult | undefined;
      const tscProgram = esbuildCtx.getTscProgram();
      if (info.output.lint === true && tscProgram != null) {
        if (watchLintRunner == null) {
          watchLintRunner = new LintWithProgramRunner({ cwd: info.cwd, pkgName: info.name });
        }
        lint = await watchLintRunner.lint({
          program: tscProgram,
          affectedFiles: esbuildCtx.getTscAffectedFiles(),
        });
      }

      return { build: { ...jsResult }, lint, mainJsPath };
    } else {
      // js=false: runTscPackageBuild 직접 호출
      const parsedConfig = parseTsconfig(info.pkgDir);
      const tscResult = runTscPackageBuild({
        pkgDir: info.pkgDir,
        cwd: info.cwd,
        output: { js: false, dts: info.output.dts },
        parsedConfig,
        env: info.output.env,
        includeTests: info.output.includeTests,
        oldBuilderProgram: lastBuilderProgram,
      });
      lastBuilderProgram = tscResult.builderProgram ?? lastBuilderProgram;

      // lint: tscResult 직접 사용
      let lint: LintWithProgramResult | undefined;
      if (info.output.lint === true && tscResult.program != null) {
        if (watchLintRunner == null) {
          watchLintRunner = new LintWithProgramRunner({ cwd: info.cwd, pkgName: info.name });
        }
        lint = await watchLintRunner.lint({
          program: tscResult.program,
          affectedFiles: tscResult.affectedFiles,
        });
      }

      const allErrors = [...(tscResult.errors ?? [])];
      return {
        build: {
          success: tscResult.success,
          errors: allErrors.length > 0 ? allErrors : undefined,
          warnings: undefined,
        },
        lint,
        mainJsPath,
      };
    }
  }

  // ... 기존 startWatch 로직 (parseTsconfig, createContext, rebuildAll 호출 등)
}
```
