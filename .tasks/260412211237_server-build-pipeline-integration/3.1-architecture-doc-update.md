## 구현계획

### 배경
Feature 1.1~1.3에서 서버 빌드가 "esbuild ‖ tsc 수동 병렬"에서 "esbuild + tsc 플러그인 통합"으로 변경되었다. `esbuild-tsc-plugin.ts`가 신규 생성되었고, `server-esbuild-context.ts`가 tsc 플러그인 관리 역할을 포함하게 되었으며, `server-build.worker.ts`가 단일 파이프라인으로 리팩토링되었다. [근거: wbs Feature 1.1~1.3]

### 목표
- Architecture 트리에 `esbuild-tsc-plugin.ts` 반영 [근거: Rule "Architecture 트리에 새 파일이 반영되어야 한다"]
- 서버 빌드 관련 파일 설명 갱신 [근거: Rule "기존 파일의 설명이 변경된 역할을 반영해야 한다"]
- Key Patterns에 tsc 플러그인 패턴 추가 [근거: Rule "Key Patterns에 tsc 플러그인 패턴이 설명되어야 한다"]
- Testing 트리에 `tests/esbuild/` 반영 [근거: D1]
