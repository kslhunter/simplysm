# Feature 2.3 dev 모드 수동 검증

## 전제 조건

- Feature 1.1~2.2 코드 변경이 적용된 simplysm 패키지가 빌드/배포되어 있어야 한다
- `target: "server"`로 설정된 패키지가 포함된 프로젝트가 필요하다 (simplysm 라이브러리 모노레포에는 서버 패키지가 없음)

## 수행 절차

1. 서버 패키지가 있는 프로젝트 디렉토리에서 `pnpm dev -t {서버패키지명}` 실행
2. 초기 빌드가 완료될 때까지 대기
3. 서버 패키지의 소스 파일(.ts)을 수정하여 watch rebuild 트리거
4. 타입 에러를 의도적으로 발생시켜 tsc 에러 리포팅 확인 (예: 존재하지 않는 프로퍼티 접근)
5. 타입 에러를 수정하여 정상 rebuild 복구 확인

## 기대 결과

- 초기 빌드가 에러 없이 성공한다
- 소스 파일 수정 시 watch가 변경을 감지하여 rebuild를 수행한다
- rebuild 결과가 콘솔에 정상적으로 출력된다
- 타입 에러 발생 시 에러가 콘솔에 리포팅된다
- 타입 에러 수정 후 정상 rebuild가 이루어진다
