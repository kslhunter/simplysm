## 구현계획

### 배경

`createSdNgPlugin`은 Angular 클라이언트 빌드용 esbuild 플러그인이다. `.ts` 파일에 대한 `onLoad` 핸들러에서 TypeScript emit 후 `transformWorkerPaths`를 적용하여 `import.meta.resolve()` 워커 패턴을 변환한다. 그러나 npm 패키지의 컴파일된 `.js` 파일에 대한 핸들러가 없어, `@simplysm/sd-service-client` 등의 `.js` 파일에서 `import.meta.resolve()`가 변환되지 않은 채 브라우저에 전달된다.

### 목표

- `.js` 파일에 대한 `onLoad` 핸들러를 추가하여 `transformWorkerPaths` 적용

### 비목표

- `.mjs` 핸들러 수정 (현재 워커 패턴을 사용하는 `.mjs` 파일 없음)
- `SdWorkerPathPlugin` API 변경

### 설계

`createSdNgPlugin`의 `.mjs` 핸들러 이후에 `.js` 파일용 `onLoad` 핸들러를 추가한다. `workerOutdir`가 제공된 경우에만 등록하며, `transformWorkerPaths`만 적용하고 변환이 없으면 `null`을 반환한다.

```typescript
if (workerOutdir != null) {
  build.onLoad({ filter: /\.js$/ }, async (args) => {
    const source = await FsUtils.readFileAsync(args.path);
    const transformed = await transformWorkerPaths(source, args.path, workerOutdir, build.initialOptions);
    if (transformed === source) return null;
    return { contents: transformed, loader: "js" };
  });
}
```
