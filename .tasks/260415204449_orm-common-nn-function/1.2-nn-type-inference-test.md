## 구현계획

### 배경
기존 `tests/types/nullable-queryable-record.spec.ts`에 `NullableQueryableRecord` 타입 추론 테스트 2개가 있다. Feature 1.1에서 `nn()` 함수와 phantom type이 `queryable.ts:1881-1912`에 구현되었으므로, 이에 대한 타입 추론 테스트를 추가한다.

### 목표
- `nn()` 함수의 타입 추론이 올바르게 동작하는지 검증 [근거: Rule "nn()은 NullableQueryableRecord의 undefined 전파를 제거한다"]
- 기존 `NullableQueryableRecord` 동작이 깨지지 않았는지 확인 [근거: Rule "nn() 미사용 시 기존 동작 유지"]

### 비목표
- SQL 생성 테스트 [근거: wbs 경계 "SQL 생성 테스트는 이 Feature에서 다루지 않음"]

### 설계
- 기존 `tests/types/nullable-queryable-record.spec.ts`에 `nn()` 관련 describe 블록 추가
- 기존 패턴 준수: `createTestDb()`, `expectTypeOf`, `$infer` 타입 추출, `expr` import
- `nn` import: `../../src/exec/queryable`에서 import

### 대안 검토
- 별도 파일 `tests/types/nn.spec.ts` 생성 → 기존 nullable-queryable-record 테스트와 주제가 밀접하므로 같은 파일에 추가하는 것이 응집도 높음
