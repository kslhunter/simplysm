# Feature 1.1 sd-claude auth CLI

## 참조 자료

### 기존 구현 (삭제 대상)

- `.claude/skills/sd-auth/sd-auth.py` — Python 구현 (save/list/switch)
- `.claude/skills/sd-auth/SKILL.md` — 스킬 정의

### 대상 패키지

- `packages/sd-claude/` — zero deps mjs 패키지
- `packages/sd-claude/scripts/` — 기존 mjs 스크립트 (postinstall.mjs, sync.mjs, sd-entries.mjs)
- `packages/sd-claude/package.json` — `bin` 필드 없음 (추가 필요)

### 데이터 파일 (모두 `~/.claude/` 하위)

| 파일 | 용도 |
|------|------|
| `profiles.json` | 저장된 계정 정보 (`{ current, accounts: { [org]: { refreshToken, usage } } }`) |
| `.credentials.json` | 현재 로그인 계정의 refresh token (`{ claudeAiOauth: { refreshToken } }`) |
| `statusline-cache.json` | 실시간 사용량 (`{ rate_limits: { five_hour, seven_day } }`) |

### 계정 전환 메커니즘

- `claude auth status` → JSON stdout에서 `orgName` 추출
- `claude auth login` + 환경변수 `CLAUDE_CODE_OAUTH_REFRESH_TOKEN`, `CLAUDE_CODE_OAUTH_SCOPES`로 전환
- 전환 후 `.credentials.json`에서 갱신된 refresh token 재저장

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | switch 대화형 선택 방식 | readline 번호 입력 | zero deps 유지, 간단 구현, 안정적 |
| D2 | non-TTY 환경 switch 동작 | 에러 메시지 출력 후 종료 | 명확한 동작, hang 방지 |

## 구현계획

### 배경

sd-claude 패키지는 Claude Code 에셋 배포용 zero-deps mjs 패키지다. 현재 `scripts/`에 postinstall.mjs, sync.mjs, sd-entries.mjs가 있으며 CLI 엔트리포인트는 없다. sd-auth 기능은 `.claude/skills/sd-auth/sd-auth.py`에 Python으로 구현되어 있으나, Claude Code rate limit 시 스킬 실행이 불가능하다.

### 목표

- sd-auth 기능을 sd-claude 패키지의 mjs CLI로 이전
- `sd-claude auth save` / `sd-claude auth switch` 명령으로 터미널에서 직접 실행 가능
- sd-auth 스킬 폴더 삭제

### 비목표

- 별도 `list` 명령 (switch가 목록 표시 겸용)
- non-TTY 환경 지원 (에러 처리만)
- 테스트 인프라 추가 (zero-deps 패키지 특성상 vitest 미추가, 순수 함수는 인라인 테스트 불필요)

### 설계

#### 파일 구조

```
packages/sd-claude/
├── scripts/
│   ├── cli.mjs          ← 신규: CLI 엔트리포인트 (bin)
│   ├── auth.mjs         ← 신규: auth 서브커맨드
│   ├── postinstall.mjs
│   ├── sync.mjs
│   └── sd-entries.mjs
└── package.json          ← 수정: bin 추가
```

#### cli.mjs

```javascript
#!/usr/bin/env node
// process.argv: [node, cli.mjs, <subcommand>, <action>]
// "auth save" → subcommand="auth", action="save"
```

서브커맨드별 모듈을 dynamic import하여 실행. 알 수 없는 명령 시 사용법 출력 + exit 1.

#### auth.mjs

sd-auth.py 로직을 1:1 포팅. Node.js 내장 API만 사용:
- `fs` — profiles.json, .credentials.json, statusline-cache.json 읽기/쓰기
- `os.homedir()` — ~/.claude/ 경로
- `child_process.execSync` / `spawnSync` — claude CLI 실행
- `readline` — 대화형 번호 선택
- `process.stdin.isTTY` — TTY 감지

#### package.json 변경

```json
{
  "bin": { "sd-claude": "scripts/cli.mjs" }
}
```

`files`에 `"scripts"` 이미 포함되어 있어 추가 변경 불필요.

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| cli.mjs + auth.mjs 분리 | 채택 | 향후 서브커맨드 확장 가능, 단일 책임 |
| 단일 파일 sd-claude-auth.mjs | 미채택 | 서브커맨드 라우팅과 auth 로직 혼재 |
| commander/yargs 도입 | 미채택 | zero-deps 원칙 위반 |
