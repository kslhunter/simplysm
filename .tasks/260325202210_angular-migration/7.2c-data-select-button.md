## 구현계획

### 배경

v14의 `features/data-view/`에 AbsSdDataSheet+SdDataSheetControl(7.2a), AbsSdDataDetail+SdDataDetailControl(7.2b)이 이미 존재한다. 동일한 Abstract Directive + Component 패턴으로 AbsSdDataSelectButton + SdDataSelectButtonControl을 추가한다.

v14에는 UI 레벨의 `SdModalSelectButtonControl`(`ui/form/button/sd-modal-select-button.control.ts`)이 존재하며, `ISdSelectModal`, `TSdSelectModalInfo`, `ISelectModalOutputResult` 타입을 정의하고 있다. Feature 레벨 컴포넌트는 이 타입을 import하여 재사용한다.

### 목표

- AbsSdDataSelectButton 추상 디렉티브: value 관리, 자동 로드(effect → load), 모달 선택, 초기화, 유효성 검사
- SdDataSelectButtonControl 컴포넌트: 아이템 템플릿 렌더링, 버튼 표시/숨김, 부모 참조
- index.ts export 추가

### 비목표

- ISdSelectModal, TSdSelectModalInfo, ISelectModalOutputResult 타입 변경 (이미 v14에 존재)
- SdModalSelectButtonControl 수정
- 공유 데이터 선택 (Feature 7.3)

### 설계

#### AbsSdDataSelectButton<TItem extends object, TKey>

| 멤버 | 종류 | 설명 |
|------|------|------|
| `modal` | abstract Signal | TSdSelectModalInfo — 모달 설정 |
| `load(keys: TKey[])` | abstract method | 키 배열로 아이템 로드 (sync/async) |
| `value` | model | TSelectModeValue\<TKey\> — 현재 선택 값 |
| `disabled`, `required`, `inset` | input (booleanAttribute) | UI 설정 |
| `size` | input | "sm" \| "lg" |
| `selectMode` | input | "single" \| "multi" (기본: "single") |
| `isNoValue` | computed | value가 null이거나 빈 배열이면 true |
| `selectedItems` | signal | TItem[] — 로드된 아이템 |
| effect | constructor | value 변경 → queueMicrotask → load() → selectedItems 갱신 |
| `doShowModal()` | method | SdModalProvider.showAsync() 호출, 결과로 value 갱신 |
| `doInitialValue()` | method | single→undefined, multi→[] 리셋 |
| setupInvalid | constructor | required && value==null → "값을 입력하세요." |

#### SdDataSelectButtonControl

| 멤버 | 종류 | 설명 |
|------|------|------|
| `parent` | injectParent | AbsSdDataSelectButton\<any, any\> |
| `itemTplRef` | contentChild | SdItemOfTemplateDirective → TemplateRef |
| `onSearchClick(event)` | method | event.preventDefault/stopPropagation + parent.doShowModal() |
| `onEraseClick()` | method | parent.doInitialValue() |

Template: SdAdditionalButtonControl으로 감싸고, @for로 아이템 렌더링(쉼표 구분), ng-content, 초기화 버튼(sd-anchor), 검색 버튼(sd-button).

Styles: `sd-data-select-button { display: block; width: 100%; min-width: 3em; }` (v12 동일)

Host binding: `[attr.data-sd-disabled]="parent.disabled()"`

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
