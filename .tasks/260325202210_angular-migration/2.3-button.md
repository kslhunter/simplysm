## 구현계획

### 배경

Angular 21 마이그레이션 프로젝트에서 기본 UI 버튼 컴포넌트 3종을 구현한다. 타겟 코드베이스에 `form-control-base()` mixin, 테마 CSS 변수 시스템(`--theme-{name}-{shade}`), `SdRippleDirective`가 이미 존재한다. 기존 컴포넌트(sd-dock, sd-gap, sd-view 등)의 패턴을 따른다.

### 목표

- sd-button: 19종 테마, 크기(sm/lg), 표시 모드(inline/inset), disabled, 리플, buttonStyle/buttonClass
- sd-anchor: 8종 테마, disabled, hover/active/touch 상태
- sd-additional-button: 콘텐츠+버튼 영역 분리 레이아웃, 크기/inset
- 각 컴포넌트의 단위 테스트

### 비목표

- sd-modal-select-button (Feature 5.3으로 이관)
- sd-select-button (Feature 5.1)
- sd-data-select-button, sd-shared-data-select-button (Feature 7.2, 7.3)

#### sd-button API

| 속성 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| type | `"button" \| "submit"` | `"button"` | inner button의 HTML type |
| theme | solid 8종 + link 10종 + link-rev | `undefined` | 시멘틱 테마 |
| inline | `boolean` | `false` | inline-block 표시 |
| inset | `boolean` | `false` | 테두리/radius 제거 |
| size | `"sm" \| "lg"` | `undefined` | 패딩 크기 |
| disabled | `boolean` | `false` | 비활성화 |
| buttonStyle | `string` | `undefined` | inner button style 바인딩 |
| buttonClass | `string` | `undefined` | inner button class 바인딩 |

- Host: `[attr.data-sd-theme]`, `[attr.data-sd-inline]`, `[attr.data-sd-size]`, `[attr.data-sd-inset]`, `[attr.data-sd-disabled]`
- Template: `<button tabindex="0" [type] [disabled] [class] [style] [sd-ripple]><ng-content /></button>`
- Imports: `SdRippleDirective`
- Inline SCSS (~150행): `form-control-base()`, 테마 `@each` 루프, 크기/모드/disabled 스타일

#### sd-anchor API

| 속성 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| disabled | `boolean` | `false` | 비활성화 |
| theme | solid 8종 | `"primary"` | 시멘틱 테마 |

- Host: `[attr.data-sd-theme]`, `[attr.data-sd-disabled]`, `[attr.tabindex]`
- Template: `<ng-content />`
- Inline SCSS (~30행): 테마별 색상, hover/active, 터치 디바이스, disabled

#### sd-additional-button API

| 속성 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| size | `"sm" \| "lg"` | `undefined` | 내부 패딩 크기 |
| inset | `boolean` | `false` | 테두리/radius 제거 |

- Host: `[attr.data-sd-size]`, `[attr.data-sd-inset]`
- Template: `._content(ng-content) + ._button(ng-content select="sd-anchor, sd-button")`
- Inline SCSS (~50행): 레이아웃, 슬롯, 크기/inset 변형

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| Attribute selector (`button[sd-button]`) | 미채택 | host에 메인 스타일이 있는 구조에서 부적합, DX 일관성 (D3) |
| 외부 SCSS 파일 | 미채택 | 인라인 SCSS가 v12 패턴과 일치, control 타입은 인라인이 타겟 관례 |
| buttonStyle/buttonClass 제거 | 미채택 | 소스 호환성 유지 (D3) |
