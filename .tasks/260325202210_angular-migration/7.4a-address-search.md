## 요구명세

```gherkin
Feature: 7.4a 외부 서비스 연동 검색

  Background:
    Given SdModalProvider를 통해 SdAddressSearchModal이 열린다

  Rule: 다음 우편번호 스크립트를 동적 로딩한다

    Scenario: 최초 모달 열기 시 스크립트 삽입
      Given 문서에 id="daum_address" 스크립트가 없다
      When 모달이 초기화된다
      Then <script id="daum_address"> 가 <head>에 삽입된다
      And daum.postcode.load 콜백이 완료된다

    Scenario: 이미 로딩된 스크립트는 중복 삽입하지 않는다
      Given 문서에 id="daum_address" 스크립트가 이미 있다
      When 모달이 초기화된다
      Then 스크립트를 새로 삽입하지 않는다

  Rule: 우편번호 검색 위젯을 모달에 임베드한다

    Scenario: 스크립트 로딩 완료 후 위젯 임베드
      Given 스크립트 로딩이 완료되었다
      When daum.Postcode 위젯을 생성한다
      Then 컨테이너 요소에 embed된다
      And initialized 시그널이 true로 전환된다
      And busy 표시가 해제된다

    Scenario: 위젯 리사이즈 시 컨테이너 높이 조정
      Given 위젯이 임베드되어 있다
      When 위젯이 리사이즈 이벤트를 발생시킨다
      Then 컨테이너 높이가 위젯 높이에 맞춰 조정된다

  Rule: 주소 선택 시 결과를 반환하고 모달을 닫는다

    Scenario: 도로명 주소 선택
      Given 위젯에서 주소를 검색했다
      When 도로명 주소를 선택한다
      Then close 출력으로 { postNumber, address: 도로명주소 + 부가주소, buildingName } 을 emit한다
      And 부가주소는 동/로/가로 끝나는 법정동명과 아파트 건물명을 포함한다

    Scenario: 지번 주소 선택
      Given 위젯에서 주소를 검색했다
      When 지번 주소를 선택한다
      Then close 출력으로 { postNumber, address: 지번주소, buildingName } 을 emit한다
```

## 구현계획

### 배경

v12 `SdAddressSearchModal`(96줄)을 v14로 마이그레이션한다. 다음 우편번호 서비스(`postcode.v2.js`)를 lazy load하여 모달에 임베드하는 단일 컴포넌트이다. v14에 `ISdModal<O>`, `SdBusyContainerControl`, `SdModalProvider`가 이미 존재한다.

### 목표

- `SdAddressSearchModal`을 v14 패턴으로 마이그레이션
- v14 코딩 규칙 준수 (`$signal` → `signal()`, `@ts-expect-error` 제거)

### 비목표

- 다음 우편번호 API 동작 변경 (v12와 동일 동작 유지)
- 주소 검색 UI 커스터마이징 (다음 위젯 그대로 사용)

### 설계

#### 파일 구조

- `packages/angular/src/features/address/sd-address-search.modal.ts` — 컴포넌트 + IAddress 인터페이스 + daum 전역 타입 선언

#### daum 전역 타입

```typescript
declare const daum: {
  postcode: {
    load(callback: () => void): void;
  };
  Postcode: new (options: {
    oncomplete: (data: IDaumPostcodeData) => void;
    onresize: (size: { height: number }) => void;
    width: string;
    height: string;
  }) => { embed(el: HTMLElement, options: { autoClose: boolean }): void };
};

interface IDaumPostcodeData {
  zonecode: string;
  roadAddress: string;
  jibunAddress: string;
  userSelectedType: "R" | "J";
  bname: string;
  buildingName: string;
  apartment: "Y" | "N";
}
```

#### v12 → v14 치환

| v12 | v14 |
|-----|-----|
| `$signal(false)` | `signal(false)` |
| `@ts-expect-error` (2건) | `declare const daum` 타입 선언으로 제거 |
| `OnInit` + `ngOnInit()` | `afterNextRender()` 또는 유지 |

#### export

- `SdAddressSearchModal`, `IAddress`를 `index.ts`에 추가

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| 파일 내 declare 선언 | 채택 | 단일 파일만 사용, 별도 .d.ts 불필요 |
| 별도 daum-postcode.d.ts | 미채택 | 이 API를 사용하는 파일이 1개뿐 |
