## 구현계획

### 배경

@simplysm/angular 패키지에 오버레이 UI의 첫 번째 컴포넌트로 드롭다운을 추가한다. v12의 `SdDropdownControl`/`SdDropdownPopupControl`을 v14 패턴(Angular 21, Signal API, native `effect()`)으로 마이그레이션한다. v14 코드베이스에 이미 마이그레이션된 의존성(`SdEventsDirective`, `core-browser` DOM 확장, SCSS 변수 시스템)을 활용한다.

### 목표

- `SdDropdownControl` + `SdDropdownPopupControl` 2개 컴포넌트 구현
- v14 패턴 준수 (Standalone, OnPush, Signal API, native `effect()`)
- 요구명세 전체 21개 시나리오 충족

### 비목표

- 모바일 모달 형식 표현 (D2: Feature 3.2 이후)
- contentClass/contentStyle input (D1: 제거)

#### SdDropdownControl API

```typescript
@Component({
  selector: "sd-dropdown",
  standalone: true,
  changeDetection: ChangeDetectionStrategy.OnPush,
  encapsulation: ViewEncapsulation.None,
})
export class SdDropdownControl {
  open = model(false);
  disabled = input(false, { transform: booleanAttribute });

  popupElRef = contentChild.required(SdDropdownPopupControl, { read: ElementRef });
}
```

- `open`: 양방향 바인딩 모델 — 열림/닫힘 상태
- `disabled`: 비활성 시 tabindex 제거 + 열기 차단
- `popupElRef`: contentChild로 SdDropdownPopupControl의 ElementRef 참조

#### SdDropdownPopupControl API

```typescript
@Component({
  selector: "sd-dropdown-popup",
  standalone: true,
  imports: [SdEventsDirective],
  changeDetection: ChangeDetectionStrategy.OnPush,
  encapsulation: ViewEncapsulation.None,
})
export class SdDropdownPopupControl {
  private readonly _parentControl = inject(forwardRef(() => SdDropdownControl));
}
```

- 부모 `SdDropdownControl`을 `forwardRef`로 inject
- `sdResize`로 콘텐츠 높이 감시 → 300px 제한

#### 위치 계산

`core-browser`의 `getRelativeOffset(document.body)` 사용. 뷰포트 중앙 기준:
- `top * 2 > innerHeight` → 위에 배치 (bottom 사용)
- `left * 2 > innerWidth` → 우측 정렬 (right 사용)
- 팝업 최소 너비 = 드롭다운 너비

#### 외부 클릭 감지

`document:blur` (capture)로 포커스 이탈 감지. `document:mouseover`로 마우스 위치 추적하여 보완. 내부 포커스 이동(relatedTarget이 드롭다운/팝업 내부)은 `contains()`로 판별하여 무시.

#### document-level 이벤트 전략 (D3)

v12의 상시 등록 대신, `effect(onCleanup)`으로 open 상태일 때만 등록:
- `scroll` (capture, passive) — 부모 스크롤 추적
- `mouseover` — 마우스 위치 추적
- `blur` (capture) — 외부 포커스 이탈 감지

닫힐 때 onCleanup으로 자동 해제. 컴포넌트 파괴 시에도 onCleanup 실행.

#### v12 → v14 API 변환

| v12 | v14 | 이유 |
|-----|-----|------|
| `$effect()` | `effect()` (Angular native) | v14 코드베이스 패턴 |
| `injectElementRef()` | `inject(ElementRef)` | wrapper 불필요 |
| `transformBoolean` | `booleanAttribute` | Angular 내장 |
| `el.findParent(other)` | `other.contains(el)` | DOM 표준 API (D5) |
| `el.findFocusableFirst()` | `el.findFirstFocusableChild()` | core-browser v14 명칭 |
| `requestAnimationFrame` | `repaint()` | CSS 전환 보장 (D4) |

| 접근 방식 | 선택 | 이유 |
