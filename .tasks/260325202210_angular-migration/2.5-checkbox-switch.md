## 참조 자료

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | 라디오 모드 구현 방식 | sd-checkbox의 radio input으로 유지 | 원본 구조와 동일. 독립 sd-radio 컴포넌트 불필요 — 인디케이터만 다르고 나머지 속성/동작 공유 |

| D5 | 디렉토리 구조 | ui/form/checkbox/ 에 체크박스+스위치 통합 | 동일 Feature의 관련 컴포넌트. button/에 anchor 포함하는 패턴과 동일 |

## 구현계획

### 배경

v14 Angular 패키지의 `ui/form/` 디렉토리에 boolean 선택 컴포넌트군을 마이그레이션한다. 원본은 v12 `ui/form/choice/`의 4개 컴포넌트(sd-checkbox, sd-switch, sd-checkbox-group, sd-checkbox-group-item)이다. 기존 v14 form 컴포넌트(sd-button, sd-textfield, sd-textarea)의 패턴을 따른다.

### 목표

- sd-checkbox, sd-switch, sd-checkbox-group, sd-checkbox-group-item 4개 컴포넌트 구현
- v14 컨벤션 적용 (booleanAttribute, computed, NgIcon 33.x)
- 테스트 fixture 작성

### 비목표

- sd-state-preset (Feature 5.3 소속)
- 폼 검증 연동 (sd-checkbox에 setupInvalid 미사용 — 원본과 동일)

### 설계

#### 컴포넌트 API

**SdCheckboxControl** (`sd-checkbox`)

| 종류 | 이름 | 타입 | 기본값 | 비고 |
|------|------|------|--------|------|
| model | value | boolean | false | 양방향 바인딩 |
| input | canChangeFn | (item: boolean) => boolean \| Promise\<boolean\> | () => true | setupModelHook으로 연결 |
| input | icon | string (SVG) | tablerCheck | NgIcon svg 입력 |
| input | radio | boolean | false | booleanAttribute |
| input | disabled | boolean | false | booleanAttribute |
| input | size | "sm" \| "lg" | undefined | |
| input | inline | boolean | false | booleanAttribute |
| input | inset | boolean | false | booleanAttribute |
| input | theme | string union | undefined | primary~white 9종 |
| input | contentStyle | string | undefined | 라벨 영역 스타일 |

**SdSwitchControl** (`sd-switch`)

| 종류 | 이름 | 타입 | 기본값 | 비고 |
|------|------|------|--------|------|
| model | value | boolean | false | 양방향 바인딩 |
| input | disabled | boolean | false | booleanAttribute |
| input | inline | boolean | false | booleanAttribute |
| input | inset | boolean | false | booleanAttribute |
| input | size | "sm" \| "lg" | undefined | |
| input | theme | string union | undefined | primary~blue-gray 8종 (white 미포함) |

**SdCheckboxGroupControl\<T\>** (`sd-checkbox-group`)

| 종류 | 이름 | 타입 | 기본값 | 비고 |
|------|------|------|--------|------|
| model | value | T[] | [] | 선택된 값 배열 |
| input | disabled | boolean | false | booleanAttribute |

**SdCheckboxGroupItemControl\<T\>** (`sd-checkbox-group-item`)

| 종류 | 이름 | 타입 | 기본값 | 비고 |
|------|------|------|--------|------|
| input | value | T | (required) | 이 아이템이 나타내는 값 |
| input | inline | boolean | false | booleanAttribute |
| derived | isSelected | computed | — | 부모 그룹 value 배열에 포함 여부 |
| derived | disabled | computed | — | 부모 그룹 disabled 전파 |

#### v12 → v14 변환 규칙

| v12 (원본) | v14 (대상) |
|------------|-----------|
| `import { transformBoolean }` | `import { booleanAttribute } from "@angular/core"` |
| `input(false, { transform: transformBoolean })` | `input(false, { transform: booleanAttribute })` |
| `import { $computed }` | `import { computed } from "@angular/core"` |
| `$computed(() => ...)` | `computed(() => ...)` |

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| checkbox/switch 별도 디렉토리 분리 | 미채택 | switch가 단일 파일로 별도 디렉토리는 과도. button/에 anchor 포함 패턴 참고 |
| choice/ 디렉토리명 유지 | 미채택 | v14의 다른 디렉토리(button, input)가 주요 컴포넌트명을 사용 |
| SdRippleDirective 사용 | 미채택 | 호스트 요소에 직접 리플 적용 시 setupRipple() 함수가 적합 |
