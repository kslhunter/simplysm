# Feature 1.2 테마 및 스타일 기반

## 참조 자료

- [wbs.md](./wbs.md)

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | 색상 생성 방식 (oklch 네이티브 vs SCSS) | SCSS 유지 | WebKit 61 제약: CSS 변수 포함 oklch()/color-mix()는 PostCSS 변환 불가. 정적 값만 쓰면 SCSS와 동일하여 이점 없음 |
| D2 | 다크모드 구현 (light-dark() vs 클래스) | 현행 클래스 방식 유지 | WebKit 61 제약: light-dark() PostCSS 폴리필 없음 |
| D3 | @property 도입 | 미도입 | WebKit 61 제약: PostCSS 폴리필 없음 |
| D4 | @layer 도입 | 도입 | postcss-cascade-layers로 WebKit 61 폴리필 가능. base→theme→dark→utilities 우선순위 명시적 관리 |
| D5 | modern 테마 | 제거 (compact/mobile/kiosk 3종) | 소스에서 파일 부재, TSdTheme 타입에도 미포함 |
| D6 | color-map 네이밍 | 수정 | lightest~darkest가 실제 밝기와 일치하도록 수정. 기존엔 dark/darker/darkest가 원본보다 밝은 색이었음 |
| D7 | 다크 테마 이미지 반전 | opt-out 방식 | 기본 반전 유지 + .no-invert 클래스로 사진 등 제외 가능 |
| D8 | TypeScript 디렉토리 구조 | v12 구조 유지 | src/core/providers/, src/core/utils/setups/. 160개 파일 마이그레이션 일관성 |

### 후속 변경

- [Feature 1.2.1](./1.2.1-rem-em-sizing.md)에 의해 다음이 변경됨:
  - Rule "테마를 전환할 수 있다 (compact/mobile/kiosk 3종)" → 제거 (_variables-mobile.scss, _variables-kiosk.scss 삭제, @layer theme 제거)
  - Rule "SdThemeProvider가 테마 상태를 관리한다" → theme signal/TSdTheme 제거, dark만 유지
  - compact 기본값의 px → rem 전환 (1rem = 12px 기준)

## 구현계획

### 배경

v12 sd-angular의 SCSS 테마 시스템을 v14 @simplysm/angular로 마이그레이션한다. v14 패키지는 Feature 1.1에서 기본 구조만 설정됨 (빈 styles.css, index.ts). v14 sd-cli에는 SCSS 컴파일 파이프라인이 없으므로 sass CLI를 npm script로 활용한다.

### 목표

- SCSS 기반 CSS 변수 테마 시스템 (~145개 변수, 수백 개 유틸리티 클래스)
- compact/mobile/kiosk 3종 테마 + 다크모드 전환
- SdThemeProvider, setupBgTheme TypeScript 구현
- @layer 기반 스타일 우선순위 관리
- color-map 네이밍 수정 (lightest~darkest = 밝음~어두움)

### 비목표

- sd-cli SCSS 빌드 파이프라인 (별도 태스크)
- PostCSS 폴리필 (소비 측 앱 책임)
- controls/ 글로벌 스타일 — card, flex, form-box, form-table, table (각 UI Feature에서 추가)
- quill CSS import (Feature 5.4)
- SdThemeSelectorControl (Feature 7.4)
- provideSdAngular 테마 초기화 (Feature 1.10)

### 설계

```
│       ├── _variables-mobile.scss # 모바일 테마 변수 오버라이드
│       └── _variables-kiosk.scss  # 키오스크 테마 변수 오버라이드
├── src/
│   ├── core/
│   │   ├── providers/
│   │   │   └── sd-theme-provider.ts  # SdThemeProvider + TSdTheme

│   │       └── setups/

│   └── index.ts                      # barrel export

└── package.json                       # sass devDependency + build:styles script
```

#### SCSS 변경사항 (v12 → v14)

| 변경 | 내용 |
|------|------|
| color-map (D6) | `dark: color.scale($base, $lightness: -10%)`, `darker: -25%`, `darkest: -40%` (음수 lightness로 실제 어두운 색) |
| @layer (D4) | `@layer base, theme, theme-variant, utilities;` 최상위 선언. 각 섹션을 해당 레이어에 배치 |
| modern 제거 (D5) | `_variables-modern.scss` 미생성, TSdTheme에서 제외 |
| 이미지 opt-out (D7) | `.sd-theme-dark img:not(.no-invert) { filter: invert(1) hue-rotate(180deg); }` |
| quill import 제거 | styles.scss에서 quill CSS import 미포함 (Feature 5.4에서 추가) |
| ng-icon 스타일 | `.ng-icon { vertical-align: middle; }` 글로벌 스타일 포함 |
| flex-direction 폴백 | `@supports not (appearance: auto)` gap 폴백 유지 (WebKit 61 flexbox gap 미지원) |

#### 빌드 설정

- devDependency: `sass` 추가
- package.json scripts: `"build:styles": "sass scss/styles.scss styles.css --no-source-map"`
- styles.css는 빌드 산출물 (sass 실행으로 생성)

#### TypeScript 설계

**SdThemeProvider:**
```typescript
@Injectable({ providedIn: "root" })
export class SdThemeProvider {
  theme = signal<TSdTheme>("compact");
  dark = signal<boolean>(false);
  // effect: body.className 갱신
}
export type TSdTheme = "compact" | "mobile" | "kiosk";
```

**setupBgTheme:**
```typescript
export function setupBgTheme(options?: {
  theme?: "primary" | "secondary" | "info" | "success" | "warning" | "danger" | "gray" | "blue-gray";
  lightness?: "lightest" | "lighter";
}): void
// effect: body.style --background-color 설정
// cleanup: 빈 값으로 복원
```

### 대안 검토

| 접근 방식 | 선택 | 이유 |
|-----------|------|------|
| 순수 CSS (SCSS 없이) | 미채택 | @each, @function 등 SCSS 기능이 유틸리티 클래스 동적 생성에 필수 |
| CSS-in-JS | 미채택 | Angular 스타일 시스템과 불일치, 런타임 오버헤드 |
| Tailwind CSS | 미채택 | 기존 유틸리티 클래스 네이밍과 호환 안 됨, 전체 컴포넌트 마이그레이션에 영향 |
