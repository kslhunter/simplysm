### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | config bar 구조 | v12 구조 재현 (상단에 설정 버튼 + 페이지네이션 통합, hideConfigBar input) | v12 호환, 6.1에서 임의 변경한 하단 페이지네이션 원복 |

## 구현계획

### 배경

v14 Angular 21 환경의 SdSheetControl은 Feature 6.1에서 기본 표시 기능(렌더링, 선택, 정렬, 트리, 페이지네이션)을 구현했다. 6.2에서는 v12의 나머지 기능인 셀 편집, 키보드 탐색, 컬럼 리사이징, 그리드 설정 모달을 추가한다.

기존 v14 파일: sd-sheet.control.ts(542줄), sd-sheet-column.directive.ts, types.ts, useSheetLayoutEngine.ts, useSheetColumnFixing.ts. v14 core-browser에 findFirstFocusableChild(), copyElement(), pasteToElement(), scrollIntoViewIfNeeded() 이미 존재.

6.1에서 페이지네이션을 하단에 임의 배치했으나 D1에 따라 v12 구조(config bar 상단 통합)로 원복한다.

### 목표

- useSheetCellAgent: 셀 편집 모드 + 키보드 탐색 + Ctrl+C/V
- useSheetDomAccessor: DOM 요소 접근 헬퍼
- 컬럼 리사이징: 드래그 + 더블클릭 초기화 + config 저장
- SdSheetConfigModal: 컬럼 관리 모달 (Fix/Order/Header/Width/Hidden)
- config bar: 설정 버튼 + 페이지네이션 통합 (v12 구조), hideConfigBar input
- itemKeydown/cellKeydown output 이벤트

### 비목표

- 가상 스크롤
- 셀 편집 유효성 검증 / dirty tracking
- 드래그 앤 드롭 컬럼 순서 변경 (모달에서만 순서 변경)

#### 리사이징 — config 저장

```typescript
private _saveColumnConfig(colKey: string, changes: Partial<ISdSheetConfig["columnRecord"][string]>): void {
  const current = this._configResource.value() ?? { columnRecord: {} };
  const columnRecord = { ...current.columnRecord };
  columnRecord[colKey] = { ...columnRecord[colKey], ...changes };
  this._configResource.set({ ...current, columnRecord });
}
```

#### 데이터 흐름 (리사이징)

```
리사이저 mousedown → document mousemove (인디케이터 위치) → document mouseup
  → newWidth = max(startWidth + deltaX, 5)
  → _saveColumnConfig(colKey, { width: newWidth + "px" })
  → _configResource.set() → layoutEngine 재계산 → 템플릿 반영
```

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| copyAsync/pasteAsync를 Element 프로토타입 확장으로 추가 | 미채택 | v14 패턴은 함수형 (copyElement/pasteToElement 선례), 프로토타입 확장 최소화 |
