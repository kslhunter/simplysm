# Feature 6.1 데이터 그리드 — 기본 표시

## 참조 자료

- [wbs.md](./wbs.md)

### 설계 결정

| # | 결정사항 | 선택 | 근거 |
|---|---------|------|------|
| D1 | SdSelectionManager/SdSortingManager API 형태 | function 기반 (useSelectionManager/useSortingManager) | 4.1의 useExpandingManager 선례, v14 use* 패턴 일관성 |
| D2 | 컬럼 리사이징/설정 모달 배치 | 6.2로 이관 | WBS 6.2 "그리드 설정 관리"와 일치, 6.1은 읽기 전용 표시 |
| D3 | 셀 편집/키보드 탐색 배치 | 6.2로 이관 | WBS 6.2 "셀 인라인 편집, 키보드 탐색"과 일치 |
| D4 | config 로드(ISdSheetConfig) | 6.1에 포함 (읽기 전용) | LayoutEngine이 config로 컬럼 정의 계산, 기본 렌더링의 전제조건 |
| D5 | 포커스/선택 표시자 | 6.1에 포함 | 마우스 기반 포커스/선택은 기본 표시 기능, 키보드 탐색(6.2)과 독립 |
| D6 | ARIA 접근성 | 추가 (aria-sort, aria-selected, aria-expanded) | 업계 표준(WCAG) 준수, 동작 변경 없이 template 속성만 추가 |

## 구현계획

### 배경

v12 sd-angular의 SdSheetControl(14파일: 컴포넌트 1, 디렉티브 2, feature 클래스 6, 타입 4, 설정 모달 1)을 v14 Angular 21 환경으로 마이그레이션한다. 6.1 범위는 기본 표시 기능이며, 셀 편집·키보드 탐색·컬럼 리사이징·설정 모달은 Feature 6.2에서 추가한다.

v14에 이미 존재하는 의존성: useExpandingManager(4.1), SdPaginationControl(4.1.1), SdCheckboxControl(2.5), SdEventsDirective·ISdResizeEvent(1.5), useSdSystemConfigResource(1.9), SdButtonControl·SdAnchorControl(2.3), NgIcon

### 목표

- SdSheetControl 기본 표시 컴포넌트 + SdSheetColumnDirective
- useSelectionManager, useSortingManager 공유 유틸리티 (core/utils/)
- 컬럼 고정, 스크롤 동기화, 포커스/선택 표시자
- ARIA 접근성 (aria-sort, aria-selected, aria-expanded)

### 비목표

- SdSheetCellAgent: 셀 편집 (Feature 6.2)
- 키보드 탐색: Arrow/Tab/Enter/F2/Escape (Feature 6.2)
- 컬럼 리사이징: 드래그/더블클릭 (Feature 6.2)
- SdSheetConfigModal + config 저장 + config 바 UI (Feature 6.2)
- ISdSheetItemKeydownEventParam, itemKeydown/cellKeydown 이벤트 (Feature 6.2)

#### 공유 유틸리티 API

**useSelectionManager\<T\>**

```typescript
export function useSelectionManager<T>(options: {
  displayItems: Signal<T[]>;
  selectedItems: WritableSignal<T[]>;
  selectMode: Signal<"single" | "multi" | undefined>;
  getItemSelectableFn: Signal<((item: T) => boolean | string) | undefined>;
}): {
  hasSelectable: Signal<boolean>;
  isAllSelected: Signal<boolean>;
  getSelectable(item: T): true | string | undefined;
  getCanChangeFn(item: T): () => boolean;
  select(item: T): void;
  deselect(item: T): void;
  toggle(item: T): void;
  toggleAll(): void;
  isSelected(item: T): boolean;
};
```

**useSortingManager**

```typescript
export interface ISortingDef {
  key: string;
  desc: boolean;
}

export function useSortingManager(options: {
  sorts: WritableSignal<ISortingDef[]>;
}): {
  defMap: Signal<Map<string, { indexText?: string; desc: boolean }>>;
  toggle(key: string, multiple: boolean): void;
  sort<T>(items: T[]): T[];
};
```

#### SdSheetControl API

```typescript
@Component({
  selector: "sd-sheet",
  standalone: true,
  changeDetection: ChangeDetectionStrategy.OnPush,
  encapsulation: ViewEncapsulation.None,
})
export class SdSheetControl<T> {
  // Inputs
  key = input<string>();
  items = input<T[]>([]);
  trackByFn = input<(item: T, index: number) => any>();
  selectMode = input<"single" | "multi">();
  autoSelect = input<"click" | "focus">();
  getItemSelectableFn = input<(item: T) => boolean | string>();
  getChildrenFn = input<(item: T, index: number) => T[] | undefined>();
  useAutoSort = input(false, { transform: booleanAttribute });
  visiblePageCount = input(10);
  totalPageCount = input(0);
  itemsPerPage = input(0);
  focusMode = input<"row" | "cell">("cell");
  inset = input(false, { transform: booleanAttribute });
  contentStyle = input<string>();
  getItemCellClassFn = input<(item: T, colKey: string) => string>();
  getItemCellStyleFn = input<(item: T, colKey: string) => string>();

  // Models (양방향 바인딩)
  selectedItems = model<T[]>([]);
  expandedItems = model<T[]>([]);
  sorts = model<ISortingDef[]>([]);
  currentPage = model(0);

  // Content query
  columnControls = contentChildren(SdSheetColumnDirective);
}
```

#### 데이터 흐름

```
items → sortingManager.sort() (if useAutoSort) → sortedItems
sortedItems → page slice (if itemsPerPage > 0) → pagedItems
pagedItems → expandingManager (flatten) → displayItems
displayItems → @for template rendering
```

#### v12→v14 변환 매핑

| v12 | v14 |
|-----|-----|
| `class SdSelectionManager` | `function useSelectionManager` |
| `class SdSortingManager` | `function useSortingManager` |
| `class SdSheetLayoutEngine` | `function useSheetLayoutEngine` |
| `class SdSheetColumnFixingManager` | `function useSheetColumnFixing` |
| `class SdSheetDomAccessor` | `function useSheetDomAccessor` |
| `class SdSheetFocusIndicatorRenderer` | `function useSheetFocusIndicator` |
| `class SdSheetSelectRowIndicatorRenderer` | `function useSheetSelectRowIndicator` |
| `$signal()` / `$computed()` | `signal()` / `computed()` |
| `transformBoolean` | `booleanAttribute` |
| `injectElementRef()` | `inject(ElementRef)` |
| `forwardRef(() => ...)` | 직접 참조 (D2@4.1) |

### 대안 검토

| 접근 방식 | 선택 여부 | 이유 |
|-----------|-----------|------|
| 매니저를 class로 유지 | 미채택 | v14에 class 매니저 패턴 전례 없음 (D1@4.1), use* 함수 일관성 |
| CSS Grid 기반 레이아웃 | 미채택 | `<table>`이 접근성 우수, v12 동일 패턴 안전, 고정 컬럼 CSS Grid 구현 복잡 |
| 가상 스크롤 도입 | 미채택 | 고정 컬럼/트리/가변 높이와 호환 복잡, v12에 없는 신규 아키텍처, 마이그레이션 범위 초과 |
| 내부 유틸리티를 컴포넌트 파일에 인라인 | 미채택 | 파일 크기 관리, v12과 1:1 추적 용이 |
