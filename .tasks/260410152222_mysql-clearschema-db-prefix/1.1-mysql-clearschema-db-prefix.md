## 구현계획

### 배경
MySQL `clearSchema` 구현(`mysql-query-builder.ts:734`)에서 `GROUP_CONCAT`이 `table_name`만 사용하여 DROP TABLE 대상을 생성. root 사용자는 기본 DB 없이 연결되므로 "No database selected" 에러 발생.

### 목표
- DROP TABLE SQL에 `` `database`.`table` `` 형태의 fully qualified name 생성 [근거: Rule "fully qualified table name"]

### 비목표
- MSSQL, PostgreSQL clearSchema 수정 [근거: wbs 경계]
- initialize 로직 수정 [근거: wbs 경계]

### 설계
`mysql-query-builder.ts:734`의 `GROUP_CONCAT(CONCAT(...))` 내부에 `def.database`를 backtick으로 감싸서 prefix로 추가. `def.database`는 L725에서 이미 `/^[a-zA-Z0-9_]+$/`로 검증되므로 SQL 인젝션 안전.

### 대안 검토
USE 구문 추가 방식은 연결 상태를 변경하는 부작용이 있어 채택하지 않음.
