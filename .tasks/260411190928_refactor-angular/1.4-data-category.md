## 구현계획

### 배경
Feature 1.1~1.3에서 core/, controls/, layout/ 카테고리가 생성되었다. 현재 src/ top-level에 남은 디렉토리 중 8개를 data/ 카테고리로 묶는다. [근거: wbs "비즈니스 CRUD 추상화 계층"]

### 목표
- 8개 데이터 관련 디렉토리를 data/ 하위로 이동 [근거: Rule "8개 디렉토리를 data/ 하위로 이동"]
- 모든 import 경로가 새 위치를 정확히 반영 [근거: Rule "import 경로가 새 위치를 반영"]
- public API(index.ts re-export) 유지 [근거: wbs 기술적 제약]

### 비목표
- 디렉토리 내부 파일 구조 변경 [근거: wbs 경계]
- 코드 로직 변경 [근거: wbs 경계]

### 설계

**디렉토리 이동 매핑:**

| 원본 | 대상 |
|---|---|
| src/sheet/ | src/data/sheet/ |
| src/data-sheet/ | src/data/data-sheet/ |
| src/data-detail/ | src/data/data-detail/ |
| src/data-select-button/ | src/data/data-select-button/ |
| src/shared-data/ | src/data/shared-data/ |
| src/kanban/ | src/data/kanban/ |
| src/permission-table/ | src/data/permission-table/ |
| src/state-preset/ | src/data/state-preset/ |

**import 경로 변경 규칙:**
- 이동된 파일 → core/: `../core/` → `../../core/`
- 이동된 파일 → controls/: `../controls/` → `../../controls/`
- 이동된 파일 → layout/: `../layout/` → `../../layout/`
- 이동된 파일 상호 참조: 변경 없음 (같은 depth 이동, D2)
- index.ts: `./sheet/` → `./data/sheet/` 등
