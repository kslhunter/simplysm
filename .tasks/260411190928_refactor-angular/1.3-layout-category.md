## 구현계획

### 배경

Feature 1.1에서 core/ 내부를 기능별로 재구조화하고, Feature 1.2에서 controls/ 카테고리를 생성하여 11개 디렉토리를 이동했다. 동일한 패턴으로 페이지 구조 계층에 해당하는 4개 디렉토리(dock, sidebar, topbar, base-container)를 layout/ 카테고리로 이동한다.

### 목표
- dock/, sidebar/, topbar/, base-container/를 layout/ 하위로 이동하여 페이지 구조 계층을 시각적으로 그룹화 [근거: wbs "의존성 분석: core/ + controls/ 의존하는 페이지 구조 계층"]

### 비목표
- 각 디렉토리 내부 파일 구조 변경 [근거: wbs 경계 "각 디렉토리 내부 파일 구조는 변경하지 않음"]
- 코드 로직 변경 [근거: wbs 경계 "코드 로직 변경 없음"]

### 설계

**경로 변경 매트릭스:**

| 카테고리 | 현재 경로 | 변경 후 경로 | 변경 내용 |
|---|---|---|---|
| layout → core | `../core/` | `../../core/` | depth +1 |
| layout → controls | `../controls/` | `../../controls/` | depth +1 |
| layout 내부 (topbar→sidebar) | `../sidebar/` | `../sidebar/` | 변경 없음 |
| layout 내부 (base-container→topbar) | `../topbar/` | `../topbar/` | 변경 없음 |
| 외부 → layout (data-sheet→base-container) | `../base-container/` | `../layout/base-container/` | `layout/` 삽입 |
| 외부 → layout (data-detail→base-container) | `../base-container/` | `../layout/base-container/` | `layout/` 삽입 |
| index.ts | `./{dir}/` | `./layout/{dir}/` | `layout/` 삽입 |
| tests → src | `../../src/{dir}/` | `../../../src/layout/{dir}/` | depth +1, `layout/` 삽입 |

**수정 대상 파일 (src/):**

| 파일 | 변경 내용 |
|---|---|
| `layout/dock/sd-dock.ts` | `../core/` → `../../core/` (2건) |
| `layout/sidebar/sd-sidebar-menu.ts` | `../core/` → `../../core/` (4건), `../controls/` → `../../controls/` (2건) |
| `layout/sidebar/sd-sidebar-user.ts` | `../controls/` → `../../controls/` (4건), `../core/` → `../../core/` (1건) |
| `layout/topbar/sd-topbar.ts` | `../controls/` → `../../controls/` (1건) — sidebar 참조는 변경 없음 |
| `layout/topbar/sd-topbar-menu.ts` | `../core/` → `../../core/` (4건), `../controls/` → `../../controls/` (6건) |
| `layout/topbar/sd-topbar-user.ts` | `../controls/` → `../../controls/` (4건) |
| `layout/base-container/sd-base-container.ts` | `../core/` → `../../core/` (7건) — topbar 참조는 변경 없음 |
| `data-sheet/sd-data-sheet.ts` | `../base-container/` → `../layout/base-container/` (1건) |
| `data-detail/sd-data-detail.ts` | `../base-container/` → `../layout/base-container/` (1건) |
| `index.ts` | `./dock/`, `./sidebar/`, `./topbar/`, `./base-container/` → `./layout/{dir}/` (11건) |
