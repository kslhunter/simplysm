## 구현계획

### 배경

v14의 sd-list-item은 v12 대비 flex 기반으로 단순화되었으나, 3가지 스타일 퇴행이 확인됨:
1. selected-icon 모드의 텍스트색/hover 누락 (host 속성 바인딩도 함께 누락)
2. accordion 자식 리스트 padding 누락
3. flat 레이아웃 dimmed 스타일의 조건 범위가 v12보다 넓어짐

### 목표

- selected-icon + selected 상태 텍스트색(`--text-trans-default`)/hover 복원 [근거: Rule "selected-icon + selected 상태에서 텍스트색과 hover 효과"]
- `data-sd-has-selected-icon` 호스트 속성 바인딩 추가 [근거: Rule "selected-icon 호스트 속성 바인딩"]
- accordion 자식 리스트 padding 복원 [근거: Rule "accordion 자식 리스트 padding"]
- flat dimmed 스타일 범위를 `[data-sd-has-children="true"]`로 제한 [근거: Rule "flat 레이아웃 dimmed 스타일은 자식 있는 항목에만 적용", D1]

### 비목표

- `.sd-theme-mobile` hover 투명 처리 복원 [근거: WBS "의도적 개선" - 테마 축소]
- flex 구조화, `gap: var(--gap-sm)`, `._label`/`._tool` 구조 등 v14 개선사항 롤백 [근거: WBS 경계]
- `setupRipple()` 방식 롤백 [근거: v14 구조 개선]

### 설계

**변경 파일:** `packages/angular/src/controls/list/sd-list-item.ts`

#### 1. host 바인딩 추가 (line 107)

```typescript
host: {
  "[attr.data-sd-layout]": "layout()",
  "[attr.data-sd-selected]": "selected()",
  "[attr.data-sd-readonly]": "readonly()",
  "[attr.data-sd-has-children]": "hasChildren()",
  "[attr.data-sd-has-selected-icon]": "selectedIcon() !== undefined",  // 추가
},
```

[근거: Rule "selected-icon 호스트 속성 바인딩" — SCSS 선택자 `[data-sd-has-selected-icon="true"]`에 필요]

#### 2. SCSS: selected-icon + selected 스타일 추가

```scss
&[data-sd-has-selected-icon="true"][data-sd-selected="true"] > ._content {
  color: var(--text-trans-default);

  &:hover {
    background: var(--trans-lighter);
  }
}
```

[근거: v12 sd-list-item.control.ts:118-126 복원]

#### 3. SCSS: accordion 자식 리스트 padding 추가

```scss
&[data-sd-layout="accordion"] {
  > sd-collapse > ._content > sd-list {
    padding: var(--gap-xs) 0;
  }
}
```

[근거: v12 sd-list-item.control.ts:96-98. v14 sd-collapse DOM: `sd-collapse > div._content > sd-list`]

#### 4. SCSS: flat 스타일 범위 보정

```scss
// 변경 전: &[data-sd-layout="flat"]
// 변경 후:
&[data-sd-layout="flat"][data-sd-has-children="true"] {
  // 기존 dimmed 스타일 유지
}
```

[근거: v12 sd-list-item.control.ts:101, 설계 결정 D1]

### 대안 검토

| 대안 | 설명 | 비채택 사유 |
|---|---|---|
| selected-icon 스타일을 inline style로 처리 | `[style]` 바인딩으로 color 적용 | hover 효과는 inline으로 처리 불가, SCSS가 적절 |
| accordion child padding을 sd-list에서 처리 | sd-list 컴포넌트에 nested padding 추가 | sd-list는 중첩 여부를 알 수 없음, 부모인 sd-list-item에서 처리가 맞음 |
