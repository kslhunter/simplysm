## 요구명세

### 범위

v14 `sd-select-button.ts:18-33`에서 v12 `sd-select-button.control.ts:14-27` 대비 누락된 스타일 복원:

1. **기본 배경색**: `background: var(--control-color)` 추가
2. **텍스트 스타일**: `font-weight: bold; color: var(--theme-primary-default)` 추가 — search icon이 primary 테마 색상으로 표시되지 않던 문제의 직접 원인 (ng-icon은 `currentColor`를 통해 부모 `color` 상속)
3. **전환 효과**: `transition: background 0.1s linear` 추가
4. **hover 스타일**: `color: var(--theme-primary-darker)` 추가, `background: var(--trans-lighter)` → `var(--theme-gray-lightest)` 변경

### 경계

- `display: inline-flex; align-items: center; justify-content: center` 유지 (v14 개선 — v12의 `display: block`보다 아이콘 정렬에 유리)
- `position: relative; overflow: hidden` 유지 (ripple 효과용)
- 컴포넌트 자체의 `padding`, `border-left`은 변경하지 않음 (부모 sd-select에서 `> sd-dropdown > sd-select-button`으로 오버라이드하지만, 독립 사용시 기본값 역할)

## 구현계획

### 배경

sd-select-button은 sd-select 내부에서 추가 액션 버튼(검색, 편집 등)으로 사용되는 서브 컴포넌트이다. 주 사용처인 `sd-shared-data-select`에서 `tablerSearch`/`tablerEdit` ng-icon을 감싸며, ng-icon은 `currentColor`를 통해 부모의 `color` 속성을 상속한다. [근거: sd-shared-data-select.ts:70-77]

v14 마이그레이션 시 `color`, `font-weight`, `background`, `transition`, hover 색상이 누락되어 아이콘이 기본 텍스트 색상(검정)으로 렌더링되는 시각적 퇴행이 발생했다. [근거: WBS "search icon 문제의 직접 원인"]

### 목표

- sd-select-button에 v12의 기본 배경/텍스트 스타일을 복원하여 primary 테마 색상의 bold 아이콘 표시 [근거: Rule "기본 스타일 복원"]
- hover 상태에서 darker primary 텍스트 + gray-lightest 배경으로 시각적 피드백 강화 [근거: Rule "hover 스타일 복원"]
- 배경 변화에 부드러운 transition 적용 [근거: Rule "전환 효과 복원"]

### 비목표

- display/alignment 방식 변경 — v14 inline-flex 유지 [근거: WBS 경계]
- position/overflow 변경 — ripple 효과용 유지 [근거: WBS 경계]
- 컴포넌트 자체 padding/border-left 제거 — 부모에서 오버라이드하지만 독립 사용시 기본값 역할

### 설계

대상 파일: `packages/angular/src/controls/select/sd-select-button.ts:18-33`

SCSS 블록의 `sd-select-button` 규칙에 누락 속성을 추가하고, `&:hover` 규칙의 배경/색상을 v12 값으로 변경한다.

변경 전 (`sd-select-button.ts:18-33`):
```scss
sd-select-button {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  padding: var(--gap-sm) var(--gap-default);
  cursor: pointer;
  border-left: 1px solid var(--trans-lighter);
  position: relative;
  overflow: hidden;

  &:hover {
    background: var(--trans-lighter);
  }
}
```

변경 후:
```scss
sd-select-button {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  padding: var(--gap-sm) var(--gap-default);
  cursor: pointer;

  position: relative;
  overflow: hidden;
  background: var(--control-color);
  font-weight: bold;
  color: var(--theme-primary-default);
  transition: background 0.1s linear;

  &:hover {
    color: var(--theme-primary-darker);
    background: var(--theme-gray-lightest);
  }
}
```
