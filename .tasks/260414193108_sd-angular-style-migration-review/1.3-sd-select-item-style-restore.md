## 구현계획

### 배경

sd-select-item은 드롭다운 목록의 각 항목을 렌더링하는 컴포넌트다. v14에서 template 구조가 변경되어 `._content` div가 모든 콘텐츠를 래핑하며, 스타일이 `> ._content` 선택자를 통해 적용된다. 이 구조 변경 과정에서 기본 배경색, transition 효과, selected 텍스트 색상, disabled 배경색 4개 스타일이 누락되었다. [근거: v12/v14 소스코드 비교]

### 목표

- `> ._content`에 기본 배경색 `var(--control-color)` 적용 [근거: Rule "기본 상태에서 control-color 배경 표시"]
- `> ._content`에 hover/focus transition 효과 적용 [근거: Rule "hover/focus 시 배경 전환에 transition 효과 적용"]
- selected 상태에서 `color: var(--theme-primary-default)` 적용 [근거: Rule "selected 상태에서 텍스트가 primary 색상"]
- disabled 상태에서 `background: var(--theme-gray-default)` 적용 [근거: Rule "disabled 상태에서 회색 배경 표시"]

### 비목표

- template/로직 변경 [근거: WBS 경계 "v14의 구조 변경은 유지"]
- hover/focus 배경색을 `rgba(0,0,0,0.07)`로 복원 [근거: WBS 경계 "var(--trans-lighter) 변경은 유지"]
- `pointer-events: none` 제거 [근거: WBS 경계 "v14에서 추가된 pointer-events: none은 유지"]

### 설계

수정 대상: `packages/angular/src/controls/select/sd-select-item.ts` — styles 섹션 (line 34-72)

v14 현재 SCSS:
```scss
sd-select-item {
  display: block;

  > ._content {
    padding: var(--gap-sm) var(--gap-default);
    cursor: pointer;

    &:hover {
      background: var(--trans-lighter);
    }

    &:focus {
      outline: none;
      background: var(--trans-lighter);
    }
  }

  &[data-sd-selected="true"] > ._content {
    background: var(--trans-lighter);
    font-weight: bold;
  }

  &[data-sd-disabled="true"] {
    > ._content {
      opacity: 0.3;
      cursor: default;
      pointer-events: none;
    }
  }

  &[data-sd-hidden="true"] {
    display: none;
  }
}
```

변경 후 SCSS:
```scss
sd-select-item {
  display: block;

  > ._content {
    padding: var(--gap-sm) var(--gap-default);
    cursor: pointer;
    background: var(--control-color);            // +추가
    transition: background 0.1s ease-in;         // +추가

    &:hover {
      background: var(--trans-lighter);
      transition: background 0.1s ease-out;      // +추가
    }

    &:focus {
      outline: none;
      background: var(--trans-lighter);
      transition: background 0.1s ease-out;      // +추가
    }
  }

  &[data-sd-selected="true"] > ._content {
    color: var(--theme-primary-default);         // +추가
    background: var(--trans-lighter);
    font-weight: bold;
  }

  &[data-sd-disabled="true"] {
    > ._content {
      background: var(--theme-gray-default);     // +추가
      opacity: 0.3;
      cursor: default;
      pointer-events: none;
    }
  }

  &[data-sd-hidden="true"] {
    display: none;
  }
}
```
