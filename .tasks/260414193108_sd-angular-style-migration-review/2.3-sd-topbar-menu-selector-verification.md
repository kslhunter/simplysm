## 구현계획

### 배경
`sd-topbar-menu.ts`의 styles에 중첩 리스트(`sd-list` 내부 `sd-list`)에 `background: var(--trans-lightest)`를 적용하는 CSS 규칙이 있다. 그러나 `SdDropdown` 컴포넌트가 팝업을 `document.body`에 append하므로, `sd-topbar-menu` 하위 선택자는 팝업이 열린 상태에서 매칭되지 않는다. v12에서도 동일한 상황이었으므로 퇴행이 아니며, dead CSS를 삭제한다.

### 목표
- dead CSS 제거 [근거: 설계 결정 D1]

### 비목표
- 선택자를 실제 작동하도록 수정 [근거: wbs 경계 "선택자 구체화 자체가 문제가 아닌 경우 수정 불필요", v12에서도 미적용]

### 설계
- `sd-topbar-menu.ts`의 `styles` 속성 전체를 제거한다 (유일한 규칙이 dead CSS이므로)

### 대안 검토
- 현상 유지: dead CSS가 남아 혼란 유발 → 사용자가 삭제를 선택
- 선택자 수정: WBS 범위 초과, v12에서도 미적용이던 스타일 → 제외

#### Slice 1: dead CSS 삭제
- **구현 내용:** `sd-topbar-menu.ts`에서 `styles` 속성 제거
