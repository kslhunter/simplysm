## 구현계획

### 배경

v14에서 `SdSelectItem.value`가 `input.required<T>()`로 변경되어, value가 undefined인 "미지정" 항목에서 `<sd-select-item>`을 사용할 수 없게 됨. 이에 따라 `<div class="_sd-shared-data-select-undefined">`로 대체되었으나, sd-select-item의 `._content` 스타일(padding, cursor, background, hover/focus 효과)이 누락됨.

### 목표

- `._sd-shared-data-select-undefined` div에 sd-select-item `._content`와 시각적으로 동일한 스타일 적용 [근거: WBS "sd-select-item과 동일한 패딩/커서/hover 스타일 적용"]

### 비목표

- SdSelectItem 컴포넌트 수정 [근거: SdSelectItem.value가 required, 수정 시 side-effect 위험]
- 드롭다운 닫기 동작 복원 [근거: Feature 범위가 "스타일" 복원, 기능적 차이는 별도 처리]

### 설계

`sd-shared-data-select.ts`의 `@Component` 데코레이터에 `styles` 배열을 추가하고, `._sd-shared-data-select-undefined` 선택자에 sd-select-item `._content`와 동일한 스타일을 정의한다. [근거: 코드베이스의 컴포넌트별 인라인 SCSS 패턴]

변경 파일: `packages/angular/src/data/shared-data/sd-shared-data-select.ts`

```scss
sd-shared-data-select {
  ._sd-shared-data-select-undefined {
    padding: var(--gap-sm) var(--gap-default);
    cursor: pointer;
    background: var(--control-color);
    transition: background 0.1s ease-in;

    &:hover {
      background: var(--trans-lighter);
      transition: background 0.1s ease-out;
    }

    &:focus {
      outline: none;
      background: var(--trans-lighter);
      transition: background 0.1s ease-out;
    }
  }
}
```

### 대안 검토

| 접근법 | 장점 | 단점 | 비고 |
|--------|------|------|------|
| **(선택) div에 스타일 추가** | 단일 파일 변경, SdSelectItem 영향 없음 | sd-select-item과 스타일 일부 중복 | 3개 속성 + 2개 상태 = 적은 중복량 |
| sd-select-item 복원 | 스타일 중복 없음 | SdSelectItem.value를 optional로 변경 필요, selectItem/toggleItem의 undefined 처리 필요, 다른 사용처 side-effect | 범위 초과 |
