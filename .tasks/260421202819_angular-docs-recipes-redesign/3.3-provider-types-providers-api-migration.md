## 구현계획

### 배경

Feature 1.1·1.2 완료로 `crud-list.md`와 `crud-detail.md`에 MOVE 표식과 이관 후보 목록이 확정되었다. 본 Feature는 해당 목록에서 `provider-types.md`(Feature 3.7)와 `providers.md`(Feature 3.8)로 지정된 항목들의 **사용 패턴·구현 예제**를 docs로 이관하고, recipes에는 축약 링크를 남긴다. 기존 docs의 타입 정의·시그니처·표는 그대로 유지하며 "사용 패턴" 하위 섹션만 추가한다.

### 목표

- provider-types.md에 `SdSelectModal<T>` 신규 섹션 + `SelectModalOutputResult<T>` 사용 패턴 + `SdModalContentDef<R>` 구현 패턴 + "선택 모달 vs 조회 전용 modal" 용도 구분을 추가한다
- providers.md에 `injectPermsSignal` / `SdToastProvider.try` / `SdActivatedModalProvider` / `SdModalProvider.showAsync` / `SdFileDialogProvider.showAsync`의 사용 패턴·코드 예제를 추가한다
- 각 API 섹션 끝에 recipes로의 역링크("실사용 예")를 배치하여 양방향 위키 연결을 완성한다
- recipes의 MOVE 표식을 축약 링크로 대체하고 이관 후보 체크리스트를 `[x]`로 체크한다

### 비목표

- **provider-types.md·providers.md의 기존 타입 정의·시그니처·표 수정 아님** — 사용 패턴만 추가
- **MOVE 표식 비대상 provider 확장 아님** — SdSharedDataProvider, SdThemeProvider 등은 범위 외
- **테스트 미작성** — 문서 작업 (D1)
- **UI 컴포넌트 이관 아님** — Feature 3.1 범위
- **Composable 이관 아님** — Feature 3.2 범위
