- **docs 기존 섹션 구조 유지**: utils.md의 기존 `## / ### / 시그니처 / 표` 구조를 그대로 유지하면서 "사용 패턴" / "주의사항" 하위 내용을 확장·추가 [근거: Feature 3.3 설계 `3.3-provider-types-providers-api-migration.md:62`]

## 구현계획

### 배경

Feature 1.1·1.2 완료로 `crud-list.md`와 `crud-detail.md`에 MOVE 표식과 이관 후보 목록이 확정되었다. 본 Feature는 해당 목록에서 `docs/utils.md`(이관 후보 목록 Feature 3.6)로 지정된 항목들의 **사용 패턴·주의사항**을 docs로 이관하고, recipes에는 축약 링크를 남긴다. 기존 docs의 시그니처·표는 그대로 유지하며 하위 내용만 확장한다. 추가로 D1 결정에 따라 `injectPermsSignal`을 `providers.md` 대신 `utils.md`에 이관한다.

### 목표

- utils.md에 `mark` / `injectViewTypeSignal` / `injectViewTitleSignal` / `injectCurrentPageCodeSignal` / `injectFullPageCodeSignal` / `setupCanDeactivate`의 사용 패턴·주의사항을 확장 추가한다
- utils.md에 `injectPermsSignal` 신규 섹션을 추가한다 (D1)
- 각 API 섹션 끝에 recipes로의 역링크("실사용 예")를 배치하여 양방향 위키 연결을 완성한다

#### 변경 5: utils/inject-routing-signals.md — `injectViewTypeSignal` 섹션 확장

현행 `### injectViewTypeSignal` 섹션(`docs/utils/inject-routing-signals.md`) 하단에 호출 시점 제약·수동 오버라이드·역링크를 추가한다.

**삽입 위치:** 현행 내부 판정 로직 직후

**추가 내용:**

```markdown
#### 호출 시점 제약

내부에서 `inject(SdActivatedModalProvider)`, `inject(ActivatedRoute)`, `inject(ElementRef)`를 호출한다. Angular `inject()`는 injection context(생성자 실행 중 또는 필드 초기화 시점) 안에서만 유효하므로, `computed` 콜백이나 `effect` 안에서 호출하면 **`NG0203` 런타임 에러**가 발생한다.

```typescript
// ✅ OK — 필드 이니셜라이저
protected readonly viewType = injectViewTypeSignal();

// ❌ NG0203 — computed 내부
protected readonly viewType = computed(() => injectViewTypeSignal()());
```

#### 수동 오버라이드 패턴

일반적으로 자동 판정으로 충분하다. 수동 오버라이드가 필요한 특수 상황(예: 특정 페이지 안에 자기 자신을 모달처럼 보이게 하고 싶은 경우)에는:

```typescript
override = input<SdViewType>();
private readonly _autoViewType = injectViewTypeSignal();
protected readonly viewType = computed(() => this.override() ?? this._autoViewType());
```

> 이 오버라이드는 추상화 복원을 부추기므로 **기본은 자동 판정으로 쓰기**를 권장한다.
