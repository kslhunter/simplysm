## 구현계획

### 배경
Capacitor 클래스(`src/capacitor/capacitor.ts`)는 1,109줄이며, Android 설정 관련 9개 private 메서드(line 512~823, ~305줄)가 가장 큰 단일 블록이다. Feature 1.1에서 `lint-core.ts`로 함수를 추출한 패턴과 동일하게, 이 메서드들을 `capacitor-android.ts`로 분리한다.

### 목표
- Android 설정 로직을 독립 모듈(`capacitor/capacitor-android.ts`)로 분리 [근거: wbs "Capacitor 거대 클래스 분리"]
- 기존 동작 100% 보존 [근거: wbs "코드 이동만"]

### 비목표
- `_configureSigningConfig` 분리 [근거: wbs 경계 "빌드 흐름의 일부"]
- `_setupNpmConf`, `_setupIcon` 분리 [근거: wbs 경계]
- 내부 로직 변경 [근거: wbs "코드 이동만"]

### 설계

**새 모듈: `src/capacitor/capacitor-android.ts`**

```typescript
// --- Exports ---
export async function configureAndroid(
  capPath: string, config: SdCapacitorConfig, npmConfig: NpmConfig
): Promise<void>
export async function findJava21(): Promise<string | undefined>
export async function findAndroidSdk(): Promise<string | undefined>

// --- Internal (unexported) ---
async function configureJavaHomePath(androidPath: string): Promise<void>
async function configureSdkPath(androidPath: string): Promise<void>
async function configureManifest(
  androidPath: string, androidConfig?: SdCapacitorAndroidConfig
): Promise<void>
async function configureRootBuildGradle(androidPath: string): Promise<void>
async function configureBuildGradle(
  androidPath: string, version: string, sdkVersion?: number
): Promise<void>
async function configureStyles(androidPath: string): Promise<void>
```

**Capacitor 클래스 변경:**
- `initialize()` line 129: `await this._configureAndroid()` → `await configureAndroid(this._capPath, this._config, this._npmConfig)`
- `_validateTools()` line 218: `this._findAndroidSdk()` → `findAndroidSdk()`
- `_validateTools()` line 229: `this._findJava21()` → `findJava21()`
- 9개 private 메서드 + `//#region Private - Android 설정` 삭제
- `env` import 제거 (`env`는 `findAndroidSdk` 내부에서만 사용되었음)

**import 변경:**
- `capacitor.ts`에 `import { configureAndroid, findAndroidSdk, findJava21 } from "./capacitor-android.js"` 추가

### 대안 검토
1. **CapacitorAndroid 헬퍼 클래스**: 상태가 없으므로 standalone 함수가 더 간결. lint-core.ts 패턴과 일관성 유지
2. **모든 함수 export**: configure* 함수들은 configureAndroid 내부에서만 호출되므로 불필요한 표면적 증가
