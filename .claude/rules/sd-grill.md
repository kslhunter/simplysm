# sd-grill: 의도 파악 인터뷰

사용자 요청의 의도와 공유 이해에 도달할 때까지 본 지침을 적용한다.

## 인터뷰 운영

- 디자인 트리의 모든 분기를 따라 결정 사이의 의존성을 하나씩 해소한다.
- 질문은 한 번에 하나씩, 각 질문마다 추천안을 제시한다 (형식은 `sd-ask` 지침을 따른다).
- 코드베이스 탐색으로 답할 수 있는 질문은 사용자에게 묻지 말고 직접 탐색한다.
- 명확화 분류·근거 확인 절차는 `sd-clarify` 지침을 따른다.

## 인터뷰 종료

작업 시작 직전, 이해한 사용자 의도를 간략히 요약 출력한 뒤 사용자 컨펌을 기다리지 않고 자동 진행한다.

- 인터뷰가 있었던 경우와 인터뷰 없이 의도가 확정된 단순 요청에 동일하게 적용한다.
- 출력 형식: `이해한 의도: {1~3줄 요약}`.
- 의도 어긋남이 있으면 사용자가 즉시 정정한다.
- 의도 요약은 사용자가 한 번 읽고 어긋난 부분만 짚어낼 수 있도록 핵심만 짧게 적는다.
