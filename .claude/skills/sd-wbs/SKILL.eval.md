## 행동 Eval

### 시나리오: WBS 생성

- 입력: "/sd-wbs 사내 도서 관리 시스템을 만들려고 한다."
- 체크리스트:
  - [ ] 프로젝트 개요 파악을 위해 사용자에게 질문했다.
  - [ ] Impact Mapping 구축을 위해 질문했다.
  - [ ] 기술적 구현 방법(How)이 아닌 비즈니스 요구사항(What)만 질문했다.
  - [ ] Feature Breakdown 시 불명확한 점을 사용자에게 질문했다.
  - [ ] `.tasks/{yyMMddHHmmss}_{topic}/wbs.md` 경로로 파일이 생성되었다.
  - [ ] 프로젝트 개요, Impact Mapping, Feature Breakdown, 제외 사항이 문서에 포함되었다.
  - [ ] Feature에 의존성, 범위, 경계, 근거가 포함되었다.
  - [ ] 대화에서 수집한 구체적 정보(수치, 열거 항목, 기술 제약, 참조 파일 등)가 문서에 빠짐없이 기록되었다.
  - [ ] 다음 단계 안내가 출력되었다.
