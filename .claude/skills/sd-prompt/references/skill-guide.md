# SKILL.md 구조 가이드

## 전체 구조

```markdown
---
name: {skill-name}
description: {아래 description 포맷 참고}
---

# {skill-name}: {제목}

## 공통 규칙              ← 여러 Step에서 참조하는 규칙 (해당 시)

## Step N: {단계 제목}
### N-N. {절차}           ← 시간 순서 절차에만 번호
### {참조 항목}           ← 형식/규칙/설정은 번호 없이
```

## description 포맷

한 줄로 작성하며, 아래 포맷을 반드시 따른다:

- **스킬**: `{기능 설명}하는 스킬. "{트리거1}", "{트리거2}", "{트리거3}" 등을 요청할 때 사용한다.`
- **규칙**: `{기능 설명}하는 규칙. "{트리거 조건1}", "{트리거 조건2}" 등을 요청할 때 사용한다.`

## 헤딩 레벨

| 레벨   | 용도                       | 예시                              |
| ------ | -------------------------- | --------------------------------- |
| `#`    | 스킬 제목                  | `# sd-tdd: TDD 개발`             |
| `##`   | 공통 규칙 / Step           | `## 공통 규칙`, `## Step 1: ...`  |
| `###`  | Step 내 절차 또는 참조 항목 | `### 2-1. 복수가설 생성`, `### 출력 형식` |
| `####` | 절차 내 상세/참조 자료      | `#### 검증 도구 상세`, `#### 종료 조건`   |

## 배치 원칙

- **`## 공통 규칙`** — 여러 Step에서 참조하는 규칙/정의를 Step들 앞에 배치한다
- **`## Step N:`** — 시간 순서대로 수행하는 각 단계
- **Step 안에 필요한 것을 넣는다** — 해당 Step에서만 쓰는 규칙, 형식, 참조 자료는 Step 안에 둔다
- **Step 밖(공통)에는 여러 Step에서 참조하는 것만 둔다**

## 번호 규칙

`### N-N.` 번호는 **시간 순서대로 수행하는 절차**에만 매긴다.

| 유형                                       | 번호 | 예시                            |
| ------------------------------------------ | ---- | ------------------------------- |
| 절차 (시간 순서대로 수행)                  | O    | `### 2-1. 복수가설 생성`        |
| 형식 정의                                  | X    | `### 출력 형식`                 |
| 조건별 분기 (확정 시 / 미확정 시)          | X    | `### 원인 확정 시`              |
| 규칙/제약                                  | X    | `### 방안 제시 규칙`            |
| 설정/경로                                  | X    | `### 출력 경로`                 |

## 스킬 호출 depth 제한

스킬에서 다른 스킬을 호출(Skill tool)할 때, **최대 2 depth**까지만 동작한다. 3번째 스킬 호출은 무시된다. (references/*.md, rules/*.md 파일 읽기는 depth에 포함되지 않는다.)

| 체인 | 결과 |
|------|------|
| 스킬 A → 스킬 B | OK |
| 스킬 A → 스킬 B → 스킬 C | FAIL (스킬 C 무시됨) |

예: `/sd-dev`가 내부에서 `/sd-plan`을 호출하고, `/sd-plan`이 다시 `/sd-prompt`를 호출하면 — `/sd-prompt`는 실행되지 않는다.

**NEVER 스킬이 호출하는 스킬이 또 다른 스킬을 호출하도록 설계하지 않는다. 스킬 호출 체인은 반드시 2 depth 이내로 유지한다.**
