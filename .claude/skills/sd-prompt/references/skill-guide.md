# SKILL.md 구조 가이드

## 헤딩 레벨

| 레벨   | 용도                       | 예시                              |
| ------ | -------------------------- | --------------------------------- |
| `#`    | 스킬 제목                  | `# sd-tdd: TDD 개발`             |
| `##`   | 공통 규칙 / Step           | `## 공통 규칙`, `## Step 1: ...`  |
| `###`  | Step 내 절차 또는 참조 항목 | `### 2-1. 복수가설 생성`, `### 출력 형식` |
| `####` | 절차 내 상세/참조 자료      | `#### 검증 도구 상세`, `#### 종료 조건`   |

## 배치 원칙

- **`## 공통 규칙`** — 여러 Step에서 참조하는 규칙/정의를 Step들 앞에 배치한다
- **`## Step N:`** — 시간 순서대로 수행하는 각 단계
- **Step 안에 필요한 것을 넣는다** — 해당 Step에서만 쓰는 규칙, 형식, 참조 자료는 Step 안에 둔다
- **Step 밖(공통)에는 여러 Step에서 참조하는 것만 둔다**

## 번호 규칙

`### N-N.` 번호는 **시간 순서대로 수행하는 절차**에만 매긴다.

| 유형                                       | 번호 | 예시                            |
| ------------------------------------------ | ---- | ------------------------------- |
| 절차 (시간 순서대로 수행)                  | O    | `### 2-1. 복수가설 생성`        |
| 형식 정의                                  | X    | `### 출력 형식`                 |
| 조건별 분기 (확정 시 / 미확정 시)          | X    | `### 원인 확정 시`              |
| 규칙/제약                                  | X    | `### 방안 제시 규칙`            |
| 설정/경로                                  | X    | `### 출력 경로`                 |
