## 5. 화면

### 5.1 거래처 목록

**텍스트 와이어프레임**
```
┌─────────────────────────────────────────┐
│ 거래처 목록                             │
├─────────────────────────────────────────┤
│ 검색: [______________________] [조회]   │
├─────────────────────────────────────────┤
│ 코드 │ 명칭          │ 담당자 │ 전화    │
│ 0001 │ ...           │ ...    │ ...     │
├─────────────────────────────────────────┤
│ [신규 등록]                             │
└─────────────────────────────────────────┘
```

**기능 개요**
- 등록된 거래처 목록을 조회한다.

**항목**
| 명칭 | 구분 | 필수 | 설명 |
|---|---|---|---|
| 검색 | 텍스트 입력 | X | 코드/명칭 부분 일치 |
| `[조회]` | 버튼 | - | 검색어로 필터링 |
| 코드 | 텍스트 표시 | - | [모델.거래처.코드] |
| 명칭 | 텍스트 표시 | - | [모델.거래처.명칭] |
| 담당자 | 텍스트 표시 | - | [모델.거래처.담당자] |
| 전화 | 텍스트 표시 | - | [모델.거래처.전화] |
| `[신규 등록]` | 버튼 | - | 등록 화면으로 이동 |

### 5.2 거래처 등록

**텍스트 와이어프레임**
```
┌──────────────────────────────┐
│ 거래처 등록                  │
├──────────────────────────────┤
│ 코드:    [____________]      │
│ 명칭:    [____________]      │
│ 담당자:  [____________]      │
│ 전화:    [____________]      │
│                              │
│           [저장] [취소]      │
└──────────────────────────────┘
```

**기능 개요**
- 신규 거래처 정보를 입력하여 등록한다.

**항목**
| 명칭 | 구분 | 필수 | 설명 |
|---|---|---|---|
| 코드 | 텍스트 입력 | O | 4자 |
| 명칭 | 텍스트 입력 | O | |
| 담당자 | 텍스트 입력 | X | |
| 전화 | 텍스트 입력 | X | |
| `[저장]` | 버튼 | - | 거래처 신규 등록 |
| `[취소]` | 버튼 | - | 입력 취소 |

**동작**
- `[저장]` 클릭 → 입력값 검증 후 거래처 마스터에 등록
- `[취소]` 클릭 → 입력 취소 후 목록 화면으로 이동
