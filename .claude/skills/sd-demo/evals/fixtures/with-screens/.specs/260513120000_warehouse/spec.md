### 4.1 Item Register (PC) [확정: 2026-05-13]

기능 개요:

- Register and edit items.

와이어프레임:

```
┌──────────────────────────┐
│ Code     [          ]    │
│ Name     [          ]    │
│ [Save] [Cancel]          │
└──────────────────────────┘
```

항목:

**입력 폼**

| 항목 | 종류   | 필수 | 도메인 매핑      | 비고 |
| ---- | ------ | ---- | ---------------- | ---- |
| Code | 텍스트 | O    | [모델.Item.code] | -    |
| Name | 텍스트 | O    | [모델.Item.name] | -    |

동작:

- [Save]: Save the form.
- [Cancel]: Reset the form.
