# 재고 관리 요구 분석서

## 1. 개요

### 1.1 핵심 목적 [확정: 2026-05-26]

창고별 품목 재고 현황 조회 시스템

### 1.2 주요 목표 [확정: 2026-05-26]

- 창고별·품목별 재고 현황 조회

### 1.3 최종 사용자/이해관계자 [확정: 2026-05-26]

- 창고 관리자: PC 로 재고 현황 조회

### 1.4 환경/장치 [확정: 2026-05-26]

```
   ┌─────────┐
   │   PC    │
   └────┬────┘
        │
        ▼
   ┌──────────┐
   │ WMS 서버 │
   └──────────┘
```

- PC — 창고 관리자가 재고 화면 조회에 사용
  - OS: Windows 11
  - Browser: Chrome 최신
  - 해상도: 1920 x 1080

### 4.1 재고 조회 (PC) [확정: 2026-05-26]

Actor: 창고 관리자
관련 섹션: [모델.재고]

기능 개요:

- 창고별·품목별 재고 현황 조회

#### 와이어프레임

```
┌────────────────────────────────────────────────────────────────────┐
│ 재고 조회                                                          │
│ [조회]  <필터>                                                     │
├────────────────────────────────────────────────────────────────────┤
│ <재고 목록 시트>                                                   │
└────────────────────────────────────────────────────────────────────┘
```

#### 항목

**필터**

| 항목      | 종류      | 필수 | 비고                     |
| --------- | --------- | ---- | ------------------------ |
| 창고      | 정적 선택 | X    | 전체·창고 목록           |
| 품목 검색 | 텍스트    | X    | 코드 또는 명칭 부분 일치 |

**재고 목록 시트**

| 컬럼   | 종류 | 필수 | 도메인 매핑          | 비고      |
| ------ | ---- | ---- | -------------------- | --------- |
| 창고   | 문자 | -    | [모델.재고.창고]     |           |
| 품목   | 문자 | -    | [모델.재고.품목명]   |           |
| 재고량 | 숫자 | -    | [모델.재고.수량]     | 우측 정렬 |
| 갱신일 | 날짜 | -    | [모델.재고.갱신일]   |           |

#### 동작

- `[조회]` 클릭: 검색 필터 조건으로 목록 갱신

#### 빈 상태

- 검색 결과 없음: "조회된 재고가 없습니다." 표시
