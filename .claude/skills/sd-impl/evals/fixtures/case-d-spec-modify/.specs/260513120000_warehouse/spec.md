### 4.1 박스 등록 (PC) [확정: 2026-05-20]

#### 와이어프레임 (텍스트)

```
┌─────────────────────────┐
│ 박스 등록                │
├─────────────────────────┤
│ <등록 폼>                │
│                         │
│         [저장]          │
└─────────────────────────┘
```

#### 항목

**등록 폼**

| 항목      | 종류   | 필수 | 도메인 매핑      | 비고                |
| --------- | ------ | ---- | ---------------- | ------------------- |
| 박스 코드 | 문자열 | Y    | [모델.박스.코드] | 코드 길이 규칙 따름 |
| 품목 코드 | 문자열 | Y    | [모델.박스.품목] | -                   |

#### 동작

- `[저장]` 클릭: 입력값으로 박스 1건 등록
