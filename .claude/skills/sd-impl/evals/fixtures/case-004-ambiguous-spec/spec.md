### §4.1 도서 대여 처리 [확정: 2026-05-15]

**Actor**: 사서
**관련 섹션**: §7.1 도서, §7.2 대여
**장치**: PC 웹

**기능 개요**:
- 도서 검색 후 사용자 지정해 대여 등록.

**와이어프레임**:
```
[도서 검색]                       [선택]
[사용자 ID 입력]                   [대여]
```

**항목표**:

| 항목         | 타입   | 비고             |
| ------------ | ------ | ---------------- |
| 도서 검색    | text   | 제목·저자 검색   |
| 사용자 ID    | text   | -                |

**동작**:
- 도서 검색 후 1건 선택.
- 사용자 ID 입력.
- "대여" 클릭 시 §7.2 대여 레코드 생성.
- **재고 부족 시 처리.**
