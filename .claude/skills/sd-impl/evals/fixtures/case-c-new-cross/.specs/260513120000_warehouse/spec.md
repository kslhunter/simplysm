### 6.1 데이터 변경 로그 [확정: 2026-05-20]

목적: 모든 도메인 모델 변경분 기록
트리거: 모든 엔티티 update 시 / 전체
관련 섹션: [모델.변경 로그]

#### 처리

1. 변경 전 엔티티 스냅샷 수집
2. 변경 후 엔티티 스냅샷 수집
3. 변경 로그 1건 적재 (필드: 엔티티명·키·변경 전·변경 후·일시·사용자)

#### 예외 처리

- 적재 실패: 로그 X, 원 트랜잭션 진행 (best-effort)

### 8.1 변경 로그 [확정: 2026-05-20]

필드:

| 필드      | 타입   | 필수 | 비고                  |
| --------- | ------ | ---- | --------------------- |
| ID        | 숫자   | Y    | 자동 부여             |
| 엔티티명  | 문자열 | Y    | 변경된 엔티티 종류    |
| 엔티티 키 | 문자열 | Y    | 변경된 엔티티 식별 키 |
| 변경 전   | 텍스트 | N    | JSON 직렬화           |
| 변경 후   | 텍스트 | N    | JSON 직렬화           |
| 일시      | 일시   | Y    | 변경 발생 시점        |
| 사용자    | 문자열 | Y    | 변경 수행자           |

키/제약:

- 식별 키: ID
