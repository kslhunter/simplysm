### §4.1 도서 목록 [확정: 2026-05-01]

**Actor**: 사서

**기능 개요**: 등록된 도서 전체 목록 표시.

**항목표**:

| 항목   | 타입 | 비고        |
| ------ | ---- | ----------- |
| 제목   | text | §7.1.title  |
| 저자   | text | §7.1.author |

**동작**: 진입 시 전체 목록 로드.

### §4.2 도서 등록 [확정: 2026-05-01]

**Actor**: 사서

**기능 개요**: 신규 도서 등록 폼.

**항목표**:

| 항목 | 타입 | 비고        |
| ---- | ---- | ----------- |
| 제목 | text | §7.1.title  |
| 저자 | text | §7.1.author |

**동작**: 입력 후 "저장" 클릭 시 §7.1 레코드 생성.
