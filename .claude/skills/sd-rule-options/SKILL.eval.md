# Eval: sd-rule-options

## 행동 Eval

### 시나리오 1: 단일 결정사항

- 입력: "/sd-rule-options 로깅 라이브러리를 선택해야 해. winston, pino, bunyan 중에 뭐가 좋을까?"
- 체크리스트:
  - [ ] 각 선택지(winston, pino, bunyan)에 장단점이 포함되어 있다
  - [ ] 각 선택지에 10점 만점 점수가 매겨져 있다
  - [ ] "수행 안 함" 선택지가 포함되어 있다
  - [ ] "수행 안 함" 선택지에도 장단점과 점수가 매겨져 있다
  - [ ] 최고 점수 선택지가 다른 선택지와 동점이 아니다 (추천 대상이 명확하다)
  - [ ] 최고 점수 선택지를 명시적으로 추천하고 사유를 한 줄로 요약했다
  - [ ] 점수 관점에 "구현 비용", "복잡도", "단순성"이 포함되어 있지 않다
  - [ ] 점수 관점에 "안정성"이 포함되어 있다

### 시나리오 2: 복수 결정사항

- 입력: "/sd-rule-options 새 마이크로서비스를 설계해야 해. 프로그래밍 언어, 데이터베이스, 메시지 큐를 결정해줘."
- 체크리스트:
  - [ ] 복수 결정사항을 건별로 제시했다.
  - [ ] 진행 상황이 표시되었다 (현재 몇 번째인지 알 수 있다)
  - [ ] 첫 번째 결정사항에 각 선택지별 장단점/트레이드오프/10점 만점 점수가 포함되어 있다
  - [ ] 첫 번째 결정사항에 "수행 안 함" 선택지가 포함되어 있다
  - [ ] 첫 번째 결정사항에서 최고 점수 선택지를 명시적으로 추천했다
  - [ ] 두 번째 결정사항에도 동일한 형식(장단점/점수/수행안함/추천)이 적용되었다
  - [ ] 이전 결정 결과가 후속 결정의 평가에 반영되었다

## 안티패턴 Eval

- [ ] 복수 결정사항을 건별 결정(선택지 제시 → 선택 → 다음 결정) 구조 없이 평면적으로 나열하였다.
- [ ] 선택지 중 "수행 안 함" 옵션이 누락되었다
- [ ] 최고 점수 선택지가 다른 선택지와 동점이다 (추천 대상이 불명확해지는 동점)
- [ ] 점수 관점에 "구현 비용", "복잡도", "단순성"이 포함되었다
- [ ] 점수 관점에 "안정성"이 누락되었다
