# Eval: sd-rule-options

## 행동 Eval

### 시나리오 1: 단일 결정사항

- 입력: "로깅 라이브러리를 선택해야 해. winston, pino, bunyan 중에 뭐가 좋을까? sd-rule-options 규칙에 따라 선택지를 제시해줘"
- 체크리스트:
  - [ ] 각 선택지(winston, pino, bunyan)에 장단점이 포함되어 있다
  - [ ] 각 선택지에 10점 만점 점수가 매겨져 있다
  - [ ] "수행 안 함" 선택지가 포함되어 있다
  - [ ] "수행 안 함" 선택지에도 장단점과 점수가 매겨져 있다
  - [ ] 동점인 선택지가 없다 (모든 평균 점수가 서로 다르다)
  - [ ] 최고 점수 선택지를 명시적으로 추천하고 사유를 한 줄로 요약했다
  - [ ] 점수 관점에 "구현 비용", "복잡도", "단순성"이 포함되어 있지 않다
  - [ ] 점수 관점에 "안정성"이 포함되어 있다

### 시나리오 2: 복수 결정사항

- 입력: "새 마이크로서비스를 설계해야 해. 프로그래밍 언어, 데이터베이스, 메시지 큐를 결정해줘. sd-rule-options 규칙에 따라 선택지를 제시해줘"
- 체크리스트:
  - [ ] 첫 번째 결정사항만 단독으로 제시되었다 (나머지가 함께 나열되지 않았다)
  - [ ] 진행 상황이 표시되었다 (예: "1/3건 완료" 형태)
  - [ ] 첫 번째 결정사항에 각 선택지별 장단점/트레이드오프/10점 만점 점수가 포함되어 있다
  - [ ] 첫 번째 결정사항에 "수행 안 함" 선택지가 포함되어 있다
  - [ ] 첫 번째 결정사항에서 최고 점수 선택지를 명시적으로 추천했다
  - [ ] 자동 선택 후 두 번째 결정사항이 별도로 제시되었다
  - [ ] 두 번째 결정사항에도 동일한 형식(장단점/점수/수행안함/추천)이 적용되었다

## 안티패턴 Eval

- [ ] 복수 결정사항(프로그래밍 언어, 데이터베이스, 메시지 큐)을 한꺼번에 모두 나열했다
- [ ] 선택지 중 "수행 안 함" 옵션이 누락되었다
- [ ] 동점 평균 점수가 존재한다
- [ ] 점수 관점에 "구현 비용", "복잡도", "단순성"이 포함되었다
- [ ] 점수 관점에 "안정성"이 누락되었다
