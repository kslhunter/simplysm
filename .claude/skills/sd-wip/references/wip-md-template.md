# 작업 메모

현재 대화의 분석 컨텍스트 압축. 산출물(있다면) 과 함께 읽어 새 세션에서 대화를 그대로 이어가도록.

**담는 것**: 산출물에 안 들어가는 결정 흐름·근거·정정·가설·메타 가이드·자료 컨텍스트.
**담지 않는 것**: 산출물에 이미 표면화된 결과·매핑·포인터 (산출물이 다룸).
