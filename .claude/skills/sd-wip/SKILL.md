# sd-wip

현재 대화의 분석 컨텍스트를 압축 파일로 작성. 새 세션에서 산출물(있다면) + 이 파일을 읽어 대화를 그대로 이어가도록.

**정확성·완전성 1순위. 시간·용량 비용 감수. 단순 요약 X.**

## 동작

### 산출물 유무 판단

산출물 = 본 세션에서 사용자 컨펌된 작성/수정 대상 파일 1건 (예: spec.md, impl.md).

- **산출물 있는 대화** → 그 산출물 옆에 `_wip.md` 작성 (덮어쓰기).
- **산출물 없는 일반 대화** → `.wips/{yyMMddHHmmss}_{slug}.md` 작성. `slug` 는 대화 주제 짧은 한·두 단어 (LLM 임의안, 사용자 수정 가능).

### 5단계 추출·검증 절차

**MUST 모든 단계 순서대로 수행. 건너뛰기 X.**

#### 단계 1: 대화 전수 스캔

첫 turn 부터 마지막까지 순회. 각 turn 에서 추출:

- 사용자 발화: 의도·결정·정정·명시 코멘트·가이드·가설·가정
- LLM 발화: 제안·결정 흐름·임의안·대안 제시

요약식으로 건너뛰기 X. turn 단위로 본다.

#### 단계 2: 카테고리별 분류

추출 항목을 다음 8축으로 분류:

1. **작업 진행 위치** — 현재 어느 단계/§ 까지
2. **결정** — 사용자 확정·합의 사항
3. **결정 흐름** — 결정 이르기까지 근거·대안·트레이드오프
4. **사용자 정정 패턴** — LLM 이 틀린 부분 → 사용자 명시 정정 (재발 방지용)
5. **사용자 명시 가이드** — 메타 행동 지침·작업 원칙
6. **가설·가정** — 확정 안 받았지만 작업 흐름에 영향
7. **보류·미합의** — 보류된 결정·미합의 논의
8. **자료 컨텍스트** — 자료 위치·핵심 발췌

#### 단계 3: 산출물 중복 제거

산출물에 이미 표면화된 결과·매핑·포인터는 _wip.md 에 옮기지 X.
(spec.md 예: `[확정]`/`[OPEN]` 헤더 본문, §9 본문 외 결정사항, BPMN·와이어프레임·항목·매핑 등 본문 그 자체)

**유지 대상**: 결과는 산출물에 들어갔지만 **그 결과에 이르는 흐름·근거·정정·가설·메타 가이드** = _wip.md 의 자리.

#### 단계 4: _wip.md 작성

[wip-md-template](references/wip-md-template.md) 구조에 따라 카테고리별 절에 작성.

- 결정 흐름은 결정 단위로 항목화: `결정 / 근거 / 대안 / 정정 흐름`.
- 정보량 누락 X. "한 페이지 요약" = 누락이지 압축 아님. 800K 대화면 _wip.md 도 그 규모의 핵심 정보가 모두 들어가야 함.
- 산출물 본문 표현을 _wip.md 에 다시 옮기지 X (단계 3 적용).

#### 단계 5: 누락 검증

대화 turn 재스캔. 단계 2 의 8축 전체에 대해 누락 검증.

누락 발견 시 단계 4 보강. 검증 통과 후 작업 종료.

## 운용

- 갱신 = 사용자 명시 요청 시. 자동 갱신 X.
- 작성 시 그 시점까지의 분석 컨텍스트 전체를 재작성 (누적 X, 덮어쓰기).
- 산출물 없는 일반 대화: 사용자가 새 세션에서 `.wips/...md` 첨부.
- 합의 사항이 산출물로 이동하면 `_wip.md` 에서 해당 부분 제거.
