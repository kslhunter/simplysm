## 섹션별 역할

| 섹션 | 용도 |
|---|---|
| `## 메타` | 상태/체크포인트 |
| `## R 단위 검증` | R별 자동 검증 + 시연 + 의도 부합 인라인 통합 |
| `## 통합/E2E 검증` | R 간 흐름 검증 결과 |
| `## 회귀 검증` | 전체 테스트 + 영향 페이지 동작 |

## R 항목 내부 요소

| 요소 | 의미 |
|---|---|
| **충족 여부** | 충족 / 부분충족 / 미충족 (종료 시엔 모두 충족) |
| **코드 분석** | spec.md R ↔ 실제 코드 대조 |
| **테스트 실행** | impl.md 테스트 직접 실행 + 결과 비교 |
| **시연** | 시나리오 + 사용자 확인 결과 (필요 R만) |
| **의도 부합** | 사용자 최종 판정 |
| **Q** | (있을 때만) 재진입 결정 등 사용자 확인 |
