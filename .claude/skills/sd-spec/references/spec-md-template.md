# spec.md 템플릿

REQ 폴더 안에 위치 (`.specs/{yyMMddHHmmss}/REQ-XXX-슬러그/spec.md`).

## 템플릿

```markdown
# REQ-001-입고지시서수정

## 메타
- 상태: draft | specifying | specified | planning | planned | implementing | implemented | verifying | done | dropped
- 생성일: YYYY-MM-DD
- 마지막 갱신: YYYY-MM-DD
- 관련 영역: <도메인 / 세부영역>
- 의존: REQ-XXX (있을 때만)

## 이력 (메타 수준 변경 발생 시만)
<!-- 분리/병합/폐기/재분류 발생 시 기록. 평소엔 섹션 자체 생략 가능 -->
- YYYY-MM-DD: REQ-XXX에서 분리됨

## 요약
<1줄 요약>

## 용어
<!-- 이 REQ 분석/Q 처리 중 발견된 약어·도메인 고유어·모호 용어. 일반 명사 X. 없으면 섹션 생략 가능 -->
- [ ] T1: <용어>
  - **A**: <합의된 정의> (YYYY-MM-DD 확정)
  - 출처: R<번호> 또는 <파일경로>:L<범위>
- [ ] T2: <용어>
  - [ ] **Q**: <정의/동의어/범위 등 확인 필요 사항>
  - 출처: ...

## 세부 요구
- [ ] R1: <요구 제목>
  > [YYYY-MM-DD, 초안] "원문 인용"
  > 출처: <파일경로>:L<범위> 또는 채팅 paste 인용 + 일자
  >
  > [YYYY-MM-DD, **최종**] "최종 인용"
  > 출처: ...

  - **A**: <합의된 가정> (YYYY-MM-DD 확정)
  - [ ] **Q**: <사용자에게 확인 필요한 사항>

- [ ] R2: ...
```

## 섹션별 역할

| 섹션 | 용도 |
|---|---|
| `## 메타` | 상태/일시/영역/의존 |
| `## 이력` | 메타 수준 변경 (분리/병합/폐기/재분류). 발생 시만 |
| `## 요약` | 1줄 요약 |
| `## 용어` | 이 REQ 분석/Q 처리 중 발견된 용어. T 체크리스트 안에 A/Q 인라인. 없으면 생략 |
| `## 세부 요구` | R 체크리스트. 각 R 안에 인용/A/Q 인라인 |

## R 항목 내부 요소

- **인용**: 시간순 + 상태 태그 (`[초안]`, `[구체화]`, `[번복]`, `[최종]`)
- **출처**: 파일경로 + 라인 범위 (예: `.docs/...eml:L42-L48`) 또는 채팅 paste 인용 + 일자. Direct 모드(사용자 직접 요청)는 "사용자 직접 요청 + 일자".
- **보정 시**: `[원문] "..."` 같이 보존, 화자 추정 시 `[추정: B 차장]`
- **A (가정)**: 사용자와 합의된 결정. 원본에 없는 것. 영구 보존
- **Q (미결)**: 사용자에게 확인 필요. 0개 되어야 specified 전환 가능

## 예시

```markdown
## 용어
- [x] T1: 긴급
  - **A**: 당일 입고 처리가 필요한 건 (2026-05-03 확정)
  - 출처: R1
- [ ] T2: PDF 강조
  - [ ] **Q**: 색상 단독인가, 굵기/배경도 포함인가?
  - 출처: R2

## 세부 요구
- [ ] R1: 입고지시서 화면에 "긴급" 체크박스 추가
  > [2026-01-22, 초안] "긴급 표시 기능이 필요합니다"
  > 출처: .docs/20260122_Ethan_Reporting기능개발요청.eml:L80-L82
  >
  > [2026-03-25, **최종**] "체크박스 형태로 화면 우상단에 배치"
  > 출처: .docs/20260325_Ethan_입고지시서수정요청건.eml:L42-L48

  - **A**: 체크박스는 헤더 영역 우측 (2026-05-03 확정)
  - [ ] **Q**: 디폴트 값은 unchecked인가?

- [ ] R2: 긴급 표시된 PDF 출력 시 빨간색 강조
  > [2026-03-17 회의, 추정: B 차장] "PDF에 빨간색으로 강조"
  > [원문] "PDF에 빨간색으루 강조"
  > 출처: .docs/회의대본_3.txt:L120

  - **A**: PDF는 #D32F2F (2026-05-03 확정)
```

## Direct 모드 출처 표기 예시

Direct 모드(사용자 직접 요청)는 파일/라인 대신:

```markdown
> [2026-05-03, 사용자 요청] "상차 상태 추가"
> 출처: 사용자 직접 요청 (2026-05-03)
```
