# sd-modal 스타일 — 수동 검증

## 전제 조건

- sd-modal을 사용하는 소비 프로젝트가 실행 중이어야 한다
- 브라우저(Chrome)에서 접속 가능해야 한다

## 수행 절차

1. 모달을 여는 버튼을 클릭한다
2. 반투명 배경 오버레이가 표시되는지 확인한다
3. dialog가 화면 중앙에 위치하는지 확인한다
4. 헤더에 제목과 닫기(×) 버튼이 표시되는지 확인한다
5. 닫기 버튼에 호버하면 배경색이 변하는지 확인한다
6. float=true 모달이 작은 크기로 표시되는지 확인한다
7. fill=true 모달이 전체 화면을 채우는지 확인한다
8. position="bottom-right" 모달이 우하단에 표시되는지 확인한다
9. 모바일 뷰포트(520px 이하)에서 모달이 하단에 표시되는지 확인한다
10. resizable=true일 때 모달 가장자리에서 리사이즈 커서가 표시되는지 확인한다

## 기대 결과

- backdrop이 화면 전체를 어둡게 덮음
- dialog가 흰색 배경 + 그림자로 중앙에 위치
- 헤더가 제목(좌측, 볼드) + 닫기 버튼(우측)으로 구성
- 각 변형(float/fill/position)이 올바른 위치/크기로 표시
- 모바일에서 dialog가 하단에 정렬
