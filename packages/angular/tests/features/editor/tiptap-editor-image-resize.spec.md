# 이미지 드래그 리사이즈

## 전제 조건
- sd-tiptap-editor 컴포넌트가 화면에 렌더링되어 있다
- 에디터에 이미지가 삽입되어 있다 (클립보드 붙여넣기 또는 드래그 앤 드롭)

## 수행 절차
1. 에디터 내의 이미지를 클릭한다
2. 이미지 주변에 리사이즈 핸들이 표시되는지 확인한다
3. 리사이즈 핸들 중 하나(우측 하단 권장)를 마우스로 드래그하여 크기를 변경한다
4. 드래그를 완료한다 (마우스 버튼 릴리스)

## 기대 결과
- 이미지 클릭 시 리사이즈 핸들(코너 또는 변)이 표시된다
- 핸들을 드래그하면 이미지 크기가 실시간으로 변경된다
- 드래그 완료 후 변경된 크기가 유지된다
- value signal의 HTML에 변경된 width/height가 반영된다
