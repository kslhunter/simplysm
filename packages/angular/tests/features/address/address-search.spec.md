# SdAddressSearchModal — 수동 검증

## 전제 조건
- 앱이 실행 중이고 인터넷 연결이 되어 있다
- SdModalProvider를 통해 SdAddressSearchModal을 열 수 있는 화면이 있다

## 수행 절차
1. SdAddressSearchModal을 모달로 연다
2. 다음 우편번호 검색 위젯이 로딩될 때까지 busy 표시를 확인한다
3. 주소를 검색한다 (예: "테헤란로 427")
4. 도로명 주소를 선택한다
5. 모달이 닫히고 선택된 주소가 반환되는지 확인한다
6. 모달을 다시 열어 스크립트 중복 로딩 없이 즉시 위젯이 표시되는지 확인한다
7. 지번 주소를 선택하여 지번주소가 반환되는지 확인한다

## 기대 결과
- busy 표시가 스크립트 로딩 중에 나타나고, 로딩 완료 후 사라진다
- 다음 우편번호 검색 위젯이 모달 내에 정상 렌더링된다
- 도로명 주소 선택 시 부가주소(동명, 아파트 건물명)가 포함된다
- 지번 주소 선택 시 지번주소가 반환된다
- 두 번째 열기 시 스크립트가 중복 삽입되지 않는다
