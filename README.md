# Simplysm

Simplysm monorepo -- a collection of TypeScript packages for building full-stack Angular applications with ORM, service framework, build tooling, and mobile support.

## Packages

| Package | Description |
|---------|-------------|
| [`@simplysm/angular`](./packages/angular) | Angular 21 UI component library |
| [`@simplysm/capacitor-plugin-auto-update`](./packages/capacitor-plugin-auto-update) | Capacitor automatic APK update plugin |
| [`@simplysm/capacitor-plugin-file-system`](./packages/capacitor-plugin-file-system) | Capacitor file system plugin |
| [`@simplysm/capacitor-plugin-intent`](./packages/capacitor-plugin-intent) | Capacitor Android intent plugin |
| [`@simplysm/capacitor-plugin-usb-storage`](./packages/capacitor-plugin-usb-storage) | Capacitor USB storage plugin |
| [`@simplysm/core-browser`](./packages/core-browser) | Core utilities (browser) |
| [`@simplysm/core-common`](./packages/core-common) | Core utilities (platform-neutral) |
| [`@simplysm/core-node`](./packages/core-node) | Core utilities (Node.js) |
| [`@simplysm/excel`](./packages/excel) | Excel file processing library |
| [`@simplysm/lint`](./packages/lint) | Shared ESLint configuration |
| [`@simplysm/orm-common`](./packages/orm-common) | ORM module (common, DB-independent) |
| [`@simplysm/orm-node`](./packages/orm-node) | ORM module (Node.js) |
| [`@simplysm/sd-claude`](./packages/sd-claude) | Claude Code asset synchronization tool |
| [`@simplysm/sd-cli`](./packages/sd-cli) | Monorepo build/check CLI tool |
| [`@simplysm/service-client`](./packages/service-client) | Service module (client) |
| [`@simplysm/service-common`](./packages/service-common) | Service module (common) |
| [`@simplysm/service-server`](./packages/service-server) | Service module (server, Fastify-based) |
| [`@simplysm/storage`](./packages/storage) | Storage module (FTP/FTPS/SFTP) |
